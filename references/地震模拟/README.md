## 三、P/S波传播公式

### P波到达距离

```
d_p = 6.5 * (timer + 震源深度/6.5)
P波到达距离 = sqrt(2 * d_p² - 震源深度²)
```

- `timer`：Scratch计时器（地震发生起，秒）
- `6.5`：P波速度(km/s)
- 本质：P波从震源以6.5km/s传播，到达地面后的水平距离

### S波到达距离

```
d_s = 4.0 * (timer + 震源深度/6.5)
S波到达距离 = sqrt(2 * d_s² - 震源深度²)
```

- `4.0`：S波速度(km/s)
- S/P速度比 ≈ 0.615，接近理论值 1/√3 ≈ 0.577
- 当结果为NaN时，S波到达距离设为-1（深源地震S波未到地面）

### 圆绘制半径

```
屏幕半径 = P波到达距离 / 1步距离
```

将公里距离转换为屏幕像素。

## 四、波圆绘制算法

### 绘制过程 `円 半径r 中心x,y 色color 透明度p`

1. `半径r = #zoom * r`（缩放）
2. 设置画笔颜色和透明度
3. 重复501次（500边形近似圆）：
   - `X = #zoom * (x - #centerX) + 半径r * cos(方向) - 0.6`
   - `Y = #zoom * (y - #centerY) + 半径r * sin(方向) - 0.6`
   - 屏幕内落笔，屏幕外抬笔
   - 右转 0.72° (360/500)

### 波颜色

| 波类型 | 颜色 | 条件 |
|--------|------|------|
| P波 | `#66c8ff`（浅蓝） | 始终 |
| S波 | `#3aff6f`（绿） | 震度 < 2.5 |
| S波 | `#ffde00`（黄） | 2.5 ≤ 震度 < 4.5 |
| S波 | `#ff0000`（红） | 震度 ≥ 4.5 |

## 五、观测站检测逻辑

### 检测条件

对每个观测站n：
```
震中距离 = sqrt((#震中X - 観測点x[n])² + (#震中Y - 観測点y[n])²) * 1步距离
```

- P波到达：`震中距离 < P波到达距离 - 8`（8像素容差）
- S波到达：`震中距离 < S波到达距离 - 8`
- 即时模式：`震级即时显示模式=1` 时直接显示

### P波检出记录

1. 站点不在 `[P/SCal]检测P#` 列表中 → 添加
2. 记录检出时间到 `观测点_检出时间`
3. `P波检测次数` 递增

### 三边测量反算震中

当 P波检测次数 ≥ 5 时，`P/S计算`精灵开始：
1. 收集检测到P波的观测站数据
2. 用P波到达时间差计算各站到震源距离
3. 中垂线法确定震中位置
4. 广播 `计算震波绘制循环`

## 六、主循环流程

每帧执行 `制御` 过程，按顺序广播：

1. `緊急地震速報_制御` — EEW控制
2. `事前計算` / `事前計算2` — 预计算
3. `判定` — 判定
4. `#E_日本地図location` — 地图定位
5. `#E_地震base` — 地震基础数据
6. `#E_観測点location` — 观测点定位
7. `#E_显示观测点` — 显示观测点
8. `#E_波生成` — **P/S波绘制**
9. `#E_震源location` — 震源定位
10. `#E_中垂线绘制` — 中垂线
11. `#E_绘制晃动检测框` — 检测框
12. `#E_显示M_深度` — 震级深度
13. `#E_显示观测点绘制` — 观测点绘制
14. `#E_计算震源绘制` — 计算震源
15. `最大震度表示` — 震度显示
16. `津波_計算` — 海啸计算
17. `処理8` — 后处理
