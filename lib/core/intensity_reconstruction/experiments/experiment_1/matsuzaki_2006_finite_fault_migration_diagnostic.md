# 松崎式有限断层距离迁移诊断

日期：2026-08-21

## 目的和边界

本诊断只读取原始 JMA 年度归档，在每个已知事件的目录震中、深度和震级固定时，比较：

```text
同一观测震度 + 同一前向系数 + 点震源三维距离
同一观测震度 + 同一前向系数 + 来源有限断层最短三维距离
```

它量化的是有限断层距离语义迁移对前向模型的影响，不是未知事件定位精度，也不是新的
系数标定。目录震源信息只用于已知事件的诊断几何和事后指标；没有把它作为未知事件
搜索输入，也没有修改原始年度 JSON 或生产算法。

工具：

```text
tool/matsuzaki_2006_finite_fault_migration_diagnostic.dart
```

输入为已归档的 `2011/2014/2016/2018` 原始 JMA 年度文件。2018 是已经打开的评估年，
因此工具要求显式 `--allow-opened-2018`。有限断层距离仍保留真实值；不在论文 `1-500 km`
域内的记录不钳到 1 km，也不进入 RMS。

机器报告：

```text
.dart_tool/matsuzaki_2006_finite_fault_migration_diagnostic/report.json
.dart_tool/matsuzaki_2006_finite_fault_migration_diagnostic/report.md
```

表中的 RMS 是观测计测震度与公式预测值的逐站 RMS；“有限断层 - 点源”小于零表示在
固定目录震源和固定系数下，有限断层距离的前向预测更贴近观测。

有限断层预测相对点源预测的平均变化全部为正，原因是这些已审计断层对接受站的平均
最短距离小于点源距；但平均变强不等于逐站更准确，2014 和熊本在 `published` 下的
RMS 反而恶化。

## 结论

1. 有限断层距离是实际迁移缺项，但不能作为无条件替换：14 个模型/几何配对中有改善
   也有恶化，方向随事件、系数和几何变化。
2. 2014 的 JMA 有效单元矩形在两套系数下都恶化，说明“几何来源正确”不等于当前
   系数已经适配该距离语义。
3. 熊本在论文原系数下恶化、在 `finiteFaultSemanticFrozen2017` 下改善，直接证明
   距离语义与系数存在耦合，不能只替换 `X` 而保持一套系数对所有语义通用。
4. 大阪双矩形在冻结系数下比单矩形略好，但这只是固定目录震源处的前向诊断；双矩形
   的物理优选仍来自独立震源结构证据，不由本次震度残差选择。
5. 未知事件没有已观测断层面，因此未知事件联合搜索仍只能计算候选点源距。要把有限
   断层效应迁移进去，下一步必须预先定义分层/混合距离标定和独立留出评价，不能把
   该诊断结果直接写成生产默认。
