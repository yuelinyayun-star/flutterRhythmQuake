## EXP1-DEC-001：事件峰值震度与 ARV 场地修正

- 日期：2026-07-18
- 状态：部分撤回；NIED 输入性质已由 `EXP1-DEC-005` 更正

> 2026-07-18 状态更正：`1.72 * log10(ARV_i)` 只在特定的
> PGV-to-intensity 公式中成立。NIED 官方说明表明 GIF `jma_s` 已是防灾科研逐次计算的
> “实时震度”，而不是等待客户端用 PGV 转换的输入。因此下文“GIF 震度直接减去该
> ARV 项”的方案不再是已确认设计，不得实现。现行边界见 `EXP1-DEC-005`。

### 原算法中对应的物理量

原论文的 `I_i` 是同一次地震在第 `i` 个地点的一条事件级烈度，不是每秒当前值、触发级别、到时或震度变化历史。

对候选震中 `P`，原算法先计算每个地点到 `P` 的距离 `Delta_i`，再由 `(I_i, Delta_i)` 反解该地点要求的等效震级 `M_i`。候选位置越合理，各地点的 `M_i` 越一致。

### 当时提出、现已撤回为待验证的输入链路

本记录当时提出：

```text
GIF 连续震度时序
  -> 在同一次事件内按测站取得峰值连续震度 I_peak_i
  -> 使用该测站的 ARV 消除地盘增幅
  -> 得到共同基准地盘上的 I_corrected_i
  -> 对每个候选位置反推各测站 M_i
  -> 比较 M_i 的一致性
  -> 形成候选震中误差面
```

这里的峰值必须来自真实事件时序，不能使用人为递增值、显示值或合成中点。

### ARV 在公式中的位置

项目已有的 JMA 风格连续计测震度关系为：

```text
PGVS = ARV_i * 0.90 * PGV600
I = 2.68 + 1.72 * log10(PGVS)
```

在这个公式体系内，测站间不同的场地项为：

```text
S_i = 1.72 * log10(ARV_i)
```

本记录当时提出“校正观测值”的表达：

```text
I_corrected_i = I_peak_i - S_i
              = I_peak_i - 1.72 * log10(ARV_i)
```

常数 `0.90` 对所有测站相同，不是逐站差异；在后续重新拟合的日本衰减模型中应由全局截距吸收，不能作为逐站 ARV 再扣除一次。

### ARV 的作用边界

ARV 只用于逐站连续震度的场地校正。它通过减少软硬地盘造成的假烈度差异，间接改变各候选位置的 `M_i` 离散和误差面。

ARV 不用于：

- 事件触发条件；
- 测站进入事件的时刻；
- P/S 到时；
- 候选位置与测站的距离；
- 原论文距离权重 `W_i`；
- 测站数量阈值；
- 置信值百分比；
- 地图显示震度。

### 已有资料可以复用的部分

`JmaSeisIntLoc` 已保存约 4372 个 JMA 震度观测点的坐标和 ARV。现有 `JmaStyleIntensityPredictor` 已实现 ARV 到地表 PGV、再到连续计测震度的公式。

这些资料可以作为实验 1 的场地信息来源，但现有“5 km 内取最近 JMA 观测点，否则 ARV=1.0”是旧诊断路径的匹配策略，不是实验 1 已确认规则。

### 明确禁止的处理

- 不把 Yahoo `level` 的区间中点伪造成连续计测震度。
- 不直接对 JMA 离散类别 `4/5弱/5强/6弱/6强/7` 做 ARV 连续减法。
- 不直接对 Yahoo 整数 `level` 减去 `1.72 * log10(ARV)`。
- 不同时“先校正观测震度”又“在前向模型中再次加入同一 ARV”，避免双重场地修正。
- 不使用 Scratch 30 级数值域作为实验 1 输入。
- 不沿用川滇、华北、Scratch HYP 或其他震源算法的衰减系数。

### 待验证，尚未决定

- GIF 连续震度与真实连续计测震度的数值偏差。
- Yahoo 与 GIF 同测站、同观测时刻的对应关系。
- 一次事件的起止边界和每站峰值冻结规则。
- NIED/KA 测站到 JMA ARV 观测点的精确、近邻和无匹配分类。
- 可接受的 ARV 空间匹配距离，不能直接沿用 5 km。
- 是否需要在 ARV 之外再加入逐站经验残差 `stationBias`。
- 日本衰减模型的形式和系数。
- 使用 `M_JMA`、`Mw` 或其他统一震级类型。
- 深度进入模型的方式以及使用震中距还是震源距。
- 搜索网格、距离权重和日本经验置信阈值。

### 第一项验证任务

在修改算法前，先建立 NIED/KA 测站到 JMA ARV 表的映射审计，至少输出：

```text

NIED latitude/longitude
matched JMA station name
JMA latitude/longitude

```

映射审计完成后，才能决定 ARV 能覆盖哪些输入站，以及无匹配站应排除、插值还是使用其他地盘资料。

## EXP1-DEC-002：JMA 校准输入使用官方连续计测震度

- 日期：2026-07-18
- 状态：输入语义已确认，实时 GIF 等价性尚未确认

### 已确认

JMA 年度震度资料的观测记录同时提供：

- 字段 19：JMA 离散震度阶级；
- 字段 21-22：保留一位小数的计测震度；
- `//`：计测震度缺测。

实验 1 标定阶段的 `I_i` 使用字段 21-22 的官方计测震度原值。字段 19
保留用于类别一致性检查、分档报告和异常检查，不把类别转换成区间中点参与回归。

实时输入的候选量是同一事件内每个 NIED/GIF 测站的真实峰值连续震度，但只有在
完成 GIF 与官方计测震度的同站/近邻、同事件验证后，才能确认是否可直接使用、需要
整体校准，还是需要按来源分别建模。

### 不能由本决策推出的内容

- 不能据此认定 GIF 数值与官方计测震度完全相同。
- 不能把 Yahoo `level`、JMA 离散类别或 Scratch 30 级转换成连续中点。
- 不能把官方事件震级直接当成单一 `M_JMA`；震级类型字段仍需筛选或统一。
- 不能把项目现有任一 PGV 公式认定为实验 1 的前向模型。

## EXP1-DEC-003：现有三条 JMA 风格 PGV 路径不作为默认公式

- 日期：2026-07-18
- 状态：冲突已确认，公式来源与适用基准待验证

项目当前存在三种不同计算：

```text
IntensityCalculator:
  x = max(hypocentralDistance - faultLength, 3 km)
  PGVsurface = PGV600 * 1.307 * ARV

JmaStyleIntensityPredictor:
  x = max(hypocentralDistance, 1 km)
  PGVsurface = PGV600 * 0.90 * ARV

source_estimator 震级诊断:
  x = max(hypocentralDistance, 1 km)
  PGVsurface = PGV600 * 0.90
```

三者在参考地盘换算、近距离处理、有限断层处理和 ARV 上都不一致。Git 历史只说明
这些代码何时进入项目，没有给出足以判定物理基准的论文引用。因此实验 1 当前不采用
其中任何一条作为默认公式。

`I = 2.68 + 1.72 * log10(PGVsurface)` 中，若 `ARV_i` 确实以乘法形式作用于
逐站地表 PGV，则逐站差异项在代数上必然为：

```text
S_i = 1.72 * log10(ARV_i)
```

这个结论不依赖全局常数使用 `0.90` 还是 `1.307`。但 ARV 的速度基准、测站匹配
方式和适用频段仍需核实；全局常数不能因上述代数关系被顺带接受。

## EXP1-DEC-004：JMA 震度归档是震度 1 以上的条件样本

- 日期：2026-07-18
- 状态：官方格式已确认

JMA 官方格式明确写明：

- 一个地震最上面的震源记录是代表值（采用值）；
- 震源记录 53-55 是震级 1 及类型，56-58 还可保存震级 2 及类型；
- 震度记录字段 19 是 `1-7/A/B/C/D` 或阶级不明 `9`，没有震度 0；
- 震源记录 91-95 的观测点数是“观测到震度 1 以上的观测点数”；
- 字段 21-22 的计测震度缺测值是 `//`。

因此当前年度归档提供的是震度 1 以上站点的条件样本，不是每个事件下全台网包含
震度 0 的完整空间场。实验 1 必须遵守以下边界：

1. 未出现在事件记录中的测站不能自动作为震度 0。
2. 仅用该归档拟合时，训练目标和评估结论必须注明“条件于归档观测站”。
3. 若实时 GIF 使用低于震度 1 的站，必须建立包含这些站的独立完整数据集，或在实时
   推理时采用与标定一致的站点选择规则；不能把两种采样域直接混合。
4. 经验置信标定必须重现训练资料的站点选择过程，否则覆盖率没有相同统计含义。
5. 当前解析器只保存震级 1，尚未保存震级 2、深度标准误差、震源评价和使用走时表；
   深度感知实验的数据层需要补齐这些官方字段后再筛选。

## EXP1-DEC-005：NIED `jma_s` 已是实时震度，不是 PGV 输入

- 日期：2026-07-18
- 状态：NIED 官方定义已确认；与 JMA 最终计测震度及场地校正关系待验证
- 官方来源：<https://www.kyoshin.bosai.go.jp/ja/about_kmoni/>

NIED“强震モニタについて”对强震指标的定义为：

- 实时震度：防灾科研开发、逐次计算的参考震度，具有与使用完整摇动记录计算的震度
  大致一致的特点；
- 最大加速度：强震计实际观测的三分量合成加速度每秒最大值；
- 最大速度：将摇动加速度积分得到的速度每秒最大值；
- 最大位移：将摇动加速度积分两次得到的位移每秒最大值。

因此 NIED `jma_s` 和 `vcmap_s` 是并列输出：

```text
jma_s   = NIED 已逐次计算的实时震度
vcmap_s = 加速度积分得到的每秒最大速度
```

实验读取 `jma_s` 时，不需要也不能再执行一次 PGV-to-intensity 转换。事件峰值可以从
真实 `jma_s` 时序取得，但它是否数值等同于 JMA 归档的一位小数最终计测震度，仍需
同事件、同站或可靠近邻数据验证。

NIED 官方页面还说明，J-SHIS 的 250 m 地盘增幅率用于紧急地震速报驱动的约 5 km
网格“预测震度分布”。该段不是对观测站 `jma_s` 实时震度计算流程的说明，不能据此
断言 NIED 对观测实时震度又应用了同一个 ARV。

因此实验 1 当前采用以下边界：

1. NIED `jma_s` 作为已经计算好的实时震度输入，保留原值和事件内真实峰值。
2. 不对 `jma_s` 默认执行 `I - 1.72 * log10(ARV)`。
3. 若要消除测站场地偏差，优先用 JMA 标定事件估计可验证的逐站长期残差
   `stationBias`；ARV 作为候选解释变量单独比较。
4. 只有在证明某个 ARV 定义、速度基准和 NIED 实时震度之间的量化关系后，才能把
   ARV 写入 `jma_s` 的校正公式。
5. 另一条独立实验可以读取 `vcmap_s` 最大速度层并建立 PGV 路径，但不能把该路径与
   `jma_s` 路径混为同一个输入。

## EXP1-DEC-006：日本前向模型先做并列实验，不直接替换生产公式

- 日期：2026-07-18
- 状态：候选模型、来源和禁止事项已确认；最终系数待现代 JMA 数据验证

已归档并核实两条不同的日本预测路线：

1. 气象厅现行 PGV 业务链：`Mj -> Mw -> PGV600 -> PGV700 -> 地表 PGV -> 震度`。
2. 松崎等（2006）直接震度式：`Mj + 距离 + 深度 -> 地表 JMA 震度`。

实验 1 以松崎式作为保留 GSTSL“每站烈度反解共同事件规模”核心的第一条日本基线，
同时保留气象厅 PGV 链作为官方业务对照。松崎原系数只用于复现实验，还必须用现代
JMA 一位小数计测震度重新拟合同函数形式并做事件级留出验证。

已确认的禁止事项：

- 不把 `jma_s` 再转换一次 PGV 或震度。
- 不把气象厅 PGV 链中业务使用的 `3 km` 下限移植到松崎直接震度式。
- 不把 Iwakiri 等（2011）清理特定近海目录时的 `10 km` 深度改写成候选震源默认深度。
- 不把 Ogiso 等（2016）的波形级频率相关场地修正用于只有标量 `jma_s` 的输入。
- 不把 Hoshiba 等（2010）的震度单位不确定性当成震中公里误差或候选置信概率。

场地处理首先比较逐站长期经验残差。估计时必须剥离事件源项，并对深源异常震域和
近断层非场地效应做单独审计；不能把 `I - 1.72 log10(ARV)` 重新作为默认输入校正。

完整公式、数据范围和实验分组见 `japanese_forward_model_sources.md`。

## EXP1-DEC-007：松崎式反解必须保留近距离双根

- 日期：2026-07-18
- 状态：公式结构和实现测试已确认；候选评分方法待比较

对松崎式按震级求导后确认，短距离时震度并非在 `Mj 5.0-8.2` 内始终单调。同一组
`观测震度、距离、深度` 可能有两个有效震级根。实验实现返回零个、一个或两个根，
并分别标记无解、唯一解和歧义解；不默认选择高震级或低震级分支。

原 `GstsReconstructor` 的单值闭式 `M_i` 接口不适用于该公式，且保持不变。下一步
需要在“每站全根共同簇”和“候选下直接优化共同 M 的前向残差”之间做独立比较。

## EXP1-DEC-008：2020-2022 JMA 原系数前向基线

- 日期：2026-07-18
- 状态：首次运行完成
- 完整记录：`matsuzaki_2006_jma_baseline_2020_2022.md`

严格使用论文震级、距离和深度范围，只接受 JMA `D/d/V/v` 类型、每事件至少 10 个
有效站，并排除站点记录无法分配给具体震源的复合记录。最终接受 162 个事件和
45,813 个测站残差。

按测站加权的平均残差为 `+0.249`、MAE `0.529`、RMS `0.661`；每事件等权的事件
均值残差平均为 `+0.120`、事件 MAE 平均为 `0.568`、事件 RMS 平均为 `0.674`。
`15-30 km` 分组平均残差为 `-0.957`，显示近距离明显过预测，但该组只有 161 个站，
尚不能直接确定修正系数。

## EXP1-DEC-009：前向残差保留为主评分候选，原系数不得扩大定位网格

- 日期：2026-07-18
- 状态：三组固定深度候选诊断完成；现代系数待拟合
- 完整记录：`matsuzaki_2006_candidate_scoring_diagnostic.md`

合成数据确认全根法和前向法都能恢复真实候选，且全根法能够处理双根。但在真实 JMA
数据中，严格全根法因任一站无根即失效，在 10-50、51-200、201-500 站三组中分别
只有 35/52、13/33、12/43 个事件存在有效候选，因此只保留为可逆性诊断。

前向法三组全部可评分，但分别有 41/52、28/33、30/43 个事件的最优点贴到
`+/-0.3°` 搜索边界。当前位置误差只是有限网格下界，不能当作收敛结果。前向法保留
为现代系数拟合后的主评分候选；在距离/深度残差改善前，不扩大网格、不增加候选深度，
也不将当前结果接入生产算法。

## EXP1-DEC-010：自由现代拟合发生饱和项退化，不作为最终日本公式

- 日期：2026-07-18
- 状态：2020 训练、2021 验证、2022 冻结测试和定位复测完成
- 完整记录：`matsuzaki_2006_coefficient_calibration_2020_2022.md`

两种拟合都保持松崎式的代数形式，但不设置未经资料支持的数值上下界。全局测站加权
法和事件源项剥离法的五个不同起点全部分别收敛到同一结果；两者的饱和指数 `d` 分别
约为 `2.90e-12` 和 `1.96e-13`。对应饱和项在 `Mj 5.0-8.2` 内的倍率仅为
`1.0000000000214` 和 `1.00000000000144`，已经失去论文原式的震级相关近场饱和。

按 2021 事件等权 RMS 选择全局测站加权模型做一次 2022 冻结评估后，前向 RMS 从
原系数的 `0.670` 降为 `0.559`，事件等权 RMS 从 `0.660` 降为 `0.538`。但改善主要
来自远距离大量测站，`15-30 km` 和 `30-100 km` 的测试 RMS 反而上升。

相同固定深度、相同 `+/-0.3° / 0.1°` 网格的定位复测没有解决贴边。2022 年三档站数
中，目录点最优次数从原系数的 `0/1/1` 变为 `0/0/0`；10-50 站组贴边从 `17/22`
增加到 `20/22`，震级压到 `Mj=5.0` 的事件从 2 增加到 6。

因此该拟合只记录为经验退化诊断，不采用为最终日本公式，也不接生产。下一轮先固定
论文结构做可辨识性实验，再决定是否需要逐站长期偏差、条件选站、异常震域或有限断层
距离；当前仍禁止扩大定位网格或增加候选深度。

## EXP1-DEC-011：当前 JMA 条件归档不能稳定辨识近场 c,d

- 日期：2026-07-19
- 状态：三种结构约束拟合和按年份定位复测完成
- 完整记录：`matsuzaki_2006_structure_identifiability_2020_2022.md`

## EXP1-DEC-031：独立震源结构证据选择大阪双矩形联合
