# 松崎式 JMA 归档条件选站诊断

## 数据边界

日期：2026-07-30

本诊断直接读取已经归档的官方原始文件，不从加工后的年度 JSON 构造未报告站：

```text
code_p.dat
i2010.dat ... i2019.dat
```

官方 URL、ZIP SHA-256、原始文件路径和字节数来自
`tmp/jma_intensity_nearfield_expansion/archive_manifest.json`。2010-2019 均已在此前
实验中打开，本次不是新盲测。测站名称字节、事件记录和计测震度均未修改。

JMA 官方格式明确规定：震源记录 91-95 是“观测到震度 1 以上的观测点数”，逐站
计测震度 `//` 才是缺测。`notArchived` 在本报告中只表示：

```text
code_p.dat 在事件时刻标记为观测中
+ 目录点震源距在公式 1-500 km 域内
+ 事件原始记录没有该站
```

它不等于震度 0，也不获得任何伪造或插补震度。模型在目录震源处的预测只用于分层统计
归档率，不作为观测值。

## 原始完整性

10 年共有 1013 个满足 `Mj 5.0-8.2`、深度 `5-100 km`、单一震源、至少 10 条连续
计测震度记录的事件。

| 检查 | 结果 |
|---|---:|
| 官方观测点数缺失事件 | 0 |
| 官方观测点数与原始记录数不一致事件 | 0 |
| 原始站记录 | 349641 |
| 有效连续计测震度 | 349641 |
| 连续计测震度缺测 | 0 |
| 最低连续计测震度 | 0.5 |
| 站码不在 `code_p.dat` | 0 |
| 与测站观测期冲突的已归档记录 | 82 |
| 活动但震源距超过 500 km 的有效记录 | 8138 |
| 震源距低于 1 km 的有效记录 | 0 |

82 条观测期冲突集中在 11 个站码，单一站码占 57 条。官方格式确认 `code_p.dat` 第 5/6
列确实是观测开始/结束时间，因此这些是当前站表和历史事件记录之间的来源冲突，不能
通过重解释列定义消除。观测期只能用于统计机会域，不能充当逐事件绝对在线证明。

## 归档机会域

1013 个事件共有 1598351 个“活动且在 1-500 km 内”的事件-测站机会，其中 341421 个
有原始归档记录。归档率随目录震源距下降：

| 目录点震源距 | 机会 | 已归档 | 未归档 | 归档率 |
|---|---:|---:|---:|---:|
| 1-<30 km | 1363 | 1252 | 111 | 91.856% |
| 30-<100 km | 54368 | 46500 | 7868 | 85.528% |
| 100-<300 km | 702681 | 250709 | 451972 | 35.679% |
| 300-500 km | 839939 | 42960 | 796979 | 5.115% |

这是条件选站的直接证据：远距离台站主要因为没有达到归档震度条件而不出现，但来源
不能区分低震度、瞬时缺报和站表历史冲突，仍不得赋值。

## 输入合同

原始 349641 条合格记录的连续计测震度全部 `>=0.5`，且官方站数与记录数逐事件完全
一致。因此当前独立算法的可复现输入合同为：

```text
有效连续计测震度 >= 0.5
-> 再应用来源独立的距离安全筛选
-> 再应用尚未冻结的最大站数
```

`Matsuzaki2006ArchiveInputSpec.minimumInstrumentalIntensity` 已成为显式必填参数，现有
JMA 实验全部传入 `0.5`。低于阈值的值按原值拒绝并计数，不钳值、不修改。2019、30 站
联合反演重跑后，与加入阈值前逐事件比较，选中站、状态、边界、候选和误差均为 0 处
不一致；历史 JMA 结果没有被回调。

若后续接 NIED 连续震度，必须先保留 `>=0.5` 的真实站值，再进入该条件模型。不能把
NIED 全台网低震度值直接与 JMA 条件归档混用，也不能只保留任意最强 30 站冒充同域。

## 决定

1. 确认 `0.5` 为当前 JMA 条件模型的观测值下界，并写入输入规格和测试。
2. 未归档站不进入震度 RMS，不补 0，不补 0.5。
3. 当前不加入“预测超过 0.5 就惩罚”的单侧项；活动期冲突和大量高预测未归档机会使
   这种硬惩罚没有经过验证。
4. 条件选站与完整台网模型必须分开命名。当前仍是归档条件模型。
5. 下一步剥离每个事件共同源项后，按站码统计跨事件长期残差；只有训练/验证年份保持
   同方向的站点项才进入独立实验，不能由 2018/2019 回调。
