# 松崎等（2006）逐站残差：预声明收缩实验

## 目的和边界

本实验只检验前一轮已发现的低样本站点项风险，站项仍由 2010-2016 年逐事件去均值后的
真实残差训练。它不修改 JMA 原始连续计测震度、不补未归档或未覆盖站、不重拟合
2018/2019，也不连接生产算法。

每个已拟合站项 `b(s)` 按训练事件数 `n(s)` 收缩：

```text
b_shrunk(s) = b(s) * n(s) / (n(s) + k)
```

`k=0` 与此前的未收缩结果严格相同；`k>0` 只把已经训练出的站项向零收回。没有估计的站
依然保留原始模型预测与原始残差。

## 预声明协议

| 项目 | 固定值 |
|---|---|
| 训练年 | 2010-2016 |
| 选择年 | 2017 |
| 冻结复用年 | 2018、2019 |
| 最小训练事件数候选 | `2, 5, 10, 20` |
| 收缩伪事件数候选 `k` | `0, 1, 2, 5, 10` |
| 选择指标 | 2017 年保留所有观测的事件等权中心化 RMS |
| 接受条件 | 相同候选基线之下严格改善超过 `1e-12` |
| 并列规则 | 先更高最小训练事件数，再更高 `k` |
| 新最终留出年 | 未打开 |

选择和所有参数只读取 2017。2018/2019 只应用已选 `(最小事件数, k)`，不参与选参。

## 选择结果

两套前向模型均选择最小训练事件数 `2`、收缩 `k=2`。这不是从冻结年倒推得到的结果。

| 模型 | 2017 基线 RMS | 未收缩 `k=0` | 选择的 `k=2` | 相对基线改善 |
|---|---:|---:|---:|---:|
| 论文原系数 | 0.475450 | 0.381176 | 0.377964 | 20.504% |
| 冻结 2017 有限断层语义系数 | 0.442393 | 0.365228 | 0.361406 | 18.307% |

每套模型的完整 20 个候选组合都已保存在机器报告中。两个模型的 `k=2` 都是该选择年的
最低已接受中心化 RMS；较强收缩 `k=5/10` 不再继续改善。

## 冻结复用结果

| 模型 | 年份 | 基线 RMS | `k=2` RMS | 改善 | 改善/恶化/不变 |
|---|---:|---:|---:|---:|---:|
| 论文原系数 | 2018 | 0.486055 | 0.379818 | 21.857% | 54/0/0 |
| 论文原系数 | 2019 | 0.478484 | 0.364073 | 23.911% | 46/3/0 |
| 冻结 2017 有限断层语义系数 | 2018 | 0.462913 | 0.377707 | 18.407% | 54/0/0 |
| 冻结 2017 有限断层语义系数 | 2019 | 0.453573 | 0.360073 | 20.614% | 46/3/0 |

相对未收缩站项，发布系数的 2017 恶化事件从 `6` 降到 `5`，2018/2019 保持 `0/3`；
冻结系数从 `7/2/4` 降到 `7/0/3`。因此收缩降低了部分冻结复用风险，但没有消除所有
事件级恶化。

## 风险复核

`trainingEventCount = 2` 不再是坏分层：发布系数 2017 的 75 条记录从
`0.530940` 降至 `0.506986`；冻结系数从 `0.473292` 降至 `0.441393`。这支持选择
收缩而不是把最低训练数直接提高到 5 并损失覆盖率。

发布系数 2019 的 `1-<30 km` 近场 42 条记录从基线 `0.610761` 到 `0.604091`，已经不再
是此前未收缩站项中的轻微恶化。冻结系数的近场仍非全部解决：2017 的 122 条从
`0.632156` 升到 `0.639777`。这仍指向有限断层距离、近场饱和或条件观测，而不是可信的
固定站点项。

无估计站的原始残差始终未被修改；它们的中心化 RMS 仍可能略升，是同一事件内其他站被
修正后事件均值改变的数学结果，不能解释为缺测补值或虚构观测。

## 结论

`k=2` 是在已打开年份中可复现的保守站项正则化选择，可保留为独立实验的冻结候选。
它不证明站项是 ARV 或纯场地放大，不能替代日本前向衰减模型、有限断层距离和 JMA 条件
选站问题，也不能接入生产。下一步必须先冻结未知事件端到端评价协议和未打开的最终
留出人口，再检验“候选震源搜索 + 冻结站项收缩”的整体效果。
