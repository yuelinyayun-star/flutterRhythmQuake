# 松崎式 2014 长野县北部 M6.7 有限断层距离诊断

日期：2026-07-27

状态：JMA 修订近地强震波形有效子断层边界和固定系数距离诊断完成；未重新拟合，未接入
生产。

## 输入事件

JMA 原始 2014 年度记录中的目标事件为：

```text
eventId = 2014112222081790-36.6928-137.8910
区域 = 長野県北部（rawRegionHex 按 Windows-31J/CP932 解码）
originTime = 2014-11-22T13:08:17.90Z
Mj = 6.7
JMA 目录深度 = 4.59 km
最大震度代码 = C（震度 6 弱）
严格接受站 = 1468
点源距 <30 km 测站 = 15
```

诊断直接读取原始 `jma_final_intensity_2014.json`，不修改逐站观测震度、事件震级、
JMA 目录深度、基线筛选或系数。点源近场站仍按既有点震源距 `<30 km` 固定，只替换
松崎式（12）的距离 `X`。

## JMA 来源模型

JMA `2014112222081790near` 修订近地强震波形反演数据的 `01event.txt` 和
`02fault.txt` 给出：

```text
last updated = 2017-03-13
type = near02
fault plane count = 1
strike = 25 degrees
dip = 61 degrees
rake = 59 degrees
rupture start = 36.6928 N, 137.8910 E, depth 4.59 km
Xorg = 7
Worg = 2
subfault size = 3 km x 3 km
assumed grid = 11 x 6
rupture speed = 2.0 km/s
Mw = 6.54
maximum slip = 2.44 m
```

JMA PDF 的暂定说明把破裂区域概述为沿走向约 `20 km`、沿倾斜方向约 `15 km`。
修订 ZIP 给出更完整的单元级边界：`11 x 6` 是假定网格，不是全部有效断层。
`format_english.txt` 明确说明 `Mark=0` 的子断层未用于反演；实际标记为 1 的单元为：

```text
X = 5..11
W = 1..4
active grid = 7 x 4
active rectangle = 21 km x 12 km
```

其余 `X=1..4` 和 `W=5..6` 单元全部为 `Mark=0`，滑移文件中也为 `-`。把整个
`33 km x 18 km` 假定网格用于距离会人为扩大断层，因此本诊断只使用连续的有效单元
矩形。`21 km x 12 km` 是修订数值数据的精确边界，不把 PDF 的“约 20 x 15 km”
文字反向改造成另一个人为矩形。

`Xorg=7/Worg=2` 所在行的中心坐标与破裂起点完全一致。相对于有效矩形起点，内部锚点
为：

```text
沿走向偏移 = (7 - 5 + 0.5) * 3 = 7.5 km
沿下倾偏移 = (2 - 1 + 0.5) * 3 = 4.5 km
下倾方位 = 25 + 90 = 115 degrees
```

几何代码实际输出的上缘深度为 `0.654211 km`。这是由来源参数派生的透明值，不是 JMA
单独报告值。JMA PDF 图面同时确认星号为破裂起点、A 到 B 对应走向，主要滑移围绕
破裂起点并沿神城断层附近向北扩展；第二页只是 9 个反演站的观测/理论波形对照。

本事件的 JMA 目录深度和反演破裂起点深度同为 `4.59 km`，衰减式深度项没有被替换。

## 距离域边界

15 个固定近场站中有 2 站的有限断层距离低于论文 `1 km` 数据域下限：

| 站号 | 有限断层距 km |
|---|---:|
| 4201020 | 0.665667 |
| 4201130 | 0.654213 |

诊断保留真实几何距离，不钳到 `1 km`，也不外推公式。距离汇总使用全部 15 个站；
残差和点源/有限断层对比只使用其余 13 个相同配对站。

## 固定系数结果

| 距离 | 最小 km | 平均 km | 最大 km |
|---|---:|---:|---:|
| JMA 目录点震源 | 5.139054 | 19.563843 | 29.461481 |
| JMA 有效子断层矩形 | 0.654213 | 15.528675 | 25.866373 |

15 个站的距离全部缩短，平均缩短 `4.035168 km`。以下残差使用 13 个同配对有效域站：

| 系数/距离 | 平均残差 | MAE | RMS |
|---|---:|---:|---:|
| 论文原系数 + 点震源 | -0.219857 | 0.467245 | 0.580148 |
| 论文原系数 + 有限断层 | -0.392663 | 0.581630 | 0.728358 |
| 2017 冻结系数 + 点震源 | +0.525906 | 0.652092 | 0.775423 |
| 2017 冻结系数 + 有限断层 | +0.403919 | 0.627446 | 0.743871 |

论文原系数只有 5/13 站绝对残差改善，RMS 恶化 `25.55%`。2017 冻结系数有 10/13 站
改善，但 RMS 只降低 `4.07%`，仍有明显 `+0.403919` 平均残差。

## 结论和边界

本事件再次证明有限断层距离会实质改变近场输入，同时展示了一个新的来源处理要求：
反演 ZIP 的假定网格不能自动等于有效断层边界，必须遵守逐单元 `Mark`。本事件有效
单元恰好形成连续矩形，所以可以无猜测地进入统一距离目录。

现有两套系数仍对距离替换表现不同；冻结系数总体只小幅改善，论文原系数明显恶化。
因此不能单项接入生产，也不能回调已经打开的 2018 重新选系数。继续补齐其余事件后，
再以统一的有效有限断层距离重新标定。
