# 松崎式有限断层距离语义重标定与 2017 选择

日期：2026-07-29

状态：2010-2016 重新标定和 2017 选择完成；2018 在本工具运行期间未读取；不接生产。

## 冻结协议

本轮不改变既有数据切分、结构或门槛：

```text
校准 = 2010-2016
验证和选择 = 2017
冻结评估 = 2018，本工具不读取
c = 0.00675
d = 0.5
候选 = natural、nearWeight25、nearWeight50、nearWeight75
通过门槛 = 2017 近场事件 RMS 严格改善，且全距离事件 RMS 不恶化
选择 = 通过门槛者中 2017 近场事件 RMS 最低
```

距离语义改为：有可靠来源有限断层的目标强震使用测站到断层联合表面的最短三维距离；
其他事件保留点震源三维距离。2017 没有已接受且需替换的来源候选，所以验证集距离仍为
点震源语义。大阪属于 2018，不进入本轮拟合或选择。

## 输入人口

2010-2016 严格基线共有 `924` 个接受事件、`307517` 个接受站。以下五个事件的全部
接受站替换为来源有限断层距离：

| 事件 | 几何 | 原接受站 | 公式域内保留 | 域外排除 |
|---|---|---:|---:|---:|
| 福岛县中通 M6.4 | JMA 修订矩形 | 1339 | 1339 | 0 |
| 2014 长野县北部 M6.7 | JMA 有效单元矩形 | 1468 | 1466 | 2 |
| 熊本地方 M6.5 | NIED 修订矩形 | 916 | 916 | 0 |
| 鸟取县中部 M6.6 | NIED 修订矩形 | 1714 | 1713 | 1 |
| 茨城县北部 M6.3 | JMA 修订矩形 | 1294 | 1294 | 0 |

3 条 `<1 km` 真实几何距离保留在目录，但不钳到 1 km，也不代入论文公式。距离覆盖后的
公式输入为 `307514` 站。按最终距离语义重新执行“至少两个 `<30 km` 站”选择后，距离
形状训练为 `71` 个事件、`41088` 个站；源项仍使用全部 `924/307514`，没有缩成五个
有限断层事件。

2017 验证为 `54` 个事件、`17329` 个站；近场验证为 `7` 个事件、`122` 个站。
