# 实验 1：日本前向震度模型来源审计

## 目的与证据等级

本文逐项核实原 GSTSL 公式中的震度、震级、距离、深度、近距离饱和、场地项和误差项在日本资料中应如何处理。这里只确定候选实验和禁止事项，不把任何一条旧公式直接宣布为生产模型。

证据等级固定为：

1. 气象厅、NIED、J-SHIS 官方资料用于确定业务定义和当前计算链。
2. 同行评审论文用于确定公式、数据范围、残差与已知局限。
3. note、Qiita、论坛和 GitHub 只用于发现实现线索、复现实验或交叉检查，不能单独决定生产参数。

## 路线 A：气象厅现行 PGV 预测链

气象厅 2024 技术资料给出的业务链是：

```text
Mjma -> Mw
震源、Mw -> 基准基盘 PGV600
PGV600 -> 工学基盘 PGV700
PGV700 -> 地表 PGV
地表 PGV -> 预测计测震度
```

主要公式为：

```text
Mw = Mjma - 0.171

log10(L) = 0.5 M - 1.85

log10(PGV600) = 0.58 Mw + 0.0038 D - 1.29
                - log10(x + 0.0028 * 10^(0.5 Mw))
                - 0.002 x

PGVS ~= ARV700 * 0.90 * PGV600

I = 2.68 + 1.72 log10(PGVS), 仅针对 I=4-7
```

其中 `D` 是震源深度，`x` 是源到目标点的最短距离。当前资料对有限震源的业务近似是：以震源为中心、以经验断层长度的一半为半径设球面，从球面到目标点取最短距离；当前下限为 `3 km`。资料同时说明某些信息采用点震源距离，因此不能把减去 `L/2` 当成所有产品永远相同的定义。

`0.90` 不是任意缩放。松冈・翠川（1994）的关系为：

```text
log10(ARV) = 1.83 - 0.66 log10(AVS) +/- 0.16
```

气象厅据此用约 `(600/700)^0.66 = 0.90` 将 `PGV600` 转为 `PGV700`。随后才乘以相对 `Vs=700 m/s` 工学基盘的 `ARV700` 或气象厅测站经验补正。

这条路线可作为官方业务基准，但不直接成为实验 1 的首选反演式，原因是它串联了 `Mj->Mw`、PGV 衰减、场地增幅和 `PGV->震度` 多个经验关系；最后一个关系还明确只标定于震度 `4-7`。NIED `jma_s` 已是实时震度，不能在输入端再执行一次这条 PGV 转换。

## 路线 B：松崎等（2006）直接震度式

原文式（12）为：

```text
I = 1.36 Mj
    - 4.03 log10(X + 0.00675 * 10^(0.5 Mj))
    + 0.0155 h
    + 2.05
```

变量定义：

- `I`：地表 JMA 震度。1997 年起使用一位小数计测震度；更早记录包含体感震度。
- `Mj`：气象厅震级。
- `X`：有断层模型时使用断层最短距离，其余事件使用震源距。
- `h`：震源深度；计算时超过 `100 km` 的值按 `100 km` 处理。

模型中的 `0.00675 * 10^(0.5 Mj)` 是随震级变化的近距离饱和项。它正是日本资料中可替换原 GSTSL 简单 `log(Delta)` 和任意 `1 km/3 km` 工程截断的候选结构，但其系数不能脱离原数据范围单独复用。

原始数据为 `554` 个事件、`27,531` 条记录，范围是：

```text
I: 0.5-7.0
Mj: 5.0-8.2
X: 1-500 km
h: 0-183 km
```

总标准差 `0.701`，其中事件内 `0.601`、事件间 `0.360`。约七成记录是计测震度，其余包含历史体感震度；训练还对远距离低震度记录做了阈值删选。因此它适合做日本直接震度基线，但不能代替只用现代计测震度重新拟合和留出验证。

岩切等（2012）给出关键外部验证：

- `Mj >= 6.0` 时，`100 km` 内残差均值接近零，距离依赖很小。
- `Mj 5.0-5.9` 时，近距离残差仍有距离依赖；约 `15 km` 内以过预测为主，样本中很多来自 2004 年新潟县中越地震余震。
- `30 km` 内四种被比较方法总体精度相近，不存在一条式子在所有近距离事件上绝对占优。

因此第一轮实验应同时做“原系数复现”和“同函数形式重新拟合”，不能只跑原式后直接接入生产。

## 深度项的物理意义和限制

松崎式中的 `+0.0155 h` 表示在其混合数据集中，当 `Mj` 和所定义距离相同，较深事件的平均震度更大。论文用深度项同时改善了板间、板内和陆壳事件的平均拟合，但这不等于深度越深总会越强，也不等于该项能单独、稳定地反演深度。

深度还会通过三维源到站距离改变 `X`。如果候选搜索同时改变震中、深度和事件规模，`Mj`、`X`、`h` 三项会相互补偿，必须用独立验证检查深度可辨识性，不能只看最小训练误差。

气象厅 2024 资料指出司・翠川式主要由约 `50 km` 以浅事件确定，深源事件会被高估；业务上震源深度大于 `150 km` 时不预测震度。这个 `150 km` 是业务适用限制，不是把候选深度截成 `150 km` 的反演规则。

Iwakiri 等（2011）为估计测站场地修正，曾在一个指定近海区域把目录中 `>10 km` 的可疑深度移到 `10 km`。论文明确把它作为当时近海台网方位覆盖不足导致的目录清理。实验 1 不采用该处理作为实时深度规则，更不能据此把所有候选深度固定为 `10 km`。

## 场地项：逐站长期残差优先于直接扣 ARV

Iwakiri 等（2011）与实验 1 当前方向直接对应。论文不是从观测震度中简单减去一个 ARV 项，而是：

```text
预测 PGV 与由观测震度反推的 PGV 之比
-> 修正深源异常震域
-> 每个事件调整 M，剥离事件间源项偏差
-> 汇总每个测站的长期残差
-> 得到测站经验增幅修正
```

其数据条件包括 `Mj >= 4.0`、深度不超过 `120 km`、震源距不超过 `300 km`、每事件至少 `5` 条观测；为减小低震度残差的距离依赖，场地估计只使用计测震度 `>=2.5`。最终得到 `1,258` 个测站修正，约覆盖当时全国三成测站；它与地形推定 ARV 的相关系数仅 `0.30`，在后四年验证中将预测震度 RMS 误差改善约 `15%`。

这支持实验 1 先估计 `stationBias`，但必须同时剥离事件源项、异常震域和距离残差。若直接把同一事件整体偏强或近断层破裂方向效应写入测站偏差，就会把非场地效应永久固化到站点。

Ogiso 等（2016）的频率相关场地修正作用于实时波形，并通过因果数字滤波处理站间频谱差异。它适合未来使用三分量波形或直接波形传播预测的实验，不适用于只有 `jma_s` 标量时序的当前输入，不能伪造频谱后套用。

## 误差与可达到精度

Hoshiba 等（2010）在当前 JMA EEW 框架下估计：

```text
以 Mj 表示源项时的不确定性：约 0.29 个 JMA 震度单位
以事件观测震度平均表示源项时：约 0.22 个 JMA 震度单位
用单一标量表示场地项时：约 0.21 个 JMA 震度单位
```

这些是预测震度组成项的不确定性，不是震中公里误差、候选评分或置信概率。实验报告可以用它们判断残差是否已接近模型固有限制，但不能直接把 `0.29` 写成震中搜索阈值。

## 对 GSTSL 核心的具体迁移

| GSTSL 部分 | 日本实验 1 处理 |
|---|---|
| 每站事件烈度 `I_i` | JMA 标定用官方一位小数最终计测震度；实时用 NIED `jma_s` 事件内真实峰值，另行验证两者偏差 |
| 区域衰减式 | 首先复现松崎直接震度式；再用现代 JMA 数据重新拟合同函数形式 |
| 每站反解震级 `M_i(P)` | 松崎式中 `M` 同时出现在一次项和对数饱和项，不能代数直接解；对每站做有界一维数值求根 |
| 距离 `Delta_i` | 浅源点震源基线用三维震源距；有可靠有限源定义的对照实验才使用断层最短距离 |
| 深度 | 作为候选维度和显式公式项；单独报告深度可辨识性，不默认 `10 km` |
| 近距离 | 使用模型自身的震级相关饱和项；不额外引入来源不明的 `1 km/3 km` 截断 |
| 场地 | 先估计剥离事件源项后的逐站长期残差；ARV 作为解释变量和无历史站回退候选 |
| 候选误差面 | 保留每站反解源规模的一致性误差；另报告计测震度前向残差，二者不得混为公里误差 |
| 置信轮廓 | 必须用日本事件、相同选站和相同模型重新标定 |

## 需要执行的对照实验

1. 原始松崎 2006 系数复现，验证 2020-2022 JMA 现代计测震度上的事件级误差。
2. 固定松崎函数形式，仅在训练年重新拟合系数；验证年选型，测试年保持冻结。
3. 气象厅 2024 PGV 业务链复现，明确只在其震级、深度和震度适用范围内比较。
4. 不加场地项、使用地形 ARV、使用逐站经验残差三组对照；逐事件剥离源项后再估站点项。
5. 按 `Mj 5.0-5.9 / >=6.0`、`0-15 / 15-30 / 30-100 km`、浅源/深源、陆上/近海分别报告。
6. 对震中、深度和事件规模做剖面误差面，检查联合搜索是否存在无法区分的长谷，而不只输出单个最优点。

在完成这些实验前，不修改生产震源算法，也不把任何论文原系数称作已经适配 NIED 实时输入。
