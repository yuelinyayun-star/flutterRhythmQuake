# 松崎 2006 公式在 JMA 2020-2022 数据上的前向基线

## 目的

本基线只回答：在使用 JMA 目录震中、目录深度和目录震级时，松崎・久田・福岛
（2006）式（12）对现代 JMA 一位小数计测震度的前向残差是多少。

本次没有搜索震中、深度或震级，也没有加入场地修正、事件源项修正、距离权重或置信
轮廓。

## 运行方法

```text
dart run tool/matsuzaki_2006_jma_baseline.dart
```

完整输出：

```text
.dart_tool/matsuzaki_2006_jma_baseline/report.md
.dart_tool/matsuzaki_2006_jma_baseline/report.json
```

JSON 保存每站的站码、三维点震源距、观测计测震度、预测震度和残差。

## 固定选择规则

- 年度资料：2020、2021、2022 JMA 最终震度归档。
- 震级范围：`5.0 <= Mj <= 8.2`。
- 震级类型：只允许 JMA 类型 `D/d/V/v`；`W` 不输入 `Mj` 公式。
- 深度范围：`0-183 km`；公式深度项在 `100 km` 封顶。
- 距离范围：`1-500 km`，超出范围的站排除，不夹值。
- 距离定义：目录震中与测站的大圆距离和目录深度组成的三维点震源距。
- 每事件最低有效站数：`10`，沿用松崎论文建模数据条件。
- 含 `alternateHypocenters` 的复合记录全部排除，因为当前年度 JSON 没有保存每条站点
  记录与各备选震源之间的明确关联。
- 未出现在 JMA 归档的站不当作震度 0。

残差定义：

```text
residual = observed instrumental intensity - predicted intensity
```

正残差表示公式低估震度，负残差表示公式高估震度。

| `Mj 6.0-8.2` | 5509 | +0.138 | 0.483 | 0.619 |

年份分组平均残差为 2020 `+0.105`、2021 `+0.309`、2022 `+0.350`。各年事件组成
不同，当前结果不能单独证明模型发生了时间漂移。

## 可以确定的结论

1. 原系数在这批条件样本上的测站加权 RMS 为 `0.661`，与原论文报告的总标准差
   `0.701` 数值接近；两批数据、距离定义和选站规则并不相同，不能据此宣称已经复现
   原论文精度或模型已经适配现代 JMA。
2. 全体平均残差为正，原式整体偏低估现代归档测站震度。
3. `15-30 km` 的平均残差为 `-0.957`，原式在该分组明显偏高估；这与岩切等
   （2012）指出的近距离残差问题方向一致。但 `1-15 km` 只有 22 个站、`15-30 km`
   只有 161 个站，必须扩充事件后再决定修正形式。
4. 浅源 `0-30 km` 的 RMS 最大，为 `0.846`；不能用同一个全局截距直接解释全部
   深度分组。
5. 接受事件全部为 `D` 类型，因此本次没有验证 `V/v/d` 类型，也没有依据建立震级
   类型转换。
6. 当前全部使用点震源三维距离。较大事件尚未使用断层最短距离，因此不能把大震分组
   当作有限断层模型验证。

## 反解中发现的结构问题

松崎式在近距离不是全局单调函数。例如 `X=15 km` 时，震度对震级的转折点约为：

```text
Mj = 7.3281701892
```

某些观测震度在 `5.0-8.2` 范围内会对应两个有效 `Mj`。实现已经返回全部根并标记
`solvedAmbiguous`，没有私自选择高震级或低震级分支。

因此下一步候选震源评分必须比较：

1. 保留全部每站根，在各站根集合之间寻找共同震级簇；
2. 在每个候选经纬度和深度下，直接优化一个共同 `Mj` 的前向震度残差。

在这两种方法通过合成事件和 JMA 留出事件比较前，不能把松崎式直接塞进原
`GstsReconstructor` 的单值 `M_i` 接口。
