# 松崎式未知事件联合反演

## 状态

日期：2026-07-30

当前已经实现独立实验用的候选点震源联合搜索，并完成合成事件行为测试。尚未完成历史
事件端到端盲测、置信标定或生产接入。

## 距离语义

历史前向标定可以在具有事件专属、来源可复现的破裂模型时使用有限断层最短距离。
未知事件推理时没有已观测破裂面，因此联合反演固定使用：

```text
候选纬度、候选经度、候选深度
-> 候选点震源到测站的三维震源距
-> 候选共同 Mj
-> 逐站预测计测震度
-> 真实震度 RMS
```

`candidatePointSource` 是推理时可计算的候选几何，不表示真实强震一定是点源，也不允许
给未知事件套用历史事件的有限断层面。混合距离标定系数用于纯点源实时搜索时的迁移误差
仍需通过独立历史回放量化。

## 显式输入

`Matsuzaki2006JointInverter` 不自行选择衰减模型，调用方必须传入明确的
`Matsuzaki2006AttenuationModel`。实验中可明确选择论文原系数，或已归档的
`finiteFaultSemanticFrozen2017` 系数。

归档输入构建器还要求显式给出连续计测震度下界。2010-2019 原始 JMA 记录已确认当前
条件域为 `>=0.5`；低值拒绝并计数，不钳值。联合反演器本身不偷偷应用来源阈值，直接
调用时仍由调用方保证观测域一致。

每次搜索还必须显式提供：

- 初始经纬度边界；
- 不得越过的经纬度硬边界；
- 深度上下界；
- 每一级经度、纬度和深度步长；
- 水平边界扩展距离和最大扩展次数；
- 最大候选评价数；
- 最少观测站数；
- 等价最优解的 RMS 容差；
- 分辨率诊断使用的 RMS 增量；
- 共同震级的一维搜索参数。

搜索还可提供以来源独立锚点为圆心的公里径向硬约束。经纬度矩形是圆形网格的枚举
外框，圆外候选不评分、不计入候选预算；最低误差靠近圆周时返回
`radialMaximum` 硬边界，不能视为收敛。

这些参数没有被写成未经标定的生产默认值。

## 搜索行为

第一级在当前显式边界内穷举完整经纬度和深度粗网格。后续层只围绕上一层多个低 RMS
种子做局部细化；种子数量和相对最低值的 RMS 增量都由每层参数显式给出。每个三维
候选调用已有前向评分器，在论文 `Mj` 数值域内搜索一个或多个共同震级局部最小值。

候选最低点接触当前水平边界时，只扩展被接触的一侧，且不得超过硬边界或扩展次数。
扩框后丢弃该轮局部结果，从扩展后的完整粗网格重新开始，再累计真实候选预算。这样
不会把局部细化范围内的最低点冒充全局最低点，也不依赖目录震中或目录深度。

在开始一个搜索阶段前会先计算该阶段完整候选数。若超过剩余预算，阶段不会被部分执行，
结果返回 `candidateBudgetExceeded`，防止把被截断的网格误报为最低点。

## 结果状态

| 状态 | 含义 | 可否视为收敛 |
|---|---|---|
| `solved` | 唯一等价最优候选，且未接触硬边界 | 是 |
| `multipleEquivalentSolutions` | 容差内存在多个真实等价候选 | 是，但必须保留多解 |
| `hardBoundaryReached` | 最优候选接触经纬度、深度或径向硬边界 | 否 |
| `expansionLimitReached` | 最优候选仍接触可扩展边界，但扩展次数用完 | 否 |
| `candidateBudgetExceeded` | 下一完整阶段超过显式计算预算 | 否 |
| `insufficientObservations` | 观测站数未达到显式门槛 | 否 |
| `noValidCandidate` | 全部候选违反公式距离域或无法得到共同震级 | 否 |

`hasSolution` 只表示结果中保留了当前候选，不能代替收敛判定；接入方必须使用
`isConverged` 和完整状态。

## 深度和分辨率边界

结果保留显式 RMS 增量内所有网格候选，并报告其经纬度、深度和震级最小值/最大值。
该 `resolutionEnvelope` 只说明当前网格和人为指定 RMS 增量下的近优范围：

- 不是概率；
- 不是置信区间；
- 不能称为准确率；
- 深度范围宽时不能只显示最低点的单一公里数；
- 最优深度接触上下界时必须返回 `hardBoundaryReached`。

真正的震中、深度和震级置信范围仍需使用完全隔离的训练/验证事件标定。

## 当前验证边界

合成测试直接用衰减式生成未修改的逐站震度，再只向反演器提供测站坐标和震度。测试
覆盖三维震源与震级恢复、水平自动扩展、经纬度硬边界、深度硬边界、镜像多解、扩展
上限、无有效候选、候选预算和站数不足。

该测试证明搜索器与前向公式在自洽数据上可以闭环，不证明真实 JMA/NIED 事件的定位
精度。下一步必须先冻结历史端到端评价门槛，再使用未参与系数选择的事件进行回放。

## 候选评分性能

候选搜索开始时已经对观测站 ID、坐标、最少站数和搜索规格做一次完整校验。此前每个
候选点又重复执行相同的整批校验，并对已验证的候选/测站坐标重复范围校验。联合反演
现仅在这个已经验证的内部循环中调用 `scorePrevalidated`：它保留完全相同的 JMA 观测、
点源三维距离、前向衰减式、震级扫描、黄金分割细化和距离域拒绝；公共 `score` API
仍执行完整输入校验。

2019 已打开审计年、300 站、44 个事件的前后回归逐事件比较中，两套模型的候选坐标、
深度、震级、RMS、等价解、边界状态和候选计数全部一致。总评分时间从论文原系数的
`111.051 s` 降到 `88.936 s`（`1.25x`），冻结 2017 有限断层语义系数从 `102.594 s`
降到 `83.028 s`（`1.24x`）。这只是已验证输入的重复检查消除，不是算法精度改动，
也不作为重新选择任何 2019 审计参数的依据。

## 冻结站项接入

联合反演器现在可以显式接收 `Matsuzaki2006StationBiasModel` 和
`Matsuzaki2006StationBiasShrinkage`。当观测站 ID 与训练站 ID 相同且经纬度精确匹配时，
前向值为：

```text
predicted_intensity = point_source_model_intensity + b_shrunk(station)
```

没有训练项的站、坐标冲突站和未知站都使用原始前向值，不补震度，也不把缺失站当作零值。
未提供站项模型时，联合反演路径与此前完全一致。当前冻结候选是训练 2010-2016、2017
选择的 `minimumTrainingEventCount=2, k=2`，但尚未在新的最终留出人口上做端到端盲测。
