# 大阪府北部地震的独立有限断层几何判定

日期：2026-07-29

状态：根据余震重定位、震源机制、强震全波形和 GNSS 反演方法说明，选择
`gnss_double_rectangle_union` 作为松崎式距离语义的优选物理几何；单矩形继续保留为
低分辨率 GNSS 简化诊断。判定不使用 2018 震度残差，不接生产。

## 判定问题

2018 冻结评估同时保留：

```text
gnss_single_rectangle
gnss_double_rectangle_union
```

两者都能产生可计算距离，但松崎式的 `X` 在目标强震中要求实际破裂面的最短距离。
因此要判断的不是“哪个震度残差更低”，而是哪种几何更符合独立震源结构证据。

本判定在已经查看 2018 冻结残差后才正式记录，不能表述为盲选。为了避免结果倒推，以下
判据只使用论文中预先存在的余震、波形、震源机制和测地反演方法，不使用任何本实验的
震度残差、RMS、系数或候选排序。

## 证据一：余震重定位和震源机制

Kato 与 Ueda（2019），DOI：<https://doi.org/10.1186/s40623-019-0995-9>。

正式出版社全文于 2026-07-29 重新核实。双差重定位和匹配滤波显示两个不同的平面：

- F1：北北西-南南东走向，向东倾约 45-50 度的逆断层；
- F2：东北东-西南西走向，向东南倾 70-80 度的高角横滑断层；
- 主震在 F1 起裂，约 0.3 秒后传播到相邻 F2；
- 两种几何随后同时动态破裂；
- 两个平面看起来不相交，但这不影响使用两个有限面并集的最短距离。

论文用两个双力偶矩张量组合解释主震 CMT，最优组合为：

```text
F1: strike=345°, dip=50°, rake=85°, Mw 5.3
F2: strike=60°,  dip=80°, rake=160°, Mw 5.5
```

这不是由本实验震度拟合得到的结论。

## 证据二：独立强震全波形与余震矩张量

Hallo 等（2019），DOI：<https://doi.org/10.1186/s40623-019-1016-8>。

该研究对主震强震记录做 Bayesian 全波形反演，并分析 108 个主要余震。主震矩张量具有
显著 CLVD 成分，分解结果对应横滑和逆断层组合；余震矩张量也同时出现这两种机制。
作者明确认为横滑和逆断层的联合剪切运动都对主震总地震矩有显著贡献。

因此单一高角横滑矩形不能完整代表主震破裂面。

## 证据三：GNSS 单/双模型的实际含义

西村、桥本、藤原（2020）：
`references/papers/2020_DPRI_2018_northern_Osaka_crustal_deformation_fault_model.pdf`。

正文第 3.1 节明确说明：震源附近没有 10 km 内 GNSS 连续站，地震位移只有数毫米，
接近检测极限；GNSS 数据本身没有分辨全部断层参数的能力。

因此：

- 单矩形模型固定 F-net 的东北-西南节面，只估计位置、滑动角和滑动量，是低分辨率
  数据条件下的简化反演；
- 双矩形模型的走向和倾角固定为强震波形反演采用的两套断层参数，再由 GNSS 估计位置
  和滑动；
- 作者明确写明地震波和余震分析已经表明两条断层都发生运动；
- 单、双模型都能大致解释稀疏 GNSS 位移，不意味着两者具有相同的震源结构真实性。

当前双矩形参数为：

```text
横滑面: strike=52°,  dip=77°, rake=151°
逆断层: strike=351°, dip=50°, rake=90°
```

它们分别接近 Kato 与 Ueda 的 F2 `60°/80°/160°` 和 F1 `345°/50°/85°`，属于相互
独立的数据类型对同一双断层拓扑的支持。

## 判定

```text
优选物理几何 = gnss_double_rectangle_union
保留诊断几何 = gnss_single_rectangle
判定依据 = 独立震源结构证据
禁止依据 = 2018 震度残差或 RMS
```

双矩形联合更符合实际破裂包含 F1 逆断层和 F2 横滑断层的事实。单矩形主要近似 F2，
遗漏了有独立波形、余震和矩张量支持的 F1，因此不适合作为松崎式强震断层最短距离的
唯一几何。

## 仍然存在的不确定性

本判定解决的是“一条还是两条断层”的拓扑选择，不表示 4 km x 4 km 矩形边界完全无
误差。GNSS 论文指出均匀半空间忽略沉积层可能使反演深度偏浅，且 GNSS 对全部参数的
分辨率有限。因此：

- 双矩形联合可以作为当前来源支持最强的距离几何；
- 单矩形继续保留，便于量化几何简化敏感性；
- 不根据 2018 残差调整矩形位置、尺寸、走向或倾角；
- 不把双矩形选择解释为对 2018 冻结评估的重新选模；
- 不回调已冻结的衰减系数。
