# 松崎式 2019 联合反演：站数饱和性实验

## 预声明边界

本实验只复用已打开的 2019 审计年，不打开新的最终留出年份，不修改年度 JSON、原始逐站
连续计测震度或测站坐标。目录真值只在每个事件的未知输入构建、候选搜索和共同震级完成
之后，用于事后误差汇总；它不进入锚点、选站、搜索边界或候选评分。

此前 `10 / 30 / 100` 对照已经证明 30 站不足，100 站仍截断 26/44 个事件。为避免根据
中间结果继续追加档位，本轮在读取新结果前固定以下上限：

```text
maximumObservations = 100 / 200 / 300 / 500 / 1000
```

2019 已知最大域安全站数为 951，因此 `1000` 表示每个事件保留所有可用域安全站，而不是
截断后的近似全量。所有档位只按原始连续计测震度从高到低保留站点，且均固定：

| 项目 | 固定值 |
|---|---:|
| 初始 / 硬水平圆半径 | 100 / 250 km |
| 深度范围 | 5-100 km |
| 连续计测震度下界 | 0.5 |
| 最低站数 | 10 |
| 网格层级 | `0.5 deg/20 km -> 0.1 deg/10 km -> 0.025 deg/5 km` |
| 细化种子 | 最多 6 |
| 候选预算 | 30000 |
| 前向模型 | 论文原系数、冻结 2017 有限断层语义系数 |

评价时使用等价最优候选中的最大震中/深度/震级误差，避免根据目录真值从同分解中选择最有利
候选。`RMS + 0.05` 分辨率包络只作网格诊断，不作为置信区间。

## 决策规则

本轮不根据 2019 的最小误差直接挑选站数，也不把单一档位的运行速度当成科学结论。只有在
以下事实都同时明确后，才讨论冻结上限：

1. 1000 站全量档位是否仍显著改变误差或边界状态；
2. 增量档位是否出现稳定的平台，而不是单一模型或少数事件的偶然改善；
3. 单事件运行时间、候选预算状态和内存行为是否能满足后续实时/回放目标；
4. 深度边界问题不能被误写成“站数已经解决”。

本文件将在全部预声明档位完成后记录结果和结论。当前不接生产。

## 结果

| 上限 | 实际站数中位 | 截断事件 | 论文原系数：震中中位/P90 km | 冻结语义系数：震中中位/P90 km |
|---:|---:|---:|---:|---:|
| 100 | 100 | 26 | 70.270 / 188.845 | 63.458 / 126.749 |
| 200 | 196 | 22 | 39.301 / 174.484 | 45.183 / 130.835 |
| 300 | 196 | 14 | 38.965 / 162.736 | 39.983 / 122.282 |
| 500 | 196 | 9 | 39.142 / 162.736 | 39.983 / 122.282 |
| 1000（全量） | 196 | 0 | 39.142 / 162.736 | 45.136 / 122.282 |

两个模型都没有出现候选预算耗尽。深度硬边界接触数（深度下界和上界合计）从 100 站的
`25/25` 降到 300 站的 `23/23`，500 站的 `21/21`，全量时为 `19/21`；因此增加站数能
让少数事件由边界状态转为内部解，但仍没有解决深度-共同震级混淆。

## 运行成本

| 上限 | 论文原系数 P50/P90 ms | 冻结语义系数 P50/P90 ms |
|---:|---:|---:|
| 100 | 724.0 / 945.6 | 718.0 / 945.3 |
| 200 | 2495.5 / 3960.2 | 2445.5 / 4005.4 |
| 300 | 2421.5 / 5062.9 | 2319.5 / 4329.2 |
| 500 | 2637.5 / 5808.5 | 2212.5 / 5947.8 |
| 1000（全量） | 2609.5 / 9741.3 | 2273.5 / 7373.9 |

站数中位数从 200 档起已是 196，因此大部分事件成本接近；P90 和最大耗时揭示了高站数
事件的真实代价。全量 1000 站的 P90 明显上升，并没有对应的总体误差下降。

全量相对 500 新加入站的 9 个事件也不是单向改善：论文原系数中有两个边界事件的震中
误差下降（例如 `23.275 -> 13.952 km` 和 `47.063 -> 26.784 km`），但亦有事件从
`35.072 -> 49.111 km`；冻结语义系数同样同时存在改善和变差。故“全部观测站”在这个
条件观测模型下不能被当作无条件更优。

## 结论

`maximumObservations = 300` 是已打开 2019 审计年中的最小预声明平台候选：相对 200，
它同时改善两套模型的中位和 P90 震中误差；继续到 500 或全量没有稳定总体收益，却增加
高站数事件的 P90 成本。后续未知事件端到端协议可将 300 作为**冻结候选输入上限**。

这不是生产性能目标，也不是最终盲测结论。它仍截断 14/44 个已打开审计事件，深度边界
问题仍存；最终是否采用只能由隔离留出人口的端到端评价决定，不能因 2019 审计表现再调
上限或搜索参数。
