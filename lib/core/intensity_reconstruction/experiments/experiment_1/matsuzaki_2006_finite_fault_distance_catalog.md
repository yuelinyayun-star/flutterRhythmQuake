# 松崎式统一有限断层距离目录

日期：2026-07-29

状态：6 个有来源几何且有点源近场站的事件已从原始 JMA 年度数据重建统一距离目录。
目录同时保留 213 个近场诊断配对/311 条变体记录，以及 8221 个全部接受站配对/
9711 条变体记录。既有 311 条记录与 6 个单事件诊断逐站零差异。目录不拟合系数；
大阪优选双矩形联合由独立震源结构证据决定，不使用震度残差；不接入生产。

## 目的

先前大阪、熊本、鸟取、茨城、2014 长野和福岛诊断分别运行，能够确认单事件距离，
但不能直接形成重标定输入。本目录统一以下语义：

```text
输入 = 未修改的 JMA 年度 JSON
基线 = Matsuzaki2006JmaBaselineEvaluator 严格接受事件和测站
近场诊断人口 = 既有 JMA 点震源距 <30 km
完整距离人口 = 6 个目标事件的全部严格接受站
有限断层距离 = 地表测站到有来源有限断层矩形联合表面的最短三维距离
论文可评价域 = 1-500 km
域外处理 = 保留真实几何距离，只标记不可代入衰减式，不钳值
```

目录工具：

```text
tool/matsuzaki_2006_finite_fault_distance_catalog.dart
```

机器报告：

```text
.dart_tool/matsuzaki_2006_finite_fault_distance_catalog/report.json
.dart_tool/matsuzaki_2006_finite_fault_distance_catalog/report.md
```

## 原始输入


只用于输出后的独立交叉验证。

## 逐站交叉验证

6 个单事件诊断全部使用同一原始年度文件重新运行，再按
`eventId + stationId + geometryVariantId` 比较统一目录：

```text
catalog records = 311
compared records = 311
missing records = 0
maximum finite-fault distance absolute difference = 0.0
maximum point-source distance absolute difference = 0.0
maximum observed-intensity absolute difference = 0.0
```

这证明统一目录没有因复制模型参数、测站排序或变体展开而改变既有诊断输入。

## 当前边界

目录已具备 2010-2016 有限断层距离语义重标定输入：

- 2010-2016 的五个目标事件均只有一个已审计几何，全部接受站使用断层最短距离；
- 其余校准事件继续使用点震源距，不能把训练源项缩成五个事件；
- 2017 没有需要替换的已接受候选，因此验证集继续使用点震源距；
- 大阪属于已经打开的 2018，不能参与系数拟合或按震度残差选几何；独立余震重定位、
  全波形和 GNSS 方法证据支持双矩形联合为优选物理几何，单矩形保留为简化诊断；
- 3 条 `<1 km` 记录没有论文公式支持，场景评估时必须保持排除；
- 胆振曲面模型没有当前点源近场站，不应为了加入模型而改变选站定义；
- 复合 JMA 记录仍因逐站震源不可分配而隔离。

共享覆盖实现见 `matsuzaki_2006_source_backed_distance_overrides.dart`。重新标定和 2018
冻结分支结果分别见 `matsuzaki_2006_finite_fault_semantic_calibration_2017.md` 与
`matsuzaki_2006_finite_fault_frozen_2018_evaluation.md`。大阪独立几何判定见
`matsuzaki_2006_osaka_independent_geometry_selection.md`。
