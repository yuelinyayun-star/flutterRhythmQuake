# 松崎式福岛县中通 M6.4 有限断层距离诊断

日期：2026-07-29

状态：JMA 修订近地强震波形有限矩形和固定系数距离诊断完成；未重新拟合，未接入生产。

## 输入事件

JMA 原始 2011 年度记录中的目标事件为：

```text
eventId = 2011041214074228-37.0525-140.6435
区域 = 福島県中通り（rawRegionHex 按 Windows-31J/CP932 解码）
originTime = 2011-04-12T05:07:42.28Z
JST = 2011-04-12 14:07:42.28
Mj = 6.4
JMA 目录深度 = 15.08 km
最大震度代码 = C（震度 6 弱）
严格接受站 = 1339
点源距 <30 km 测站 = 14
```

诊断直接读取未修改的 `jma_final_intensity_2011.json`，不修改逐站观测震度、事件震级、
JMA 目录深度、基线筛选或系数。近场站仍按既有点震源距 `<30 km` 固定，只替换松崎式
（12）的距离 `X`。

## JMA 来源模型

JMA 震源过程目录单独收录目标事件，不使用 4 月 11 日福岛县浜通 `M7.0` 的模型，也不
用整个余震云代替有限边界。目标事件键为 `2011041214074228near`：

- PDF：<https://www.data.jma.go.jp/eqev/data/sourceprocess/event/2011041214074228near.pdf>
- 原始数据：<https://www.data.jma.go.jp/eqev/data/sourceprocess/data/2011041214074228near.zip>

本地原始文件及 SHA-256：

```text

```

ZIP 的 `01event.txt` 和 `02fault.txt` 给出：

```text
last updated = 2017-03-13
type = near01
fault plane count = 1
strike = 170 degrees
dip = 40 degrees
rake = 58 degrees
rupture start = 37.0525 N, 140.6438 E, depth 15.51 km

Worg = 5
subfault size = 2 km x 2 km
grid = 7 x 6
rupture speed = 2.0 km/s
Mw = 6.03
maximum slip = 2.48 m
```

42 个子断层全部为 `Mark=1`，所以有效有限边界就是完整的 `7 x 6` 连续网格，即
`14 km x 12 km`。这里没有 2014 长野事件那样需要排除的 `Mark=0` 假定单元。

`Xorg=3/Worg=5` 对应行的中心坐标和破裂起点完全一致，因此内部锚点为：

```text
沿走向偏移 = (3 - 0.5) * 2 = 5 km
沿下倾偏移 = (5 - 0.5) * 2 = 9 km
下倾方位 = 170 + 90 = 260 degrees
```

几何代码派生的上缘深度为 `9.724912 km`。这是由来源参数透明计算的值，不是 JMA
单独报告值。JMA PDF 图面确认星号为破裂起点，主要滑移在起点附近浅部和东南侧；
图中的灰点是 `2011-04-11 14:07` 至 `2011-04-13 07:00` 的 DD 余震分布，只用于解释
断层参数背景，不参与数值边界构造。第二页是 26 个反演站的观测/理论波形对照。

PDF 2016 年暂定说明正文写 `MJMA 6.3`，而 2017 年修订 ZIP 的 `M=6.4`、JMA 震源过程
目录和实验年度原始记录均为 `6.4`。诊断保留年度输入 `Mj 6.4`，不以旧 PDF 显示值
覆盖原始数据。

JMA 年度目录深度 `15.08 km` 继续用于衰减式深度项；反演破裂起点深度 `15.51 km`
只用于有限断层几何。二者语义和来源不同，没有互相覆盖。

## 固定系数结果

14 个站的有限断层距离全部位于论文 `1-500 km` 数据域内，因此没有距离下限钳制或
域外排除。

| 距离 | 最小 km | 平均 km | 最大 km |
|---|---:|---:|---:|
| JMA 目录点震源 | 17.549385 | 25.684149 | 29.783187 |
| JMA 有限矩形 | 12.383877 | 20.984921 | 27.421575 |

13/14 个站的距离缩短，1 个站增加 `0.234091 km`；平均缩短 `4.699229 km`。

| 系数/距离 | 平均残差 | MAE | RMS |
|---|---:|---:|---:|
| 论文原系数 + 点震源 | -0.021962 | 0.450534 | 0.557030 |
| 论文原系数 + 有限断层 | -0.272121 | 0.413841 | 0.500256 |
| 2017 冻结系数 + 点震源 | +0.672418 | 0.683255 | 0.877076 |
| 2017 冻结系数 + 有限断层 | +0.495825 | 0.544694 | 0.680245 |

论文原系数 RMS 改善 `10.19%`，但逐站只有 6/14 个绝对残差改善、8/14 个恶化；有限
断层使平均残差从接近零移到 `-0.272121`。2017 冻结系数 RMS 改善 `22.44%`，逐站
10/14 个改善、4/14 个恶化，但仍有 `+0.495825` 的平均残差。

## 结论和边界

目标事件有独立、完整且可复现的 JMA 有限矩形，能够进入统一距离目录。两套固定系数的
RMS 都因有限断层距离改善，进一步证明点震源距离是当前迁移实验的实际缺项；但原系数
逐站多数恶化，且两套模型仍存在方向相反的系统平均残差，说明旧点源标定已经吸收了
距离语义错误和其他事件/测站差异。

因此本结果不单项接入生产、不回调 2018 选择，也不据此重选系数。继续补齐剩余候选，
统一有限断层距离语义后再重新标定。
