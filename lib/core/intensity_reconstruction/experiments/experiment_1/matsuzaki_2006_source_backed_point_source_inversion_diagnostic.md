# 有来源有限断层事件的点源联合反演诊断

日期：2026-08-21

## 目的和边界

本诊断将六个已有独立有限断层几何来源的事件，按未知事件处理，只把未修改的 JMA
逐站计测震度和测站坐标送入候选点源联合搜索：

```text
原始 JMA 观测 -> 最高震度测站锚点 -> 候选点源三维距 -> 共同 Mj -> RMS
```

搜索期间不读取有限断层几何，也不读取目录震中、深度或震级来构造输入。目录真值只在
搜索完成后用于事后误差统计，因此这不是有限断层搜索，也不是新的盲测；2011/2014/2016
属于已打开的来源几何与校准资料，2018 属于已打开冻结评估年。

工具：

```text
tool/matsuzaki_2006_source_backed_point_source_inversion_diagnostic.dart
```

固定协议：最多 300 个站、原始连续计测震度 `>=0.5`、初始 100 km、硬半径 250 km、
深度 5-100 km、三阶段 `(0.5°,20 km) -> (0.1°,10 km) -> (0.025°,5 km)`，最多
30000 个候选；不使用冻结站项，也不使用有限断层几何。

机器报告：

```text
.dart_tool/matsuzaki_2006_source_backed_point_source_inversion/report.json
.dart_tool/matsuzaki_2006_source_backed_point_source_inversion/report.md
```

## 结论

1. `finiteFaultSemanticFrozen2017` 在福岛、长野、鸟取和大阪的水平误差小于同事件的
   `published` 对照，但在 2011 福岛、2014 长野、2016 熊本、大阪等事件同时出现更低
   深度边界接触或震级误差，不能按 RMS 单项选择。
2. 12 次运行中，`published` 有 3 次硬边界，冻结系数有 5 次硬边界。冻结系数确实能
   改变目标面，但没有解决深度可辨识性；它把某些候选从错误的深度上界移到最低深度，
   这仍不是收敛。
3. 熊本是重要对照：原系数给出约 3.5 km 震中误差且状态为 `solved`，冻结系数震中
   误差约 6.1 km 且触及深度下界。不能把冻结系数视为未知事件的无条件升级。
4. 有来源有限断层事件上的点源反演只能证明迁移风险存在，不能证明应该把有限断层距
   写入未知事件搜索。未知事件仍没有可用的断层面。

下一步应固定输入和搜索规格，分别对候选位置固定剖面重估共同震级，比较深度变化时的
   RMS 曲线、点源与来源有限断层前向差异以及深度边界接触。该剖面只用于识别不可辨识
   状态，不用于调参或把边界候选标成收敛。
