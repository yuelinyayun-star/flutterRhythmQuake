# 算法实验 1：JMA 替换审计

## 审计目标

本文逐项回答：原 GSTSL 烈度反演中哪些数学结构可以保留，哪些物理量、参数和数据
必须使用日本/JMA 资料替换。这里记录的是实验边界，不是生产算法配置。

状态定义：

- `保留核心`：物理含义不因地区和震度体系改变；
- `已确认替换`：JMA 数据字段和替换方向已有直接依据；
- `必须重标定`：结构可比较，但原数值不能用于日本；
- `待验证`：存在多个合理定义，当前证据不足以选择；
- `禁止复用`：来源区域或数值域明确不适用于本实验。

## 逐变量迁移表

| 原算法量 | 原算法含义 | JMA 实验处理 | 状态 |
|---|---|---|---|
| `I_i` | 一次事件在地点 `i` 的事件级宏观烈度 | 标定使用 JMA 官方一位小数计测震度；实时候选为事件内每站 NIED `jma_s` 峰值实时震度 | 输入类型已确认；与最终计测震度的数值关系待验证 |
| 烈度点 | 宏观调查点或从等震线取得的点 | 使用有站码、坐标和真实观测值的 JMA 测站记录，不从等震线造点 | 已确认替换 |
| 烈度上下限处理 | 中国烈度 I-III 合并、X 以上压到 IX | 不采用；JMA 计测震度保留原一位小数 | 禁止复用 |
| `M` / `M_s` | 原区域衰减式所对应的震级 | 必须明确 JMA 震级类型；不能混用 `V/D/d/v/W` 后统一做同一转换 | 待验证 |
| `c0..c3` | 川滇或华北烈度衰减系数 | 用日本事件重新拟合，或采用来源和速度基准均核实的日本前向模型 | 必须重标定 |
| `Delta_i` | 候选震中到烈度点的二维震中距 | 震中距仍可作为浅源基线；深度模型需比较震源距或经验证的源到站距离 | 待验证 |
| 深度 | 原 GSTSL 不搜索、不进入公式 | 日本资料深度跨度大，不能默认为 10 km 或忽略；需浅源实验与深度感知实验分开 | 必须新增并验证 |
| 近零距离 | 对数模型要求距离大于零 | 不能擅自使用 1 km 或 3 km 截断；需由日本模型的饱和项、有限源定义或标定范围决定 | 待验证 |
| 场地项 | 原 2010 实际计算未校正 | 先拟合逐站长期残差；ARV 只作为候选解释变量，不默认从 NIED 实时震度扣除 | 必须新增并验证 |
| `M_i(P)` | 候选 `P` 下由每站强度和距离反解的等效震级 | 保留“每站反解共同事件规模”的含义；具体数值由 JMA 模型反解 | 保留核心 |
| `M_I(P)` | 所有 `M_i` 的未加权算术平均 | 作为忠实迁移基线保留；是否需要稳健中心量只在独立对照实验中判断 | 保留核心，统计性能待验证 |
| `W_i` | 原论文距离权重，参数为区域经验值 | 权重结构可作为基线比较；`a=0.1,b=1000 km` 和 `a=0.05,b=480 km` 均不得用于日本默认值 | 必须重标定 |
| `rms(P)` | 每站反解震级围绕 `M_I` 的加权离散 | 保留为候选一致性误差；单位是反解规模的离散，不是公里误差或 JMA 真值误差 | 保留核心 |
| `rms-min(rms)` | 将候选误差面最低点归零 | 保留用于候选面和等值线；不能把归一化值称为准确率或概率 | 保留核心 |
| 搜索网格 | 原论文区域内的规则候选点 | 使用适合日本经纬度范围的显式投影、边界和分辨率；海域不能因无陆地测站被删除 | 必须重标定 |
| 表 3 置信阈值 | 华北随机子采样得到的经验覆盖阈值 | 用 JMA 训练事件、JMA 模型和日本台网重新生成 | 禁止复用原表，必须重标定 |
| 测站数量档 | 原表按烈度点数量查阈值 | 按 JMA 有效测站数和事件类型重新标定；不能沿用 19 档或插值 | 必须重标定 |
| 缺测/未报告站 | 原宏观烈度资料没有统一实时缺测语义 | JMA 归档记录震度 1 以上站点；未列站和 `//` 缺测都不得自动当作震度 0 | 已确认替换规则 |
| 输出图 | 烈度震级、误差面、置信轮廓 | 输出每站原值/校正值、距离、`M_i`、残差、权重和候选真实误差面 | 已确认工程要求 |

## 当前可以直接确定的 JMA 输入

项目的 JMA 官方归档解析器已明确区分：

```text
intensityClass          <- 观测记录字段 19
instrumentalIntensity  <- 观测记录字段 21-22，一位小数
magnitudeType          <- 震源记录字段 55
depthKm                <- 震源记录深度字段
```

因此实验标定数据不能再使用以下替代物：

- Scratch 30 级；
- Yahoo `level`；
- JMA 类别区间中点；
- 人工递增的当前震度；
- 将缺失连续计测震度转换成 0。

离散类别仍有价值，但用途是检查计测震度分档是否一致、报告类别误差，以及评估实时
GIF 峰值最终落入哪个 JMA 类别，不作为连续回归的伪数值。

## 日本前向模型来源已恢复

日本资料已经恢复出两条必须分开验证的路线：

```text
气象厅现行业务链：
  Mj -> Mw -> PGV600 -> PGV700 -> 地表 PGV -> 预测计测震度

松崎等（2006）直接震度式：
  Mj + 断层最短距离/震源距 + 深度 -> 地表 JMA 震度
```

两条路线的完整公式、训练范围、近距离表现和已归档原文记录在
`japanese_forward_model_sources.md`。它们是并列实验候选，不表示当前已经选定生产模型。

松崎式可保留 GSTSL“候选位置下每站反解共同事件规模”的结构，但 `Mj` 同时出现在
一次项和震级相关饱和项中，每站 `M_i` 必须通过有界一维数值求根，不能沿用原川滇
公式的闭式反解。气象厅业务链则用于官方基准对照，不能对已经是实时震度的 NIED
`jma_s` 再执行一次 PGV-to-intensity 转换。

### NIED 实时输入的官方定义

NIED 官方把 `リアルタイム震度` 定义为防灾科研开发、逐次计算的参考震度，并说明它
与使用完整摇动记录计算的震度大致一致。最大速度则是加速度积分得到的速度每秒最大值。
二者是不同强震指标，因此：

```text
jma_s   已经是实时震度
vcmap_s 才是最大速度层
```

`jma_s` 不需要在客户端再次进行 PGV-to-intensity 转换。NIED 官方提到的 J-SHIS
地盘增幅率用于 EEW 预测震度分布的 5 km 网格，不足以证明观测站 `jma_s` 应直接
减去 `1.72 * log10(ARV)`。该直接校正已从实验默认设计撤回。

### 归档观测域限制

JMA 官方格式把 91-95 字段定义为“震度 1 以上的观测点数”，逐站字段 19 也只定义
`1-7/A/B/C/D/9`，没有震度 0。因此这些年度文件不是全台网完整震度场。

这对衰减拟合有直接影响：当前数据没有告诉模型同一事件中哪些未列站实际低于震度 1、
离线、缺报或不在当时台网。只用这些资料可以研究“已报告有感站之间的强度一致性”，
但不能把远距离未列站补成 0 后拟合完整衰减尾部。

实验必须在规格中选择并标明其中一种观测域：

```text
A. 归档条件模型
   训练和验证都只使用 JMA 归档列出的震度 1 以上站
   实时推理采用与其可比较的站点阈值

B. 完整台网模型
   另建包含事件时台网状态、低震度与缺测原因的数据集
   对未检出/低于阈值使用明确的删失模型或真实连续值
```

在完整台网数据取得前，不能宣称模型已经学到震度 1 以下的 JMA 衰减，也不能用
“未出现在归档”代替“观测震度为 0”。

## 必须分开的震级问题

现有 2020-2022 JMA 数据包含多个震级类型。字段 55 的类型信息不能在数据准备阶段
丢弃。实验必须在以下方案中通过来源和验证结果选择一种：

1. 只使用一个被确认适用于所选日本衰减模型的震级类型；
2. 使用有正式依据的类型转换，转换前后分别保留原值和类型；
3. 不宣称输出传统震级，只拟合事件共同源规模，再另行标定到目标震级。

在方案确定前，项目现有对所有数值统一执行 `Mw = magnitude - 0.171` 的做法不能进入
实验 1。

## 距离和深度不能一起含糊处理

原算法的 `Delta_i` 是二维震中距，且不估计深度。JMA 归档事件覆盖浅源到数百公里
深源，若把所有事件放入同一二维衰减式，深源事件的传播距离会被系统性低估。

实验至少需要两个可分辨的模型族：

```text
A. 浅源 GSTSL 基线
   只使用事先定义并冻结的浅源训练范围
   距离使用震中距
   用于检验原算法核心在 JMA 计测震度上的可迁移性

B. JMA 深度感知模型
   深度作为显式输入或候选维度
   距离定义由所选日本衰减模型决定
   单独验证浅源、板内深源、近海和陆上事件
```

这里尚未决定浅源深度上限、候选深度网格或最终距离定义；这些值必须由数据实验和
所采用公式的正式定义确定。

## 现有 JMA 风格实现的冲突

现有代码不能直接充当实验模型，因为至少存在以下不一致：

| 路径 | 距离处理 | 参考地盘到地表 | ARV |
|---|---|---|---|
| `IntensityCalculator` | 减半断层长度，最小 3 km | `PGV600 * 1.307` | 使用 |
| `JmaStyleIntensityPredictor` | 震源距最小 1 km | `PGV600 * 0.90` | 使用 |
| `source_estimator` 震级诊断 | 震源距最小 1 km | `PGV600 * 0.90` | 未使用 |

在采用传统 PGV 路径前，必须分别核实：

- 衰减式输出的 PGV 对应哪个速度基准地盘；
- ARV 表对应哪个速度基准和定义；
- `0.90` 与 `1.307` 各自转换的起点、终点和适用条件；
- 断层长度修正是否属于该公式，及其震级适用范围；
- 近距离 1 km/3 km 下限是来源规则还是工程保护；
- `M_JMA -> Mw` 转换适用于哪些震级类型和震级范围。

这些问题未解决前，可以拟合完全经验的 JMA GSTSL 基线做对照，但不能把某条现有
PGV 路径命名为“JMA 已验证模型”。

## 现有数据管线的具体缺口

对当前代码逐层核对后的结果如下：

| 层级 | 当前行为 | 对实验 1 的影响 |
|---|---|---|
| `JmaIntensityArchiveParser` | 保留基础强度、深度、震级 1 和类型；未保存震级 2/类型及震源质量字段 | 强度输入可追溯，震级统一和深度筛选信息不完整 |
| `JmaIntensityDatasetBuilder` | 清单保留无类型的 `magnitude`，没有写入 `magnitudeType`，资格规则也不按类型筛选 | 现有清单不能构建单一震级类型标定集 |
| `SyntheticRevealDatasetBuilder` | `truth` 保留 `magnitude`，再次丢弃 `magnitudeType` | 合成数据无法追溯震级定义 |
| `StaticIntensityEvent` | 只有 `double? magnitude`，没有类型字段 | 下游调用者无法阻止震级类型混用 |
| `JmaStyleIntensityPredictor` | 对传入的无类型数值统一执行 `Mw = magnitude - 0.171` | 对混合类型数据缺少适用依据 |
| `StaticAttenuationTrainer` | 不使用目录震级，逐事件拟合 `sourceScale` | 可作为强度场定位基线，但不能宣称输出 JMA 震级 |

现有年度拆分是 `2020=train`、`2021=validation`、`2022=test`，构建器会拒绝重复
`eventId`，因此当前样本在事件 ID 层面分离。实验 1 仍需生成自己的版本化清单，至少
额外保留：

```text
preferred magnitude value
preferred magnitude type
all alternate hypocenters and their magnitude types
depth and determination flag
instrumental-intensity missing state
station intensity class
station identifier and coordinate provenance
```

`synthetic_reveal` 中的到时是固定 P/S 速度合成值，震度是最终峰值，文件本身也带有
`final_peak_intensity_not_realtime_value` 与
`theoretical_arrival_not_observed_pick` 标记。它可以用于站点缺失敏感性对照，但不能
用于证明 GIF 实时峰值、真实进入时刻或到时语义已经与 JMA 对齐。

官方格式还提供震级 2/类型、深度标准误差、使用走时表、震源评价和震源辅助信息。
它们分别关系到震级类型统一、深度标签质量和事件筛选，实验数据版本必须补齐，不能
通过 `rawRegionHex` 或无类型数字间接猜测。

## 推荐的验证顺序

1. 新建实验 1 的版本化 JMA 事件清单，保留 `magnitudeType`、深度、站码和计测震度缺测状态；不覆盖旧预训练数据。
2. 先按单一震级类型和浅源范围建立最小标定集，避免同时混入类型与深度误差。
3. 审计 NIED/GIF 站到 JMA ARV 站的匹配距离与覆盖率，不先设 5 km 默认规则。
4. 拟合日本经验衰减基线，并对事件级留出集输出震中、规模和误差面指标。
5. 按已归档的气象厅 2024、司・翠川 1999、翠川等 1999 原文实现传统 PGV/ARV
   基准，使用相同拆分与直接震度基线比较。
6. 增加深度感知实验，按浅源、深源、近海、陆上和震级范围分组报告。
7. 最后用训练事件随机子采样生成日本置信轮廓，验证集只做覆盖率检查。

在第 1-6 步稳定前，不连接生产 UI，也不使用华北/川滇置信表替代日本标定结果。
