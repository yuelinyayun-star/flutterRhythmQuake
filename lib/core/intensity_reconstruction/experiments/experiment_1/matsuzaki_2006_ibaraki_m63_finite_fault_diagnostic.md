# 松崎式茨城县北部 M6.3 有限断层距离诊断

日期：2026-07-27

状态：JMA 修订近地强震波形有限矩形、同行评审论文和固定系数距离诊断完成；未重新拟合，
未接入生产。

## 输入事件

JMA 原始 2016 年度记录中的目标事件为：

```text
eventId = 2016122821384904-36.7202-140.5742
区域 = 茨城県北部（rawRegionHex 按 Windows-31J/CP932 解码）
originTime = 2016-12-28T12:38:49.04Z
Mj = 6.3
JMA 目录深度 = 10.84 km
最大震度代码 = C（震度 6 弱）
严格接受站 = 1294
点源距 <30 km 测站 = 20
```

诊断直接读取原始 `jma_final_intensity_2016.json`，不修改逐站观测震度、事件震级、
JMA 目录深度、基线筛选或系数。点源近场站仍按既有点震源距 `<30 km` 固定，只替换
松崎式（12）的距离 `X`。

## JMA 有限断层边界

JMA `2016122821384904near` 修订近地强震波形反演数据的 `01event.txt` 和
`02fault.txt` 给出：

```text
last updated = 2017-03-13
type = near02
fault plane count = 1
strike = 156 degrees
dip = 50 degrees
rake = -59 degrees
rupture start = 36.7223 N, 140.5686 E, depth 10.93 km
Xorg = 8
Worg = 5
subfault size = 3 km x 3 km
subfault grid = 10 x 8
length = 30 km
width = 24 km
rupture speed = 2.6 km/s
Mw = 6.04
maximum slip = 0.31 m
```

JMA 随附的 `format_english.txt` 明确把 `Xorg/Worg` 定义为破裂起点沿走向和下倾方向
所在的子断层编号。`02fault.txt` 中第 `8,5` 子断层中心正是报告的破裂起点，因此其
内部锚点为：

```text
沿走向距矩形起始边 = (8 - 0.5) * 3 = 22.5 km
沿下倾距上缘 = (5 - 0.5) * 3 = 13.5 km
下倾方位 = 156 + 90 = 246 degrees
```

实验保存破裂起点这个来源明确的面内参考点，没有把它猜成矩形中心或角点。几何代码
实际输出的上缘深度为 `0.588400 km`；这是由 `10.93 km`、`13.5 km` 和倾角 `50°`
派生的透明值，不是 JMA 单独报告值。

JMA PDF 图面同时确认：星号位于断层坐标中的破裂起点，A 到 B 与走向方向一致，主要
滑移集中在破裂起点北侧的浅部。第二页是 14 个反演站的观测/理论波形对照，没有提供
另一套断层几何。

JMA 年度目录深度 `10.84 km` 继续用于衰减式深度项；反演破裂起点深度 `10.93 km`
只定义有限矩形在三维空间中的位置，两者没有互相覆盖。

## EPS 双平面边界

Hikima（2023）为同时分析 2011 和 2016 两场茨城事件，用两个平面近似弯曲断层面：

```text
北段：strike 130 degrees, dip 42 degrees
南段：strike 155 degrees, dip 47 degrees
总长度：19 km
宽度：12 km
子断层：1 km x 1 km
```

正文和 Fig. 2 能确认两平面结构以及 2016 年破裂主要位于南段，但没有给出两个平面的
完整数值边界、各段长度和可直接恢复的三维参考点。仅从图面量取坐标会制造来源中没有
的边界，因此本次距离诊断不使用该双平面。它只用于交叉说明真实断层具有弯曲结构，
JMA `30 km x 24 km` 单矩形是可复现但简化的反演模型。

## 固定系数结果

20 个站的有限断层距离全部位于论文 `1-500 km` 数据域内，没有域外站，也没有使用
距离下限。

| 距离 | 最小 km | 平均 km | 最大 km |
|---|---:|---:|---:|
| JMA 目录点震源 | 13.608183 | 21.597373 | 28.977124 |
| JMA 有限矩形 | 1.360392 | 15.018572 | 26.992454 |

所有 20 个站的距离都缩短，平均缩短 `6.578802 km`。以下残差使用相同的 20 个配对站：

| 系数/距离 | 平均残差 | MAE | RMS |
|---|---:|---:|---:|
| 论文原系数 + 点震源 | -0.579341 | 0.615506 | 0.699014 |
| 论文原系数 + 有限断层 | -1.076700 | 1.076700 | 1.136968 |
| 2017 冻结系数 + 点震源 | +0.113538 | 0.333348 | 0.435959 |
| 2017 冻结系数 + 有限断层 | -0.237558 | 0.322478 | 0.391006 |

论文原系数下 20/20 个站的绝对残差都恶化，RMS 增加 `62.65%`。2017 冻结系数的
RMS 降低 `10.31%`，但逐站只有 9/20 改善、11/20 恶化，平均残差还从轻微正偏转为
负偏。这不是“有限断层对每站都更好”的结果。

## 结论和边界

JMA 有来源的有限矩形使全部近场站距离明显改变，进一步确认全点源距离不是完整的论文
距离语义。但论文原系数显著恶化、冻结系数只有小幅整体改善且多数站逐站恶化，说明
旧点源校准系数已经吸收距离定义误差，单矩形近似和测站/事件差异也仍然存在。

因此本事件可以进入统一有限断层距离目录，但不能据此把有限断层距离单项接入生产，
不能回调已经打开的 2018 重新选择系数，也不能从 EPS 图片猜出一套更贴合结果的双平面。
必须先把其余事件按同样来源标准补齐，再统一距离语义重新标定。
