# 有来源有限断层事件的深度 RMS 剖面

日期：2026-08-21

## 目的和边界

本诊断读取上一轮点源联合反演报告中的第一返回候选，固定其纬度和经度，只扫描深度
`5-100 km`，每个深度重新优化共同震级。它用于识别深度是否被观测和前向模型约束，
不用于调搜索规格、回写候选或判断生产收敛。

原始 JMA 观测仍由同一输入构建器选择最多 300 站；目录震源只用于事后标注目录深度，
搜索和剖面计算不读取有限断层几何。

工具：

```text

```

## 结论

1. 深度结果不是一个统一的固定偏差：原系数在鸟取、茨城向 `100 km` 边界，冻结系数
   在长野、熊本、茨城、大阪向 `5 km` 边界；同一模型在不同事件方向也不同。
2. 长野原系数的 `RMS + 0.05` 包络是 `40-100 km`，冻结系数是 `5-60 km`；这不是
   精确深度，而是当前数据下的宽不可辨识范围。
3. 最优点触及边界且曲线继续向边界下降时，结果只能标记为未收敛；不能通过扩大深度
   范围、把边界值显示成确定深度或用有限断层距离事后补偿。
4. 下一步若继续，只能增加独立的深度信息或建立有明确物理依据的分层/距离模型，再用
   未参与选择的事件验证；不能从这 12 条剖面直接调深度上下界或系数。
