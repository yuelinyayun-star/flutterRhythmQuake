# GSTSL intensity reconstruction

本目录独立还原马干、张杨、史保平（2010）《利用地震烈度数据重构历史地震震级和震中位置的方法》中的烈度资料网格搜索试算方法。

原始资料：

- `references/papers/2010_马干等_利用地震烈度数据重构历史地震震级和震中位置的方法.pdf`
- `docs/reference/intensity_based_historical_epicenter_magnitude_gstsl.md`

## 当前边界

已经实现：

- 论文公式 `(8-a)`、`(8-b)`、`(8-c)` 的川滇衰减参数；
- 由烈度和候选震中距反解每站震级 `M_i`；
- 论文公式 `(3)` 的未加权平均烈度震级 `M_I`；
- 论文公式 `(5)` 的距离权重；
- 论文公式 `(6)` 的 `W_i^2` 加权 RMS；
- 论文公式 `(7)` 的全网格最小值归一化 `rms[M_I]`；
- 显式候选点列表和显式规则网格；
- 2009 华北公式 `(8-a)` 的标定后线性烈度震级模型；
- 论文表 3 的 19 组震中区域阈值和两条单侧震级概率界；
- 显式指定衰减模型、距离权重、训练事件、候选网格、抽样站数、重复次数、随机种子、概率级别和经验分位数规则的随机子采样校准器。

## 来源核查后的语义边界

2009 年华北直接来源和 1997 年 Bakun-Wentworth 原文已经归档并核对。代码已经完成以下来源拆分：

- 2010 川滇事件评分使用 `a = 0.1, b = 1000 km`。
- 2010 表 3 实际借用自 2009 华北研究；可复现来源使用华北公式 `(8-a)`、`a = 0.05, b = 480 km` 和 10 个华北事件。
- 表 3(b) 是 `M - [M_I]_epi` 的两条单侧概率界。50% 两值相同表示经验中位数，不是中央 50% 双侧区间。
- 随机子采样校准结果记录本次实际使用的区域衰减模型与距离权重，不从生产算法或默认配置中暗取参数。

完整来源、原文步骤和适用限制见 `docs/reference/intensity_based_historical_epicenter_magnitude_gstsl.md` 第 13 节。

没有实现或没有擅自补充：

- 论文没有给出的固定网格范围；
- 论文没有给出的固定网格步长；
- 对数距离为零时的人工距离下限；
- 表 3 未列烈度点数量的插值规则；
- KA `level` 到宏观烈度或 JMA 震度的转换；
- 日本区域衰减参数；
- 深度和发震时刻搜索；
- 与现有 KA/HYP、地图或 UI 的连接。

`gstsl_reconstructor.dart` 的候选点列表接口是算法主入口。`GstsRegularGrid` 只是显式生成候选点，不携带论文之外的默认值。

## 文件

- `gstsl_models.dart`：输入、候选、逐站反解量、评分结果和规则网格。
- `gstsl_attenuation_model.dart`：三种衰减模型和距离权重。
- `gstsl_reconstructor.dart`：候选评分、网格最小值和归一化误差面。
- `gstsl_confidence_table.dart`：借用的 2009 华北表 3 精确查表数据。
- `gstsl_confidence_calibrator.dart`：可复现的随机子采样经验置信标定。
- `intensity_reconstruction.dart`：公共导出入口。
- `experiments/experiment_1/`：从原论文结构向日本 JMA 震度体系迁移的独立实验记录；未经确认的参数不进入论文还原核心。

## 生产使用限制

论文参数来自川滇地区 14 个 `5.9 <= Ms <= 8.0` 事件。当前实现首先用于论文算法复算与研究，不能直接用于日本实时地震，也不能将结果无条件标为仪器震中。
