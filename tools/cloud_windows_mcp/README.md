这是云电脑的 Windows MCP 部署包，用于查看桌面、操作鼠标键盘、启动 APP 和执行性能诊断命令。

在云电脑中解压压缩包，双击 `Start.cmd`。必须在需要测试 APP 的同一个 Windows 登录用户下运行。首次启动会安装到当前用户的 LocalAppData，设置登录时启动，并主动连接中转服务器。无需云电脑公网地址，不会修改 APP 源码或回放服务。

启动后告诉 Codex“云电脑 MCP 已启动”，即可检查连接。测试期间保留已登录且未锁定的桌面；注销、锁屏和远程桌面断开可能影响截图或鼠标键盘操作，需要实际连接确认。

双击 `Stop.cmd` 会停止服务并禁用自动启动。日志位于 `%LOCALAPPDATA%\RhythmQuakeCloudMCP\logs`，服务安装失败时提供日志即可，不要发送 `private` 目录。

部署包包含仅用于该隧道的私钥和 MCP 认证密钥，请只传到你自己的云电脑，不要公开上传。服务器中转端口只监听 127.0.0.1；专用 SSH 密钥限制固定转发端口且不能执行命令。MCP 保留完整操作能力，测试结束后可以关闭。
