1. 複数トリガ (Multi-trigger) — nearbyLength = 7
================================================================================

DEF 複数トリガ 状態 %s %s %s %s %s %s 番号 %s 7 %s %s

逻辑:
  if (conditions):
    if (conditions):
      点許可状態更新(0, 初トリガからの時間切れ+禁止)
      点許可状態更新(1, 初トリガからの時間切れ)

    pxx4g3[1..10] = 0    ← 重置 10 个计数器

    repeat 7:             ← nearbyLength = 7
      if (conditions):
        点許可状態更新(0, 時間エリア内に点なし)

        if (conditions):
        点許可状態更新(5, 通常許可)
        ~bN += 1

        repeat 7:
          if (conditions):
            ~bN += 2
            if (conditions):
              点許可状態更新(5, 補助許可)

      if (conditions):
        ~bN += 2
        pxx4g3[1] += 1

        if (conditions):
          pxx4g3[2] += 1

          # 加速追加 - 加权分值表
          加速追加(0.5, 許可震度+)
            if: 加速追加(0.15, 震度高+)
            if: 加速追加(0.05, 震度中+)

          加速追加(0.25, 近いトリガ済み+)
            if: 加速追加(0.2, 高い近いトリガ済み+)

          加速追加(0.15, トリガ済み+)
            if: 加速追加(0.1, トリガ済み+)

          加速追加(0.07 + (1 + X/3) * ((1.05 - Y) * Z), 加速+)    ← 动态加权
          加速追加(3/20, 追加震度+)   = 0.15

          NG加速(5)
            if: NG加速(8)

        pxx4g3[3] += 1

    # 第二遍：再次检查邻近站状态
    repeat 5:
      if (conditions):
        点許可状態更新(6/5, 周りの多くが許可or揺れてるから)

    # 第三遍：高密度触发检查
    repeat 7:
      if (conditions):
        点許可状態更新(5, トリガーが多いから)
        if: 点許可状態更新(5, 検出ありの周りで加速だから)

    # 第四遍：低震度过滤
    repeat 3:
      if (conditions):
        点許可状態更新(1, そんなに震度高くない)
        点許可状態更新(1, 最長時間オーバー1)

    # 周りの震度が低い 检查
    点許可状態更新(1, 周りの震度が低い)

    # 震度一定以下 检查
    点許可状態更新(1, 震度一定以下)

### 9.1 JMA2001距離近似

P波/S波走时距离计算，使用牛顿迭代法:

```
q = 0, f = 1
repeat 6:
  f = tjma * MATH(MATH(NONE / tjma))     ← Newton step
  q += MATH(tjma3 * MATH(NONE)) *
       (... + 426 * ... + 852 * bool_flag)
  f += 1
```

对应的 Dart 实现: `IntensityCalculator.calcJmaShindo` (line 146-174)

### 9.2 緯度経度で距離km (Haversine)

```
dist_km = 111.31949 * acos(sin(lat1)*sin(lat2) + cos(lat1)*cos(lat2)*cos(dlon))
```

### 9.3 点-震源 距離計算 (网格搜索震源推算)

**算法流程**:

```
// Step 1: 网格搜索 (23.5N~??, 123.5E~??, 188个搜索点)
for grid_y in 0..6:    // 6个纬度带
  for grid_x in 0..188: // 188个经度点
    for each station:
      grid_lat = 23.5 + (grid_y - 1) / 23
      grid_lon = 123.5 + ((grid_y - 1) % 23)
      
      // 计算从搜索网格点到测站的距离
      dist = haversine(grid_lat, grid_lon, station_lat, station_lon)
      store dist in search grid array[(grid_y) * 10 + ...]
      
    // 实际震中点估算公式:
    lat_estimate = -4.065e-7 * pos^2 + 8.161e-3 * pos + 35
    lon_estimate = 135 + (grid_value / 100)
    
    dist = haversine(lat_estimate, lon_estimate, station_lat, station_lon)
    store dist in results array
    
    // 找最近N个观测点
    call カメラ用近傍点 to find nearest stations
    
// Step 2: 为每个搜索网格计算到每个测站的距离
for each station:
  dist = haversine(result_lat, result_lon, station_lat, station_lon)
  store in distance array

// Step 3: 找最小距离网格作为震中
find min dist → 震中位置
```

**核心公式** (震中位置反算):
```
pos = station_index * 8 - 1
lat = -0.00000040650455 * pos² + 0.008161478619615 * pos + 35  ← 二次多项式拟合
lon = 135 + (grid_val / 100)
```

### 9.4 円の中か判定 (点在圆内判定)

```
result = 0
count = 0
repeat 10:
  if station inside radius:
    count += 1
    if enough stations inside:
      result = 1  ← 在圆内
      break
```

### 总结

Scratch 的震源推算使用**网格搜索法**：
1. 在 23°N-35°N / 123°E-135°E 范围内建立 6×188 的搜索网格
2. 对每个网格点计算到所有激活测站的 Haversine 距离
3. 使用二次多项式从测站指数反算震中纬度
4. 找距离和最小的网格点作为推定震中
