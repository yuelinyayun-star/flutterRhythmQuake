# NSMC 云图可见区及外圈预载

## 授权范围

用户要求不要一次加载全部不可见内容，随后明确“视野外也加载一部分”。本轮只优化现有 NSMC 全球红外云图的加载与处理；保持原信源 `GEOS_IRX`、原始观测时次、透明度0.72和地图相机规则。没有切到风云4B或浙江源，也不修改 JMA、雷达、EEW、情报或检出的绘制规则。

## 具体修改

| 文件 / 位置 | 原行为 → 新行为 |
| --- | --- |
| `lib/services/sources/nsmc_satellite_cloud_service.dart` / `fetchNow`、帧类型、URI及投影入口 | 启动后下载2048×1024全球整图并转成2048×2048 → 仅获取原始目录及最新UTC时次，发布瓦片帧描述；图片按可见瓦片请求。原始目录直接送入已有Rust解析接口。原完整图帧类型仍能用于旧数据。 |
| `lib/widgets/map/nsmc_satellite_cloud_layer.dart` / 绘制分支与生命周期 | 整张云图全球重复 → 新实时/播放帧使用XYZ瓦片，`panBuffer=1`预载一圈、`keepBuffer=1`保留临近缓存；新时次先在不可见暂存层加载，可见区全部解码后整体切换，避免拼接不同时间；外圈不阻塞切帧。关闭或TickerMode禁用时移除瓦片层并释放请求。保留旧完整图帧的原绘制入口。 |
| `lib/widgets/map/nsmc_cloud_tile_provider.dart`（新增） | 无专用队列 → 可见瓦片优先、外圈随后，最多4个并行请求；地图剔除瓦片时中止排队/网络请求；最多48块/8 MiB压缩瓦片缓存，退役项清除对应Flutter图片缓存；销毁释放全部资源。 |
| `lib/services/weather_playback_controller.dart` / NSMC显示分支 | 播放时下载整张历史全球图 → 仅切换历史时次描述，地图仍按当前可见区及一圈邻区取图；下一帧等待当前可见区就绪，暂停/退出释放等待。不更改其他产品预载、播放或缓存策略。 |
| `lib/services/foreground_station_payload.dart` / 仅NSMC编码、解码 | Android传递整张图片 → 支持带`tiled:true`的时次描述；原含PNG的旧帧仍可原样解码。其他桥接类型不变。 |
| `native/station_core/src/nsmc_image.rs`（新增）、`src/lib.rs`、头文件 | Dart计算NSMC图像投影 → Rust计算XYZ经纬边界、投影行映射及PNG输出。支持旧全球整图和新256×256瓦片，RGBA按原像素复制，不重着色或修改透明度。输入借用，输出通过专用free释放。 |
| `lib/services/native_nsmc_image*.dart`（新增） | 无对应桥接 → Windows生产调用Rust；图像工作在compute isolate中完成。项目当前未支持station-core的平台使用明确便携实现，没有原生失败后的静默回退。 |

原 `nsmcSatelliteLatestTime`、`nsmcSatelliteSourceRow` 公共兼容函数仍供旧测试/调用方使用，新的生产实时路径不再使用旧Dart目录策略；Windows投影入口已实际切到Rust。

## 请求及显示边界

- 同一时次只请求当前地图XYZ范围及外侧一圈。远处不提前下载；拖动或缩放后按新的范围继续取图。
- WMS仍按官方EPSG:4326返回数据，Rust逐瓦片映射到麦卡托坐标，不能直接把经纬矩形图片贴到地图上。
- 跨180°使用原地图世界环绕，瓦片经度归一化，边缘相接。不会因跨线构造一张横跨360°的大请求。
- 每个请求图像256×256、响应限制512KiB，超时15秒；原始字节进入Rust，校验后转换。空透明瓦片是有效无云区域，不能当成需兜底的失败。
- 最大原生瓦片级别为3，全球宽度对应2048像素，与原全球图水平像素数一致；继续放大由地图按原分辨率缩放，避免为了优化额外增加高缩放请求。当前/暂存的可见瓦片由图片监听者持有，不受压缩历史缓存48块上限破坏；离屏后释放。
- 本轮不改变原30分钟目录刷新周期和源的实际时效。
