# NMEFC 右侧岸段预报图

右侧 NMEFC 侧栏使用已接纳报文的 `coastalMapUrl`，对应原始
`details.maps.coastalMapUrl`。只修改该机构的右侧页面，不改左下信息列表和 JMA 排版。

Rust 经既有 packed FFI 的 `nmefcCoastalMap` 操作确定附件与缓存身份；网络复用
已有 WinHTTP 客户端。Flutter 只调度附件字节、解码并绘制图片，点击后可缩放查看原图。
缩略图完整适配侧栏，不裁切，按屏幕像素宽度解码，最多 1024 像素宽。

没有轮询。同一事件、报次、发布时间和 URL 只加载一次，侧栏轮播返回时复用。
最多保留两报图件，新报即使重用 URL 仍重新加载并要求重新验证传输缓存。
失败可以手动重试；缺图保留原文字栏，不拼接猜测文件名，不替换为深海波幅图。
解除报不显示之前的岸段图；新报加载时也不沿用旧图。

## 岸段核验与未完成项

用户先要求参照 KA 映射。KA 公开源码使用原始 `forecastArea` 与岸线要素
`properties.name` 匹配，但 `cn_tsunami` 资源通过认证接口
`https://api.lipomoea.tech/cn_tsunami_topo_json_url` 提供；本机参考源码和公开仓库
都没有附带该文件。未请求或绕过此认证接口，未声称取得 KA 岸段。

用户随后允许沿用此前近似方案，又要求先核验发布行政层级。本轮新加的
花莲/宜兰简称到整县映射已撤掉，当前仅保留之前完整行政名称的严格匹配基线。
不把临时制作的对比图中的候选范围作为官方分区事实。

直接核对官方 2024-04-03 第 1 报：
https://obs.nmefc.cn/Warning/TsunamiAdvice/202404030758_1_file/202404030758_1.html

表格分为“省份、预报区域、预报点”，其中包含：

|预报区域|预报点|
|---|---|
|花莲|花莲|
|宜兰|宜兰县|
|台东北|富冈|
|台东南|大武|
|屏东西|后壁湖|
|屏东东|屏东东|
|台北东|台北东|

该实例足以说明预报区域不能统一视为完整县市。方向岸段不直接扩大到整县，
预报点也不充当区域边界。还未核实这些分区的端点/官方矢量表；这里不虚构边界。
现有解析仍逐区域采用原始 `warningLevel` 的红、橙、黄，不改成 KA 的 JMA 色系。
省份名、区域名、原始报文和官方原图均未回写修改。
