## 1. 一句话结论

JMA EEW **不是"一条震级公式"**，而是

> **检测触发 → 震源/震级 → 前向地面运动预测 → 分档发布与校验**

四段**强耦合**流水线。每一段之间都有**硬闸门（阈值/一致性/取消）**；
并且**震级永远与"产生该观测量那个观测站"自身的震源距配对**——
这正是本项目当前最缺的两件东西。

## 2. 第一段：检测与触发

- **[公式] 硬阈值**：任一多機能型地震計的 P 波或 S 波**振幅 ≥ 100 gal** 即触发候选。
  → 这是**绝对量阈值**，不是相对基线的抬升。
- **[机制] B-Δ 法**：单站即时完成"噪声判别 + 大致震央距离 Δ"。
- **[机制] 多站一致性**：需多个观测点数据一致，判定"疑似地震（而非噪声）"后才进入定位。
- **[机制] 单站兜底与取消**：仅 1 站触发即发（予報）后，若预定时间内**没有第 2 站**确认，
  判为落雷等噪声 → 发 **キャンセル報**（数秒〜10 数秒；岛嶼部可达约 30 s）。
- **[机制] 一般向警報需 ≥2 点地震計观测。**

> 对照本项目病根：本地触发用"60 s 中位基线 +3 级 × 连续 3 帧"的**相对**判据，
> **无绝对振幅下限**、**无多站一致性门**、**无单站取消**——见 §5。

## 3. 第二段：定位与震级

### 3.1 定位（多算法并行）

- **[机制]** B-Δ、**領域法（territory）**、**グリッドサーチ（grid search）**、
  NYAD（not-yet-arrived-data，用"已到达/未到达 P 波"做几何约束）、
  以及常规走时定位（Hypoon）**并行运行**。
- **[机制]** NYAD / Hypoon 的定位**仅在位置误差小于拒绝阈值时才被采纳**[S3]。
- **[机制] IPF（2016 起）**：相位关联方案可把**时空接近的多个地震**正确分离[S3][S4]。

### 3.2 震级（本项目最该抄的一节）

**[公式] 三套 M 式，按 S 波到达切换**（`A` = 3 成分合成**変位**振幅；`R` = **该观测点自身的震源距離**；`D` = 深さ）[S1]：

```text
P波 M 式（明田川ほか 2010）:
  0.72 M = log10 A + 1.2  log10 R + 5.0e-4 R − 5.0e-3 D + 0.46

全相 M 式（清本ほか 2010）:
  0.87 M = log10 A + 1.0  log10 R + 1.9e-3 R − 5.0e-3 D + 0.98

海底計 OBS 上下動 M 式（林元ほか 2019）:
  0.90 M = log10 A_Z + 0.83 log10 R + 1.7e-3 R − 2.6e-3 D + 1.68
```

- **[机制] 稳健合并**：等"複数観測点"的振幅；对"観測点 M 偏大"者**当异常值剔除**后再算 M[S1]。
- **[机制] IPF 用最近 ~5 站的変位振幅**估 M，并随振幅增长**持续更新**[S4]。
- **[机制] 固定 M（固定化）**：切到全相 M 的瞬间，为避免 M 反而变小——
  先**保持 P 波期最大振幅算出的 P 波 M**，直到"全相 M > 固定 M"（或达到破壊継続時間/时限）才切[S1]。
  → **M 单调增长是刻意设计**：M 是"待收敛的源尺寸"，只能从下方逼近，**不是"锁住一个会衰减的观测峰值"**。
- **[公式] Mj→Mw**：`Mw = Mj − 0.171`（Utsu 1982）。

### 3.3 双路并行（冗余）

- **[机制] IPF（有震源）** 与 **PLUM（無震源）** 并行；PLUM 不估震源，直接用**目标点 30 km 内的实测震度**外推[S3][S4]。
- **[机制] 两者按"取最大值"合并**，兼顾大震捕捉与冗余[S4]。

## 4. 第三段：前向地面运动预测

**[公式]** JMA 官方四步法[S2][S5][S6][S7]：

```text
(1) Mj → Mw:            Mw = Mj − 0.171
(2) 距離減衰 (Si & Midorikawa 1999):
    log10 PGV600 = 0.58 Mw + 0.0038 D − 1.29
                   − log10( X + 0.0028·10^(0.50 Mw) ) − 0.002 X
    X = 断層最短距離（早期用 X = R − L/2, log10 L = 0.5 Mw − 1.85；X 下限 3 km）
(3) 场地放大 (Matsuoka & Midorikawa 1994):
    log10 ARV = 1.83 − 0.66 log10(AVS30)
    PGV700 = 0.9 × PGV600 ;  PGV_surface = ARV × PGV700
(4) 計測震度 (Midorikawa 1999):
    I = 2.68 + 1.72 log10(PGV_surface)  (± 0.21)
```

- **[机制] 对每个目标参考点前向算震度**（全国 188 区、约 4500 参考点）[S4]。
- → **显示与发布同源**：都由"震源参数 + 距离 + 场地放大"推出，不存在"两个互斥的强度口径"。

## 5. 第四段：发布与校验闸门

| 闸门 | 条件（来源） |
| --- | --- |
| 予報 | 100 gal 且（**M ≥ 3.5 或 予測最大震度 ≥ 3**）[S9] |
| 一般向警報 | **≥2 点观测** 且 予測最大震度 **≥ 5弱** → 对 予測 ≥4 的地区发布[S8] |
| 続報 | 仅当**新**区域达到 ≥5弱 才更新[S8] |
| 取消 | **仅限"落雷等非地震"误报**；若只是"5弱→3 以下"，**不取消**[S8] |

## 6. 逐条对照：本项目病根 → JMA 对应设计

| 本项目现状（见 `nied_magnitude_bias_20261003.md`） | JMA 的对应设计 | 可直接借鉴度 |
| --- | --- | --- |
| 触发 = 相对基线抬升，**无绝对下限** → M0.8 触发 67 站 | 100 gal **绝对阈值** + 多站一致性 + 单站→**取消** | ◐ 中：**只借"前端检测质量"**，阈值须按**召回**重设、远低于 JMA（见 §7.5） |
| 震级 = **全网最大强度** 配 **最近站距离**（张冠李戴） | **每站用自身震源距 R** 算 M_i，再**稳健合并** | ✅ 高（核心） |
| 触发链与震级链**无任何交叉校验** | IPF+PLUM **双路**、多算法并行、相位关联 | ◐ 中（需两套估计源） |
| 发布**锁住峰值强度**（事后不回撤） | **固定 M**：只升不降，但**有明确切换条件** | ◐ 中（语义不同，见 §7） |
| 同报内「发布震级」与「实测最大震度」**互斥** | **前向预测**：显示与发布**同源** | ✅ 高 |
| 强度口径混用（一处用显示强度、一处用加速度） | 统一由 PGV 前向推出 | ✅ 中 |

## 7. 能借鉴什么 / 不能照搬什么 / 折中

**可直接借鉴（与本项目数据条件相容）**

1. **同站配对**：`D` 取"承担该 `I` 的那个站"**自身**的震源（或震央）距——本项目已有帧内 `latLng`，不需要新数据源。
2. **前端绝对下限（只提检测质量）**：在相对判据之外加一条绝对振幅/震度下限，**但阈值须按"高召回小震"来定、远低于 100 gal**——它滤的是"零地面运动却触发"的**解码/噪声伪迹**，不是滤小震。（见 §7.5）
3. **足迹"约束"而非"裁决"**：把触发足迹（站集/相位/相对到时）**喂进**震源解——关联 → 定位约束 → 每站自身 `I × D` → 稳健合并。**不要**做成发布拦截器（见 §7.5）。
4. **单一强度口径**：发布与显示**同源**。

**不能照搬（本项目缺 JMA 的输入）**

- JMA 的 M 式吃的是**3 成分変位振幅 A** 与**震源距 R**；本项目实时只有**从 GIF 解码的量化震度**。
  → 无法直接套用 P波M/全相M 公式；**只能用"每站自身震度 + 自身距离"的对应形式**做同站配对（这正是 §6 第 2 行的核心）。
- JMA 的 PGV 前向式需要 **GMPE + AVS30 场地放大**数据库；本项目没有。
  → 前向预测的前两步无法照做，但"**前向**而非'事后拿最大强度反推'"这个**方向**可以借鉴。

**折中建议（供后续设计评估，非本轮改动）**

- 把"配对"修复做成**影子候选 / 开关式**，先不动默认路径。
- 触发侧若要提质量，**优先改"检测质量"（输入行为），不要改"输出发布"**：见 §7.5 的目标函数差异。
- ~~在发布层加"一致性闸门"作为拦截器（不符就不发布/降级）~~ —— **此条已作废**，理由见 §7.5。

### 7.5 ⚠ 关键更正（2026-10-09）：本项目与 EEW 的目标函数相反

本项目**不是**"缩小版的 EEW"。EEW 服务的是**破坏性大震的极低误报**（代价：M<3.5 的小震**根本不发报**）；
而本项目的**目标样本恰恰就是"JMA 没有发报的那些事件"**——即**低于 EEW 发布阈值的本地小震**。
因此：

| 维度 | JMA EEW | 本项目 |
| --- | --- | --- |
| 优化目标 | 大事件**低误报**（高精度） | 小事件**高召回**（高灵敏度） |
| 阈值性质 | 100 gal / M≥3.5 是**产品门槛** | 门槛必须**远低于** JMA，否则目标样本全被自家门槛挡掉 |
| 触发足迹的作用 | 佐证"这是地震" | **提供关联/几何约束**，用于**算得更准**，而非判"真伪" |

**推论（本轮纠正）**：把"触发足迹 ↔ 震级"做成**发布拦截器 / 降级器**是**方向性错误**——
它等价于在本项目的主目标总体（亚阈值小震）上做**降召回**，会把我们想找的事件亲手滤掉。

**正确用法**：触发足迹应当**喂进**震源解（关联 → 定位约束 → 每站"自身强度 × 自身距离"配对 → 稳健合并震级），
让**同一个足迹**既提高精度、又**不牺牲召回**——这才是 JMA §3 的真正启示（多站处理是**输入**，不是**输出裁决**）。

**唯一站得住的"门"是前端的**：若"零地面运动却触发数十站"，那是**检测器/解码器的输入质量缺陷**，
要在**检测段**用绝对下限 + 多站一致性修（且阈值要比 JMA 低、按召回校准），**不是**在发布段把结果抹掉。
