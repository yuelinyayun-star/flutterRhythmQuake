本文以 Bakun and Wentworth (1997) 的强度资料反演方法为基础，为中国西南川滇地区标定烈度衰减关系，再通过网格搜索试算法 GSTSL（Grid Search & Trial Source Location）估计历史地震的震中区域和烈度震级。

## 2. 方法解决的问题

输入是若干个带位置的宏观烈度观测点：

```text
(latitude_i, longitude_i, intensity_i), i = 1..n
```

输出是：

- 可能的震中区域，而不只是一处没有不确定度的点；
- 每个候选震中对应的烈度震级 `M_I`；
- 以修正后的震级离散度 `rms[M_I]` 表示的候选震中适合程度；
- 根据烈度点数量查表得到的震中区域和震级置信范围。

该方法不要求先人工绘制等震线。它直接使用离散烈度观测点，对资料较少或不便可靠绘制等震线的历史地震更有价值。

## 3. 烈度衰减模型

论文比较三类烈度-震级-震中距关系，其中 `I_i` 为烈度，`M` 为震级，`Delta_i` 为震中距：

```text
(1-a) I_i = c0 + c1 * M + c2 * Delta_i
(1-b) I_i = c0 + c1 * M + c2 * log10(Delta_i)
(1-c) I_i = c0 + c1 * M + c2 * Delta_i + c3 * log10(Delta_i)
```

论文用川滇地区 14 个有仪器记录的地震标定系数。这些事件位于 1923-2008 年，震级范围为 `5.9 <= Ms <= 8.0`。拟合时，同一烈度区的震中距取中间值 `Delta_median`。

川滇标定结果：

```text
(8-a) I = -5.38 + 1.91 * M - 0.0173 * Delta_median

(8-b) I = -4.29 + 2.06 * M
            - 2.1933 * log10(Delta_median)

(8-c) I = -4.73 + 2.10 * M
            - 0.0033 * Delta_median
            - 1.9294 * log10(Delta_median)
```

论文最终选用第二类对数距离模型 `(8-b)`。三类模型对应的烈度震级与仪器 `Ms` 标准偏差分别约为 `0.294`、`0.294` 和 `0.288`。虽然第三类略低，但论文后续计算采用第二类。

作为比较，论文列出的加州关系为：

```text
I = -3.29 + 1.68 * M - 0.0206 * Delta_median
I =  5.07 + 1.09 * M - 3.69 * log10(Delta_median)
```

论文结论是：川滇地区烈度随震中距衰减的速率约为加州模型的 60%。这也直接说明衰减系数具有明显地域性，不能跨区域直接套用。

## 4. 候选震中的评分

对网格中的每个候选点 `P`：

1. 计算每个烈度观测点到 `P` 的震中距 `Delta_i`。
2. 用衰减关系把每个 `(I_i, Delta_i)` 反解为单点震级 `M_i`。
3. 取所有单点震级平均值作为该候选点的烈度震级 `M_I`。
4. 计算 `M_i` 围绕 `M_I` 的离散程度。
5. 搜索离散度最小的区域，并绘制 `M_I` 与离散度等值线。

以线性距离模型为例，单点震级是：

```text
M_i = (I_i - c0 - c2 * Delta_i) / c1
M_I = mean(M_i)
```

对论文最终采用的 `(8-b)`，单点震级可写为：

```text
M_i = (I_i + 4.29 + 2.1933 * log10(Delta_i)) / 2.06
```

未经加权的离散度为：

```text
rms(M_I - M_i) = sqrt(sum((M_i - M_I)^2) / n)
```

逻辑是：如果候选点靠近真实震中，各烈度点反解出的 `M_i` 应更一致；候选点错误时，反解震级的离散程度会增大。

## 5. 距离权重

论文认为近处烈度点对震中和震级的约束应强于远处点，因此使用：

```text
W_i = a + cos((Delta_i / b) * pi / 2),  Delta_i < b
W_i = a,                               Delta_i >= b
```

加权离散度为：

```text
rms(M_I - M_i)
  = sqrt(sum(W_i^2 * (M_i - M_I)^2) / sum(W_i^2))
```

其中：

- `a` 是远距离水准值；
- `b` 是距离因子，单位 km；
- `a` 越小，近点和远点的权重差异越大。

Bakun and Wentworth 的加州研究使用 `a = 0.1, b = 150 km`。本文计算川滇置信值时使用 `a = 0.1, b = 1000 km`，其中 `b` 约等于标定资料的最远震中距。论文明确指出 `a`、`b` 的选择存在一定任意性。

## 6. 网格归一化误差与等值线

不同事件的原始最小离散度不同。论文把每个候选点的加权离散度减去整个网格的最小值：

```text
rms[M_I](P)
  = rms(M_I - M_i)(P) - min_grid(rms(M_I - M_i))
```

因此：

- 最优网格点的 `rms[M_I] = 0`；
- `rms[M_I]` 等值线用于圈定震中区域；
- `M_I` 等值线用于估计震级；
- 论文不是简单返回一个最小点，而是强调候选区域和置信轮廓。

## 7. 论文结果

### 标定误差

- 三种模型对仪器 `Ms` 的标准偏差约为 `0.288-0.294`。
- 该误差约为 Bakun and Wentworth 加州结果的 1.6-2.2 倍。
- 论文认为一个重要原因是没有校正局部场地条件对烈度的影响。

### 2008 汶川地震

- 仪器震级 `Ms 8.0`。
- 仪器震中处的烈度震级约为 `M_I 7.9`。
- 烈度反演中心位于北川附近，与仪器震中相差约 100 km。
- 论文把该偏移解释为长断层、分段破裂和北川附近大滑移造成的烈度分布中心偏移。

这个案例非常重要：烈度场反演得到的可能是主要能量释放或强震动中心，不一定是最初破裂点或仪器学意义上的震中。

### 四个验证事件

| 事件 | 烈度点 | 文献/仪器参考 | 论文结果 |
|---|---:|---|---|
| 1786 康定 | 11 | 约 M7.5 | `M_I 8.1`，参考震中位于 80% 区域内 |
| 1850 西昌 | 11 | 约 M7.5 | `M_I 7.6`，参考震中位于 50% 区域内 |
| 1913 峨山 | 未明确列于该段 | Ms 7.0 | `M_I 7.0`，参考震中位于 50% 区域内 |
| 1970 通海 | 13 | Ms 7.8 | `M_I 7.4`，仪器震中位于 80% 区域内 |

## 8. 与当前实时 HYP 的关系

| 项目 | 当前文章/Scratch HYP | 本论文 GSTSL |
|---|---|---|
| 主要输入 | KA 检出的测站触发时刻、站点状态、P/S 归类 | 各地点的烈度值与坐标 |
| 物理关系 | JMA2001 P/S 走时 | 地域性烈度衰减关系 |
| 主要目标函数 | 反推发震时刻的加权离散、未着惩罚等 | 每个烈度点反解震级的加权离散 |
| 输出 | 纬度、经度、深度、发震时刻 | 震中区域、烈度震级 |
| 深度 | 参与搜索 | 不估计 |
| 发震时刻 | 参与搜索/计算 | 不估计 |
| 实时性 | 面向实时测站检出 | 原本面向历史宏观烈度资料 |

两者共同点是“对每个候选位置计算各测站反演量的一致性，再搜索离散最小区域”，但输入、物理模型和输出维度不同。不能因为目标函数形状相似就把两者混成同一算法。

## 9. 对 RhythmQuake 的可用价值

可以考虑的方向：

1. 作为稳定后的独立诊断层，用当前事件的测站 JMA 震度场对震中区域做第二种反演。
2. 为震级估算提供与 P/S 走时无关的交叉证据。
3. 显示完整的候选误差面和置信轮廓，而不只显示单个最优点。
4. 在 HYP 出现多个局部谷底时，用烈度场结果作为诊断信息检查哪个区域更符合强震动空间衰减。
5. 对当前“支持站很多但震中/深度仍异常”的事件，区分到时拟合问题与强震动分布中心偏移问题。

不能直接做的事情：

1. 不能把论文川滇系数直接用于日本。
2. 不能直接把 KA `level` 当作论文烈度。必须使用明确映射后的 JMA 震度值，并核实连续震度、离散震度阶和宏观烈度之间的量纲差异。
3. 不能用它替代 JMA2001 到时定位，因为它不计算深度和发震时刻。
4. 不能把论文表 3 的置信阈值直接作为当前 UI 的质量百分比。
5. 对近海地震要特别警惕陆地测站单侧分布；海上缺少烈度点可能把烈度中心拉向陆地。
6. 对长断层或多段破裂事件，结果可能更接近强震动中心而不是初始震中。

## 10. 若以后实现，必须先完成的标定

1. 使用日本有 JMA 最终震中、震级和测站震度的现代事件建立标定集。
2. 分区域检查日本东北、关东、中部、西南和北海道的衰减差异，不能默认全国一套系数。
3. 明确震级类型，不能混用 `M_JMA`、`Mw`、`Ms`。
4. 加入测站场地项或至少量化站点固定偏差。
5. 单独评估陆上、近海、深源、长断层和小震级事件。
6. 用事件级留出验证，避免同一事件的测站同时进入标定和验证。
7. 输出应标为“烈度场反演中心/区域”，不能无条件标成 HYP 震中。

## 11. 结论

这篇论文最值得吸收的不是川滇地区的具体系数，而是以下结构：

```text
地域标定的烈度衰减模型
  -> 每个候选震中反解各站震级
  -> 以反解震级的一致性构造误差面
  -> 网格搜索最小区域
  -> 输出震中置信轮廓与烈度震级
```

它适合作为 RhythmQuake 将来的独立烈度场估算器或诊断器，不应直接改写当前按文章/Scratch 运行的 P/S 到时 HYP 核心。

1. [6] 没有套用加州衰减关系，而是使用 12 个 20 世纪标定事件建立太平洋西北地区关系，并检验跨喀斯喀特山脉的传播路径差异；东西两侧路径在约 `225 km` 以内没有显著差异，超过该距离后才需要区分。该研究明确不使用场地修正，理由是可用于稳定估计场地项的近期大震太少。

5. [8] 使用 14 个有仪器位置的训练事件、4375 个 MSK-64 烈度观测，得到北部和中部莱茵地区专用关系 `M_LIi = (MSKI_i + 0.7374 + 0.0184Delta_i) / 1.2673`。

### 13.5 华北直接来源恢复出的规则

2009 期刊全文补全了 2010 论文未展开说明的表 3 来源和实验步骤：

1. 华北标定集包含 10 次 1945-1977 年浅源地震，`5.3 <= Ms <= 7.8`，震源深度均不超过 25 km；其中 3 次没有仪器震中而采用宏观震中。
2. 使用中国地震烈度表。低端将 I、II、III 统一视为 III；高端将 X 及以上统一视为 IX。这个处理只属于华北历史宏观烈度资料，不能直接套到 JMA 震度阶级。
3. 训练资料主要从等震线图均匀随机取点：等震线边界点可取半级烈度，例如 V/VI 边界取 `5.5`；无法确定外延的最外侧烈度区不使用。
4. 零星高/低烈度异常区按其所在主体烈度区处理；震中附近不包含仪器震中的更高烈度区也被压回震中所在烈度区。论文明确承认这些做法忽略了局部地质和破裂方向性。
5. 对同一烈度的震中距取中间值 `Delta_median`，计算前剔除距离均值 `+/- 2 sigma` 之外的偏离点。
6. 华北论文最终选择线性距离模型，而 2010 川滇论文选择对数距离模型。两者的衰减系数和烈度震级式不能混用。
   华北置信标定实际使用公式 `(8-a)`：`M_i = (I_i + 1.73 + 0.0106Delta_i) / 1.31`，不能用前一步回归式 `(6-a)` 的系数代替。
7. 表 3(a) 的生成方式是：对每种目标站数，从每次标定地震的全部烈度数据中随机抽取，围绕真实震中建立 `400 km x 400 km` 搜索区，以 `5 km` 间隔计算误差面；每次地震重复 `1000` 次，10 次地震合计 `10000` 个样本，再按真实震中被某条等值线包围的比例标定 95%、90%、80%、67%、50% 阈值。
8. 生成表 3 时使用 `a = 0.05, b = 480 km`。`b = 480 km` 约等于华北训练资料的最大震中距。
9. 论文比较了 `b = 150, 300, 480, 750, 1000, 1200 km`；`b = 150 km` 的置信值偏差较大，`b >= 480 km` 后影响较小。实际案例仍按等值线闭合情况使用过 `b = 400, 480, 1000 km`，因此 `b` 不是所有事件共享的固定常数。
10. 表 3(b) 分别标定 `M - [M_I]_epi` 的单侧下界和上界。50% 两值相同表示经验中位数，不是零宽度的中央 50% 区间。
11. 2009 论文没有实施场地校正，并明确将其列为必须继续研究的问题。

### 13.6 2010 表 3 的来源不一致

2010 川滇论文第 129 页称“计算置信值时取 `a = 0.1, b = 1000 km`”，但它的表 3 全部数值与 2009 华北表 3 逐项相同；2010 结论又明确写道“沿用了华北地区”的位置等值线和震级上下界置信值。

因此目前能确认的事实是：

- 2010 的川滇事件评分和绘图使用 `a = 0.1, b = 1000 km`；
- 表 3 数值的可复现生成过程只在 2009 华北论文中出现，使用 `a = 0.05, b = 480 km`、华北线性衰减模型和 10 个华北事件；
- 2010 论文没有提供一套能用 14 个川滇事件、`a = 0.1, b = 1000 km` 重新生成同一张表的实验细节；
- 在重新标定以前，表 3 只能标为“2010 借用的 2009 华北经验阈值”，不能宣称是川滇模型自身生成的置信度，更不能用于日本。

## 14. 2010 论文明示的后续问题

论文讨论部分没有把当前模型写成最终通用方案，而是明确提出以下后续工作：

1. 结合川滇构造和地质背景，对历史地震进行更合理的分区和分类，建立更合适的区域衰减模型。
2. 校正局部场地条件对烈度值的影响。
3. 比较“等震线与实际烈度资料结合标定”和“完全使用实际烈度观测标定”的差异与优劣。
4. 解决烈度震级相对真实震级标准偏差偏大的问题。
5. 在区域研究充分后再推广到其他地区。

这些是论文作者明确提出的问题，不是项目自行添加的优化项。
