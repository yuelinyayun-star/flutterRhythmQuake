# NIED 小震震级偏低排查（2026-10-03）

## 范围与结论

主目标是小震震级偏低，深度仅作辅助。生产算法未修改，未编译发布。
本次只新增测试侧观察器和独立分析脚本。没有把目录震级、参考软件深度
或位置送入定位算法，没有改写原始 GIF，也没有统一加震级补偿。

已证实存在三类降低震级的机制：定位拾取筛选漏掉震级观测、定位报次缓存
压住后续震度上升、连续震度再次向下量化。另有最大震度与最近站距离
不配对的公式局限。不同样本由不同因素主导，尚不能把其中一种认定为
所有小震的唯一根因。

## 证据方法

- `test/support/nied_magnitude_audit.dart` 继承原估计器，原样返回
  `super.estimate` 结果；旁路记录原始 active 快照及诊断，不反馈到算法。
- 分别保持所有 active 站、带 triggerStamp 的 active 站的震度，使用相同
  原公式进行诊断计算；多震源不作全局最大值与单事件输出的直接对比。
- 定时器按原 GIF 时间戳推进，避免快速回放把站点保持时间变成机器运行时间。
- 主批次 7 个窗口共 1052 张 GIF；补充 3 个完整窗口共 453 张 GIF。
  唯一窗口合计 10 个、1505 张；另对 4 个窗口重复诊断 599 帧。
- 山梨 M2.4 窗口缺 5 帧：00:32:52、00:33:16、00:33:30、00:34:12、
  00:34:43 JST。保留缺帧事实，不插值、不补造触发时刻；该例只能证明
  当前输入上的筛选机制，不代表实时运行发生率。
- 与先前无观察器原版基线比较，3 个重合窗口共 453 帧的经纬度、深度和
  发布震级完全相同，原始数据摘要相同。两次观察器诊断的 599 帧也一致。

## 1. 震级复用了定位的拾取筛选

`source_estimator.dart` 的 `_niedHypStationFromSnapshot` 在 active 站缺少
`triggerStamp` 时直接返回 null；`estimate` 又只从该 workerFrame 的
activeStations 更新 `magnitudeIntensityState`。有震度但没有有效拾取的站
因此既不能用于走时定位，也完全不能提供震级信息。

原始回放实例：山梨参考 M2.4，2026-06-27 00:33:20 JST。

| 项目 | 记录值 |
|---|---:|
| 最强 active 站 | YMN002 |
| 连续震度 | 1.2339419007430257 |
| triggerStamp | null |
| 全 active 保持震度（经原量化） | 1.16 |
| 定位可用 active 保持震度 | -1.17 |
| 原版发布震级 | 0.1407818925 |
| 同公式、同位置、同距离，用定位可用站重算 | 0.1407818925 |
| 同公式、同位置、同距离，用全 active 站诊断 | 2.4707818925 |

差值 2.33 来自输入站筛选，不是该帧的报次锁定。该事件后续最终发布约
M1.47，而非一直 M0.14。不能据此直接把所有 active 站并入每个事件；
正式修复仍需要事件归属、时间有效性和噪声门槛，不应修改 P/S 定位门槛。

## 2. 定位稳定被当成震级稳定

`SrevKaizouMagnitudePublicationState.update` 同一报次只计算一次；
`stable=true` 后永久返回锁定值，该实例之后即使报次变化也不解锁。
报次比较只看经纬度、深度，不看震度是否仍在上升。

纪伊水道截图候选窗口，2026-10-03 21:46:20 JST：原版发布 M1.29043653，
缓存输入 -0.17；当前同一批定位可用站保持震度为 0.16，同公式可得
M1.62043653，少更新 0.33。该候选窗口尚未完成截图事件身份核验，
EQuake 截图值不是目录真值。

原始 SREV 改造版 `project.json` 震级积木执行验证：保持其震源缓存不清除，
在同一位置代入以上已记录的两个输入，原积木从 M1.29043653 更新为
M1.62043653。证明其震级循环不要求位置变化才更新。这是公式与更新语义
验证，不是完整 SREV 检测流程的等价回放。

参考 M4.6 的会津 150 km 深源窗口也存在该现象：原版 M2.47078189，
当前定位可用站重算 M3.14078189，差 0.67。因此此问题并不限于小震。

## 3. 单源连续震度被再次向下量化

生产 `srevKaizouScratchConvertedShindo` 先经 30 档 `levelFromShindo`，
再取档位下界；小震可损失约 0.33 或 0.5 个震度单位。在未触及零下限、
且单源分支下，当前公式中震度降低多少，震级也降低多少。

会津参考 M3.2 的 2026-06-24 13:24:49 JST 帧：连续震度
1.715069911627876 被转为 1.5；原版 M2.81078189。相同位置和距离仅保留
连续震度的诊断值为 M3.02585180，量化损失 0.21506991，不是深度造成。

SREV 改造版原始目标 `受信と検出` 的过程 `検出許可震度算出`，积木
`_,` 将 `ten:震度100` 写入实时状况列表第 1 项。其单源分支使用此连续值；
它受检测许可条件约束，不能简化成无条件全台网最大值。多源关联槽采用
转换值，不能将两种输入语义混用。

## 4. 最大震度与距离不是同一站的观测对

当前简化公式为 `M = I - 0.94 + 1.73 * log10(D)`（单源、随后下限裁零），
其中 D 是全表最近站的震中距，至少取 20 km，不是产生最大 I 的站的距离，
也不是震源距。距离选择复现了改造版公式，不能单凭偏差认定是移植算错。

- 纪伊候选 21:46:20 JST：最近站距离 24.408 km，最大震度站 NARH01
  距离 69.487 km。同帧连续值代入前者 M1.713、后者 M2.499。
- 钏路参考 M3.0 的完整窗口，单源帧 16:39:08 JST：原发布 M2.161；
  保留连续值为 M2.404，配最大震度站距离后为 M2.882。
- 会津深源窗口末帧：原公式 D=20 km，最强站 FKS010 的震中距约
  133.038 km；深度 150 km 未直接入公式。原发布 M2.471，当前连续值且
  改用最强站距离的诊断值 M4.577。

这些只是一次改变一个计算因素的敏感性分析，不能把接近参考值当作模型
已经有效，更不能直接用最强站替换所有场景的距离。深度修正与多站模型
仍需独立标定及弱震/强震/深源分组验证。

## 适用性与限制

参考 M5.6 样本原版输出 M6.561，并未统一偏小；不能对所有事件整体抬高。
参考 M2.6 的萨摩窗口未产生定位，不能记为震级误差 0，也不能拿它证明精度。
多数样本标签来自用户提供的 JMA、Hi-net 或 EQuake 参考，部分尚待最终目录
核验；所有标签仅在推算后附加。本次不是总体误差统计，也没有证明“大震
普遍准确”。两份原始报告中 all-active 诊断不含后加 timed-only 字段时，
不能用它单独归因报次锁定；应使用 `timing_filter_audit` 分离这两项。

## 下一步实验顺序（不接入生产）

1. 在独立实现中分离定位拾取站和震级观测站，保留事件关联及噪声限制。
2. 独立验证单源连续震度语义，避免把显示用档位当连续输入。
3. 将震级更新条件与定位报次、稳定标记分离，验证峰值保持和事件结束，
   同时防止尾波下降让震级回落或其他事件抬高震级。
4. 上述实现差异处理后，再评估站点匹配的距离/深度模型，不能先拟合常数。

## 外部资料对我方优化的约束（2026-10-04）

- [JMA目录利用手引](https://www.data.jma.go.jp/eqev/data/bulletin/catalog/notes_j.html)：
  速度M与位移M使用指定分量的波形最大振幅、距离/深度项及台站条件修正。
  因此现有连续震度不能直接当作这些振幅，深度对这些模型确实有作用，
  不应把“我方现有函数无深度参数”扩大成“深度不影响震级”。
- [JMA计测震度计算](https://www.jma.go.jp/jma/kishou/know/jishin/kyoshin/kaisetsu/calc_sindo.html)：
  `I=2log(a)+0.94`的a是滤波后三分量合成、满足累计超越0.3秒的加速度，
  不是水平位移，也不是普通PGA；不能逆变换后冒充位移M输入。
- [JMA EEW技术资料，2024-04-11](https://www.jma.go.jp/jma/kishou/know/jishin/eew/katsuyou/reference.pdf)：
  第9至10页使用每站振幅随时间更新M，区分P波、固定和全相阶段，并做质量控制。
  我方吸收的是“定位与震级生命周期分离”的原则，不把GIF当成原始波形照抄公式。
  第14页PGV到震度的关系明确针对震度4至7，不能为解决小震而无验证外推到负震度。
- [山本等（2007）震度震级研究](https://www.jstage.jst.go.jp/article/segj/60/5/60_5_407/_article/-char/ja)：
  论文目标是提高震度预测，定义的震度震级不自动等于目录Mj；不能把另一类M
  与Mj或EQ显示值混合作为训练真值。
- 仓库既有GSTSL研究提供逐站反演、场地项、事件级留出验证的结构；
  中国宏观烈度系数不可直接用于日本实时连续震度。既有PGA/PGV诊断代码的
  `supported=false`和物理量不等价保护必须保留，不因候选更接近某个样本就解除。

## 换算适用域、真实波形滤波与覆盖缺口（2026-10-04）

本轮仍不修改生产算法，不使用EQ或目录震级调整系数。新增工具全部位于
`tools/experiments/equake_replay/`，结果仅写入新建的`.dart_tool` JSON。

### 换算敏感性

核对`srevKaizouMagnitudeFromDistanceAndIntensity`后，现有表达式确实将
`10^((processedI-0.94)/2)`与自身相乘，再取log10。因此等价于
`max(0, processedI-0.94+1.73*log10(D))`。这是算术事实，但单凭此不能断言
重复乘法是笔误，也不能把去掉一次乘法当成正确Mj。该I不是已经验证的位移或
速度振幅，距离项也不能脱离量纲和适用范围直接照搬。

`audit_magnitude_transfer.mjs`读取相同shadow和配对消融报告，验证原输入摘要、
扫描表及站点库摘要，在730个有估算帧、784条最强站行上复核原算术，再只改变
这一指数项。保持站点选择、源位置、20km距离下限、多源分支、零截断不变。

| 案例 | 原公式的同站振幅/距离候选M | 单指数敏感性M |
|---|---:|---:|
| 福岛近海弱震 | 0.55779 | 1.78007 |
| 山梨小震 | 2.54472 | 2.39775 |
| 山梨较强震 | 6.62442 | 4.43760 |
| 和歌山南 | 1.08207 | 1.69678 |
| 会津浅震 | 3.02585 | 2.63832 |
| 茨城 | 1.34510 | 1.79794 |

以上基线是之前的离线同站配对候选，不冒称当前生产最终显示。单指数使一部分
弱信号结果升高，却让山梨较强震大幅降低，不能作为通用修复。没有拟合折中
系数，也没有报告这些已查看样本上的独立留出精度。

山梨两事件共有107个候选站，最终最强站均为YMN002；我方最终估计几何相同，
所以距离项差为0。该站原图峰值分别1.2339419和5.3136409，差4.079699；
原式未截断M差同为4.079699，单指数为2.0398495。参考标签M2.4和5.6的差为
3.2，但参考不是本轮独立查询并冻结的标定标签，估计几何也不是独立真值。
不能用这一对事件反推某个最合适斜率。

JMA目录说明中的位移/速度震级使用指定物理振幅及相应距离、深度修正；不是
将实时震度直接代入其中。Yamamoto等2007年的震度震级MI也有S波走时及站点
修正，作者区分MI和Mj；不能省掉站点项再宣称得到JMA震级。

- CSV按原始字节读取并保存SHA，样本数组只读；不补帧、不插值、不重采样，
  不覆写原始数据。滤波结果为独立派生数组。
- 应用JMA公开的三种频率响应，三分量合成后求0.3秒累计持续阈值，输出
  连续诊断量`2log10(a)+0.94`；没有冒称已执行官方取整得到认证计测震度。

## 原时钟逐秒对照与60秒历史检验（2026-10-04，续）

继续隔离于生产，未改扫描表或公式，未平移原时钟、补帧、补像素或改原始波形。

### 输入与时钟

按上一轮原波形包的精确站码，直接解码原始surface GIF，保留RGB、null及SHA。
会津4站中3站有取色点；山梨242站中213站有取色点。分别读取151帧jma_s，
会津另有151帧acmap_s；所选窗口没有缺失jma_s帧。无坐标站不补附近像素。
两个事件都只用原始CSV的样本时间和manifest的observedAt作UTC/JST转换；
没有使用目录发震时刻校正波形，也没有使用retrievedAt估计历史网络延迟。

此前一秒诊断的第i行代表区间`[start+i, start+i+1)`。本轮分别显式报告
图像标签为该区间起点和右端的两种约定，不按误差择优，不估计或应用lag。
两套约定的有效样本数不同，不把两者的误差差额解释成网络延迟改善。

### 确认存在长时间保持，但没有认定上游实现版本

直接从全部原图读到以下连续峰值平台：

| 站/事件 | GIF峰值 | 首次达到(JST) | 最后保持(JST) | 连续帧数 |
|---|---:|---|---|---:|
| YMN002/山梨 | 5.3136409 | 22:29:08 | 22:30:07 | 60 |
| FKS027/会津 | 0.4398253 | 13:24:52 | 13:25:52 | 61 |

这是图像数据本身的行为，不是应用端额外延长，也不能仅由平台时长反推NIED
当前完整算法。2025年功刀综述第2.2节描述了最新60秒滤波波形内的0.3秒持续
阈值计测震度概算；NIED官网仅说明实时震度为逐次计算的近似值，不足以证明
当前jma_s文件所用滤波版本、初始化状态或具体发布时钟。

前轮整段FFT后按独立一秒取阈值，主要峰值可接近GIF，却没有相同的保持行为。
因此逐秒曲线的大差异不能直接当作颜色解码失败、时钟错位或震级偏低证据。

### 固定60秒诊断及结果

在完全相同的原始三分量波形上复算此前JMA零相位FFT，对已滤波向量取固定
60秒内累计0.3秒阈值。不以观测结果搜索最佳窗口，也不以60个一秒震度的
最大值代替60秒样本排序。前59秒因历史不足全部为null，未缩短窗口或补零。
第i行的60秒区间为`[start+i-59, start+i+1)`；只有右端标签约定将该窗口
明确解释为在图像标记时刻结束。FFT本身仍利用整段未来数据，绝非因果实现。

| 案例/标签 | 有效完整历史站秒 | 一秒FFT MAE | 60秒FFT MAE |
|---|---:|---:|---:|
| 山梨/区间起点 | 4457 | 2.15572 | 0.09321 |
| 山梨/区间右端 | 4440 | 2.14319 | 0.08131 |
| 会津/两种标签均同 | 3 | 4.41153 | 0.10578 |

同一行两种窗口只使用完全相同的一组可比站秒。山梨右端约定包含199个站，
60秒差值GIF-minus-wave均值-0.01151，RMSE0.17148。会津仅有3个可比点，
不能扩展成弱震精度验证，也不能和山梨合并后忽略样本数差别。

山梨已映射站中，完整60秒波形历史共有6340行；1320行图像时刻超出本次
capture覆盖区间，余5020行有图，其中580行像素不可解码，最终4440行有效。
这1320行不表示原capture窗口内漏下载，不能与前述窗口内jma_s无缺帧混淆。

具体示例：山梨YMN002在22:29:49，GIF为5.31364，一秒FFT诊断为0.99836，
60秒FFT为5.37612。该站43个完整历史站秒的MAE由4.21928降到0.11326。
这支持统计时间窗是曲线差异的重要来源，但并不是震级误差从4降到0.1。

### 不可略去的剩余问题

- 山梨4440条中仍有361条绝对差超过0.2。AIC010的24条可比记录平均绝对差
  1.54280，SZO025的39条为0.61884。尚未确定是历史像素映射、因果滤波、
  仪器/波形版本或其他差异，未调整坐标或用邻站替换。
- 两事件完整60秒、GIF非null的可比样本均没有负GIF震度，因此本实验没有
  验证最关心的负震度弱信号域。不能据总体MAE较小宣称弱震测量链已正确。
- 用波形CSV时有0.01gal量化与整段FFT边界限制；不能还原强震计连续运行
  的全部历史和滤波状态。整段零相位滤波与实时因果滤波存在本质区别。
- 没有验证新的震级系数，没有以官方标签或EQ结果参与上述对照。

统计分母、前59秒缺失规则、60秒阈值上下界，以及所有原一秒结果保持不变。

Luna只读复核时钟、null及统计分母，结果一致。实际测试已有输出路径会被拒绝，
拒绝后文件SHA保持不变。生产source_estimation及既有波形/对齐算法Git差异为空。
