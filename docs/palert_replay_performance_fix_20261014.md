# P-Alert 推算、历史回放与预测缓存（2026-10-14）

修改前保存了当前脏工作树中受影响主文件的 ZIP，位置见 `tmp/source-replay-fix-active.json`。未回退其他迁移、公式整改或 UI 修改。

## 修复

- P-Alert 拾取器原先遇到任何非恰好一秒的间隔就清空历史。本轮连续采集的 12 份公开原始 GraphQL 响应，时间从 UTC 09:04:50 到 09:05:12，实际间隔为 1、2、3 秒。现在保留六秒新鲜度范围内真实收到的样本；仍需八个实际样本预热，不补齐缺失秒。超过六秒或数据无效时清空，八秒无峰值改善按源时间过期。
- 移除检测变更回调中重复提交同一 P-Alert 帧的推算入口，保留异步测站流中的正常入口。检出回调仍更新格子、保存记录。
- 按用户要求先接入 P-Alert 震级/预估震度显示：对至少五个被 HYP 关联到同一震源的测站，将各自原始事件 PGA 峰值与自身震源距配对，反解 APP 已有台湾 PGA 衰减模型，再取中位数。公式为 `M_i = (ln(PGA_i / 1.657) + 1.607 ln(R_i)) / 1.533`，缺少站点校正时明确记录单位因子。没有借用 NIED 日本震级标定或其他并发震源的最大振幅。
- 该结果属于模型等效震级初估，卡片标注“PGA 初估”。随后使用已有台湾乡镇预估震度与缓存，徽章和颜色取预测档位；缺少有效震级仍显示无预测。没有完成真实台湾地震的精度标定，也没有宣称它是官方 P-Alert 波形 ML。
- 历史测站回放原先只恢复检出和地图快照。现在每一帧在显示合并之前交给独立 worker，源估进入地图和统一 UI。原始时间、幅值、EEW 报文不改写；不向实时 tracker、录制器、TTS 或自动化发布。停止/重启用 generation 丢弃旧输出并释放 worker；真实 EEW 优先显示。P-Alert 的 CWA EEW 隐藏规则区分实时与回放。
- NIED 地图波圈在历史回放中使用该帧原有 `wave_elapsed_s` 加回放位置相对接收时间的增量，避免拿历史发震时间直接减电脑当前时间。
- 日本全网源估预估震度加入 32 项 LRU，键包含未舍入的震级、深度、纬度、经度，模型和测站集固定。没有减少测站、降低精度或修改预测公式。
