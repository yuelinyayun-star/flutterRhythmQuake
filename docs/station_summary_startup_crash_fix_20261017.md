# 测站摘要启动闪退修复（2026-10-17）

用户报告启动后自动退出。Windows 应用事件及本地转储确认 Debug 进程发生 `0xc0000005` 写入访问异常；其原生 DLL 与本轮构建输出一致，并非旧库未更新。

## 已复现的路径

崩溃处为 Dart Debug JIT 的 `_ExternalUint32Array.[]=`，调用方是 `NativeStationSummary.update`，上层为侧栏摘要投影。读取转储并在受调试进程异常时读取调用帧对象，确认了该路径。

独立复现先提交空测站帧，再提交不断增长的测站数组。修复前约 2000 次更新后发生与 APP 相同的访问异常；已有正常数值与原始报文测试没有覆盖这个 JIT 转换场景，因此此前测试通过不能证明启动稳定。

复现程序和修复前桥接源码保存在 `tmp/crash_startup_20261017` 及 `tmp/reproduce_summary_growth.dart`。没有修改原始地震报文来制造复现。

## 修复

摘要桥接不再创建零长度的外部 FFI TypedData 视图：空目录偏移、空数值帧、空活动标记与空字符串走可复用的自有空视图/空字符串；非空数据仍直接使用原生缓冲。原生调用仍收到有效指针和原始长度，原生清空、排序及计算行为保留。

本次只修改摘要桥接和对应回归测试，不回退原生计算，不修改 UI 布局、过滤规则或云端。修复前文件已单独备份。

## 已完成验证

- 原独立 Windows JIT 复现连续完成 20000 次更新。
- 新增空帧、增长、反复清空及资源释放压力回归。
- 摘要、NIED 数组观测、KA 历史共 19 项 Flutter 原生回归通过，保留原始 WHEWS 与 GIF 对照。
- 修改文件静态分析无问题，Windows Debug 构建通过。

完整 APP 核验：使用修正后的 Debug、现有本机设置和真实源连接，连续采样 125.7 秒，窗口持续有响应；最终身份复核时进程已运行 255.6 秒，未出现新的退出、转储或该进程的 Windows 崩溃事件。采样记录保存在 `tmp/crash_startup_20261017/fixed_runtime_125s.json`，随后确认 PID、路径及启动时间，只停止了测试进程。

Debug 与 Profile 最终构建均通过，两者原生 DLL 哈希相同；本轮只改 Dart 桥接边界，Rust 库内容没有变化。上述结果验证了已复现的启动崩溃修复，没有将短时观察当成所有源、所有回放场景的长期稳定性证明。
