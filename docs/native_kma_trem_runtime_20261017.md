# KMA、TREM 实时数据链原生迁移（2026-10-17）

本批迁移 Windows 正式地图中的 KMA、CWA/TREM 实时测站处理。修改前文件保存在 `tmp/native_kma_trem_20261017/before`；未修改云端、其他地震源的过滤或震级/烈度规则，未构建 Android。

## 已完成的边界

原始 WS / HTTP / SSE → 原有 WinHTTP 原生传输 → Rust 源会话 → 原生解析、观测状态、检出及格网 → 编码完成的有限显示快照 → Flutter 绑定视图和绘制。

`native/station_core/src/station_runtime.rs` 持有连接、认证、心跳、超时、重试、目录与最新观测；原生传输的通知直接回到 Rust 接收队列，原始网络响应不再先回 Dart。不同源/连接会话使用不复用的身份，停止后关闭原生端及 UI 端口。

- KMA：PEWS、现有 FAN 选项、WHEWS 与 Jian 的连接入口；保留各自时间和报文解释；MMI 整帧校验、严格递增时间检查、缺帧、60 帧历史、保持窗口、邻站检出、12.5 秒活动到期及上升/结束通知。邻站仅保存 30 公里内的索引，删除原来未被消费的完整 N×N 距离矩阵。
- TREM：目录、可选登录/刷新、SSE 主链路、JSON 备用链路、节点切换、过期检查、观测合并、震度排序及分档通知。未将连续心跳当成有效观测。
- 两者：图层变更签名、自动化输入行、格网保持状态、分级与四角顶点由 Rust 准备；现有 Flutter 配色、标记、闪烁和绘图样式继续使用。TREM 当前显示分级也随快照返回。
- 显示快照、最新历史快照和原文的编码均发生在生产线程，FFI 取显示结果仅交换缓冲和固定归档引用，不在 UI 线程重新遍历/编码原生对象树。普通显示不带 KMA 的完整历史；历史捕获按需读取与该显示帧绑定的原文和历史快照。
- 源关闭时删除依赖该原生会话的惰性历史入口，防止随后读取已经释放的会话。历史归档系统的其余编排仍沿用现有实现。

## 尚未完成的范围

这不是整个应用已经原生化的声明。其他台网、统一事件合并和语音决策、全局地图相机策略、历史/回放会话及归档调度仍有 Dart 逻辑；回放图层和非 Windows 分支保留既有路径。本批普通实时路径的历史捕获接现有系统，不代表整个归档/回放系统已经迁入 Rust。

WHEWS 认证和登录刷新分支已按现有协议实现，但本批没有使用真实凭据进行带认证的端到端验收；实际联网验收覆盖 PEWS、Jian KMA 和匿名 TREM。实时验收时没有活跃检出，不能将这些空格网的联网结果当成真实强震告警的演示。

本批没有提供完整 APP 同设置、同输入的 CPU/RSS 前后对照，因此不宣称整机占用下降百分比。已核实的是上述正式运行链离开 UI 线程并由 Rust 持有；Flutter 布局/绘制慢帧与后续链路仍须分别处理。
