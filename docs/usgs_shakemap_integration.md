# USGS ShakeMap 地图接入

- 数据来自官方 USGS 周列表的原始 `properties.detail`、`types` 和 `updated`。产品加载独立于统一信息卡的显示时长，桌面端检查完整周列表中的前 50 个 ShakeMap 事件。
- 详情读取 `properties.products.shakemap`，按 `preferredWeight`、`updateTime` 选择当前产品；删除报不重新启用旧产品。
- 使用当前产品的 `download/cont_mmi.json`，把官方 `MultiLineString` / `LineString` 绘制为现有地图上的等烈度线。原始 MMI 数值、坐标、颜色和线宽直接读取，不转换成中国烈度、不重采样、不再加载底图覆盖图片。
- 新产品或新版自动在地图展示 2 分钟。启动时已有的历史产品只建立基线；普通详情更新时间变化但 ShakeMap 版本未变，不重复展示。
- 点击 USGS 列表事件加载对应产品，选中期间持续显示；再点击取消。列表小图层图标表示官方列表含 ShakeMap。地图底部显示版本、产品更新时间（电脑时区）及原始 MMI 线色说明，线条附 MMI 数字标签。
- 使用 FlutterMap 镜头投影、历史震中标记及现有地图取景方法。按镜头选择经度世界副本，不修改原始坐标；支持日期变更线及旋转。下载或解析失败时保留同一事件的旧线；换事件和取消选择使旧请求失效。缓存最多 20 场地震的线数据，持续显示不闪烁。
- 原始 GeoJSON 合法但等烈度线集合为空时，手动选择显示“USGS 本版无可绘制的 MMI 等烈度线”；自动加载不跳转空图层，也不构造替代线。
- ShakeMap 新产品或新版自动显示期间，使用独立的 `usgsShakeMap` 信息卡参与统一 UI 轮播，标题为 `USGS ShakeMap 烈度速报 第N版`，徽章显示产品原值对应的 MMI。卡片保留绑定 USGS 事件的原始 ID、震源参数和发震时间；普通 `usgsEqlist` 卡片独立显示，即使属于同一地震也不与产品卡合并。产品到期只移除产品卡，不影响普通信息卡；不重新进入实时接纳队列，不触发语音或警报。
- 列表手动显示与自动产品卡分开管理。选择另一机构或另一条 USGS 历史记录不会吞掉自动产品卡，也不修改实时事件队列。同机构不同事件保留各自展示项并轮播；选中历史记录与实时卡属于同一事件时，沿用实时最新报文。取消手动显示只移除该选择，自动产品到期也不会取消手动选择。
- 所有列表项的“地图显示”和行点击共用选择链，同时把原始事件转换为统一信息卡；取消或切换地图选择时同步清理或替换。手动选中期间持续展示，原始发震时间、震源参数、报次和 API 来源不改写，复用现有信息卡布局及轮播。
- ShakeMap 与 USGS 信息事件共用来源震级过滤：0 不过滤，负值不接收，正值为最低震级（包含等于阈值的事件）。自动更新与列表选中加载都受此设置约束；设置收紧时移除不符合条件的图层，正在返回的请求不能重新显示被过滤的事件。产品身份、原始震级和地图数据不修改。

## CENC 列表关联

现有 CENC 列表已接入 FAN / NowQuake 烈度速报关联。匹配事件 ID；不同 API 的 ID 不同则必须同时符合发震时间（1 秒内）及坐标（每轴 0.011° 内，兼容目录 0.01° 的舍入）。地点名字不作为匹配依据。源时间按 UTC+8 还原，显式带时区的报文按原时区处理。

匹配成功的列表项显示波形图标，点击请求原有烈度速报详情并复用 CENC 图层。选中历史事件时不混入另一场实时地震的烈度图；详情和列表更新仍受选择序号保护。取消选择恢复原实时图层。无对应速报的地震只显示震中。

## 海上事件烈度显示修正（2026-10-14）

截图事件 `us6000u214` 第 1 版原始产品为 M6.9、深度 10km。
`maxmmi` 为 `nan`，但 `maxmmi-grid` 为 `8.195`；原始 info.json 同样提供
`MMI.max_grid=8.195`。产品解析先接受有效的 `maxmmi`，否则读取有效的
`maxmmi-grid`，数值必须有限且处于 `(0, 12]`。两项均无效时仍显示未知，
不根据震级或等烈度线最大级别制造产品烈度。该栅格峰值属于 ShakeMap 模型，
不表示台站实测；统一 UI 第 1 版显示 MMI VIII 并复用现有 VIII 级颜色。

本机 APP 保存的同事件 WHEWS 去重记录显示后一次烈度字段从 `9.0` 变成 `0`。
原代码把非空 `0` 接受为有效烈度，罗马数字显示又将其钳制为 I。
WHEWS 的 USGS 信息适配现只接受有效的正烈度；零、非数值或越界值沿用
既有缺失烈度的本地 CSIS 估算规则，前提是震级、深度可用。
有效的 I 级报告仍显示 I，不因震级较大而覆盖它。原 `sourcePayload` 保留不变。
普通信息卡的本地估算与 ShakeMap 的 MMI 产品值继续独立。

原始捕获、散列及保存记录说明见 `test/fixtures/usgs_intensity_20261013/README.md`。
新增回归覆盖截图对应第 1 版、非有限/越界数值、有效低烈度、原字段保留，
并通过真实 AlertModule 检查手机轮播与桌面双卡片的徽章颜色和布局。
