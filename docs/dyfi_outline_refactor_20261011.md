## 保留的修改

`lib/widgets/map/usgs_dyfi_layer.dart` 原来在每次国界重绘时投影所有 288 个多边形、10,654 个原始顶点，然后判断路径是否在画面内。现在加载时记录各环的保守边界框，先排除画面外的环，再调用原路径投影。经度跨度达到 180° 的环仍完整投影，日期变更线、世界副本、洞和极区不裁剪原坐标。Mercator 四角的屏幕包围框包含旋转后的环，并留出描边和浮点边界余量；其他 CRS 保持完整路径处理。

共享路径函数去掉中间的包装坐标列表，仍以同样顺序调用 `WorldWrap.longitudeClosestTo` 和相机投影，保留全部原点及闭合点。格网颜色、填充透明度、描边、命中测试、列表、统一 UI、震级过滤和产品生命周期未改。

国界已经由静态 Future 缓存解析结果，原来 `rootBundle.loadString` 又保留原文。本轮设为 `cache: false`，解析后的原始坐标仍共享，只去掉重复文本。

## 同一 Profile 二进制的组件实测

冻结本轮前的完整组件和当前组件，原始数据不改。固定 120 视角预热后，10 轮交替执行原版与新版；统计为国界投影与绘图指令记录的批量耗时，不是 FPS 或 GPU 光栅化耗时。

| 指标 | 原版 | 新版 |
| --- | ---: | ---: |
| 120 视角平均批量耗时 | 902.7233 ms | 279.3117 ms |
| 每批实际进入完整路径投影的多边形次数 | 34,560 | 6,696 |
| 独立组件 GC 后平均 Dart 堆 | 29.9621 MiB | 28.4673 MiB |
| 独立组件 GC 后平均单点 RSS | 244.4102 MiB | 237.0957 MiB |

投影及绘图指令记录耗时减少 **69.06%**；组件 Dart 堆减少 **1.4948 MiB**。内存采用原版→新版→新版→原版四个独立进程，实际保留同一个原始 DYFI 产品及其 15 个格网。RSS 是 GC 后单点，不能作为整机常态内存收益。

首轮耗时采集与测试进程有重叠，保留其日志但不用于上述耗时结论。正式耗时来自测试及其余组件进程均结束后的 `comparison-isolated.json`。初次测试的参考辅助文件遇到 `Path` 导入重名，限定 `LatLng` 导入后重跑成功。
