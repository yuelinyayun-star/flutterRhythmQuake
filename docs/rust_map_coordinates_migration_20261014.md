## 实际改动

本地保留 flutter_map 8.3.0 源码与许可证，在 `getOffsetsXY` 中消除对拼接洞环迭代器反复调用 `elementAt` 的重复遍历。Windows 的静态 CRS 坐标批量变换交给 Rust，几何输入按原投影点列表弱引用缓存，输出缓冲重复使用，几何 owner 由 NativeFinalizer 回收。系数、运算顺序、顶点、洞环、世界副本与可见范围沿用原实现，无降精度、抽样或 FMA 改写。

测站历史捕获使用共享字段布局的不可变 Map 接口，减少每站字符串键 Map 和二次递归复制；全部 27 个字段及观测子字段原值、键顺序保留。ISO 日期字符串只在同一帧内按时间及 UTC 标记复用，UTC/本地日期不会混用。源对象之后变化不会修改已经捕获的历史，捕获结果可以传入写盘 isolate。

删除 detection snapshot 回调里一次重复的整图 `setState`。测站及检出网格继续由原 `_niedLayerRevision` 更新，推算事件及震源标记继续由原 `currentNiedEvent` 监听器更新；真实震源事件更新仍保留。

## 等价验证

地图几何覆盖 22 个桌面/窄屏视图，包括旋转、洞环和世界边界，原标量渲染与原生坐标路径逐像素一致；原始顶点 float64 位也一致。原始奈良 GIF 的 51 帧逐站验证历史全部字段、顺序及冻结行为，并检查日期、嵌套容器和 isolate 传输边界。

测站圆点分组实验保持每个圆点的原 `drawCircle` 原语，Rust 仅规划连续同样式且抗锯齿覆盖矩形互不重叠的组。24 个原始测站视图（含旋转、重叠、世界副本，DPR 1/1.25/2）逐像素一致。但是完整 APP 复测发现帧数减少，最终未采用，生产代码恢复实验前画法，原生分组模块及测试移出生产工程，保存在备份目录的 `circle-experiment/`。曾尝试的 raw points/path 画法在完整旋转/原始测站对照中存在像素差异，也未采用。
