## 修改

`TravelTimeService` 用于 P/S 波圈、到达倒计时、本地预警面板和部分震源阶段判断。原实现每次查询都先对全部距离列生成插值数组：JMA2001 每行 236 列，JB 每行 81 列。

- 按距离求走时只计算最终相邻两列；按时间求波圈距离则按原前向扫描顺序逐列计算，查到位置即停止。
- 保留原来的深度索引选择、负数处理、外推行为及乘加/除法顺序；没有改成二分查找，也没有引入表格单调性假设。
- 原深度、距离和 P/S 走时数值完整存于 Float64List，替代逐项持有 double 的普通列表；不降精度、不改数值、不重采样。
- 原有按需加载、并发合并、加载通知、测试重置及不缓存原始文本的逻辑保留。

上一次已有的 `cache: false` 不是这次新改动。此前工作区修改均保留。
