# JMA 海啸左侧列表

## 显示

- 左侧地震列表按警报等级独立显示：JMA 大津波警報、津波警報、津波注意報、津波予報；部分解除区域保留其状态，全部解除或取消后清空左侧海啸卡片，原报仍保留用于旧报拦截。
- 与地震历史分开，历史为空仍可显示海啸；沿用 JMA 来源开关，海啸不套用地震震级筛选。
- 左下信息列表恢复原有地区预报分级卡片，每行两个区域，区域／到达／预计波高对齐；不插入站点预报或观测卡片，验潮站数据在右侧海啸页显示。
- 到达时刻转换到电脑本地时区，只显示 HH:mm；到达状态放在同一列。
- 左下卡片按内容取 1／2 格，最多两格；超出内容继续每 12 秒分页（2026-10-22 调整）。
- 海啸信息卡片在历史事件之前，共用一个可滚动列表，不是固定悬浮置顶。
- 鼠标悬停、详情弹窗、页面 TickerMode 禁用或应用失活时暂停；恢复后重新计时。
- 区域详情保留完整到达时间、原状态文字；“公告”可查看报文摘要。
- 地图、声音和海啸更新合并规则保持原流程。

新增支持当前 `area` 数组，同时兼容旧归档的区域字符串。保留 EventID、报次、原始时间、截止时间和 sourcePayload；局部 cleared 不按整报 cancel 处理。

版式参考 NHK 公开的历史画面说明中“区域 / 到达时刻或状态 / 预计高度”的固定列结构，来源为消防厅报告 PDF 第 153 页（印刷页 148）：
https://www.fdma.go.jp/singi_kento/kento/items/kento106_01_p0.pdf#page=153

文字缩写：`津波到達中と推測` 显示 `到達と推測`，`ただちに津波来襲と予測` 显示 `すぐ来る`。原状态仍保留；未知状态显示原文。

波高只用原报数值/描述，保留“巨大”“高い”“10m超”“0.2m未満”；不按警报等级自行生成波高。缺失为“未知”。

## 原生边界

- `native/station_core/src/jma_tsunami.rs`：原文适配、等级分组、波高展示文本和状态短文本。
- `native/station_core/src/jma_tsunami_sidebar.rs`：地区与验潮站关联、站点预报和实测合并、等级排序、按可用高度进行单列／双列分页。保留原始输入，不按站名合并两个明确不同站号的站点。
- `lib/services/native_jma_tsunami_io.dart`：FFI 编解码，实时解析与分页通过短生命周期 isolate 调用 Rust，不在 UI isolate 执行源数据解析/分页运算。
- `lib/widgets/ui/jma_tsunami_sidebar.dart`：右侧海啸页的字体和布局测量、绘制、UI 页码状态、12 秒显示定时器，测量结果交给 Rust 确定分页。`jma_tsunami_list_card.dart` 继续用于左下信息列表的原有分级卡片。
- 目前接入已有 Windows native core。其他平台沿用原有来源解析路径；本轮未新增 Android 原生库或编译 Android。
- JMA 新增的报文接纳、独立报次、旧报拦截、同报补全与观测更新由 `jma_tsunami_observations.rs` 处理。其他机构仍沿用既有生命周期；语音调用沿用既有入口。

## 站点预报与观测

- 右侧栏每项只展示地区名称、截至目前实测最大波高和区域预计波高；第一波、站名等字段在点击详情中查看。左下信息卡片保留地区预报的原有展示。
- 波高和最大波时间持续按报文更新，不把第二次报文称作第2波，也不从更新次数推测波次。观测中、上昇中、以上、欠測和第一波識別不能按原值保留，未知不变成零。
- 参考 NHK 广报局的预报／观测分区与简洁列表原则：https://note.com/nhk_pr/n/n30dcf25c50f2 。该资料没有提供逐次第2／第3波的数据结构；第一波、最大波含义依据 JMA 官方说明。
- VTSE41 与 VTSE51 分别保存报次和时刻，避免警报第7报拦掉观测第1报；观测更新不清空仍有效的预报，观测取消不撤销有效警报。取消／解除之后的迟到旧观测不能恢复旧显示。
- WHEWS 初始聚合分别保留两类最新电文，JMA 海啸的内容去重在 Rust 中计算，第一波单独变化也能进入更新。
- 站点预报读取 `areas[].stations`，实际观测读取文档明确的 `observations[].stations`；不将站点预计到达解释为实测。Jian 相同字段形状可进入共用适配，未有样本证明的其他形状不猜测映射；P2P 552 不提供站点实测。

## 验证

原始官方 XML 与 Jian 文档原样本参与测试，不改写事件时间模拟新报。协议边界测试单独标注，不当作实时事件。

预览为 JMA 官方历史样本，不是实时警报。
