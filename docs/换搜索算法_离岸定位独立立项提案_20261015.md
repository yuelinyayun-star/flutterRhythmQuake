## 1. 立项背景：问题量化

离岸震级偏高的根因**在定位层**（震级公式与发布锁各贡献一部分，已分别整改）：

| 指标 | 内陆 | 离岸（干净子集） | 倍数 |
|---|---:|---:|---:|
| 末帧震央中位误差 | 7.2 km | **22.2 km** | **3~6×** |
| 末帧震央平均误差 | 8.2 km | 28.6 km | 3.5× |
| 逐帧震央抖动（多格/大跳） | 单格、零抖动 | 最高 234 km/147 km | — |

**放大链**：离岸台站**全在一侧（陆上）** ⇒ 震中经度 ⇄ 深度 ⇄ 发震时刻**近似简并**（把震央往海里推、用「变浅/提前发震」补偿，代价面几乎不动）⇒ 搜索落点偏海。

**代价**：震级用的 `D = 震央→最近 scratch 站距离`在离岸侧退化为**单一孤立海岸站的距离**，随离岸位移线性增长（≈8.7 km/0.1°），经 `1.73·log10(D)` 放大 ⇒ **每 20 km 离岸位移 ≈ +0.5 Mag**。宫城県沖 22:05：官方格公式 M=3.471（对官方 3.5 偏差 −0.03，近乎完美），App 震央格 M=3.91（+0.41）——**公式没问题，震央放错**。

## 2. 现状契约（为什么不能继续小修）

现状不是「参数没调好」，而是**搜索形态本身**在离岸平坦面上必然陷入单轨迹局部解，且其行为被**参考一致性契约**冻结。

### 2.1 Rust 定位内核（`native/station_core/`）

**搜索器** `src/hyp_search.rs`：

```rust
const STEPS: [(f64, f64); 4] = [(3.0, 100.0), (1.0, 50.0), (0.3, 20.0), (0.1, 10.0)];
```

- **四段贪心爬山**：最细 **0.1°（≈11 km）**；每步只试 **6 个轴向移动**（±lat / ±lon / ±depth），**无对角**。
- **严格 ties**（`+1e-9` 才判改善）；**经度无界**、纬度限 `[-90,90]`；**全局 1000 次迭代上限**。
- **单轨迹**：`current` 只朝**立即改善**方向走，一旦进入平坦区**不会主动跳出**。

**打分器** `src/hyp_score.rs`（`Scorer`）：

- 目标是**纯走时残差**（加权 RMSE）——**不用振幅、不用方位**；
- 6 个场景 `PP/PS/P_PREV / SP/SS/S_PREV`（P 侧 + S 侧各取最优）；
- 「未触发站」只有一个**很弱的线性罚** `penalty = penalized/count`，且 `count ≥ 50` 权即归零；
- 输出契约 `output[99]`、`waves[2*count]`、搜索日志 `32 doubles/row`。

**契约冻结声明**（`include/rq_station_core.h:172-174`，原文）：

> "Search **preserves four steps, six neighbor order, strict ties, +1e-9 move threshold and global 1000-iteration limit**. Longitude remains unbounded."

⇒ **改步长 / 加对角 / 改邻域 = 破坏 ABI 参考契约 + 全量并行快照**。此前已实测「步长本身只值 ≤0.09 Mag/格」，**不是主因**（证据 1 单格）。

### 2.2 Dart 侧驱动（`lib/core/source_estimation/source_estimator.dart`）

- **种子 = 最早触发站质心**（`:11244`）——离岸事件最早触发站都在**岸上/西侧**，种子天然偏陆侧；
- **热启动 = 上一帧结果** ⇒ **路径依赖**；
- 原生 Rust 与 Dart 参考搜索**数值等价**（证据 6 副产品：`dart_free` 与 `off` 逐字节相同）——**Dart 侧不存在独立误差源**，问题在两侧**共用的同一种搜索形态**。

## 4. 立项理由：J3 是首个正向证据

J3 在本语料上是**唯一**做到以下两点的杠杆：

1. **干净离岸误差单调改善**（随权重 `w` 上升：28.6 → 28.6 → 28.1 → **24.8**（w=3）→ 26.0），是**单杠杆最大改善**；
2. **单事件近精确**：岩手県沖 06-28（233 站）由 18.9 km **校正到 3.6 km**（Δlon +0.163 → −0.037，几乎落在官方经度）——**方向与幅度都对**。

**但失败模式同样明确且可归因于搜索形态**：

- w=3 时離岸**種子島**（仅 9 个强度站）发散至 **12614 km**；w=6 时内陆**熊本**崩到 1373 km；
- 「站点数下限」护栏（≥20/≥50 站）**挡回離岸種子島**却**把内陆熊本搞崩**——**把一个灾变换成另一个灾变**。

⇒ 失败**不在信息，在搜索**：0.1° 六邻贪心爬山**路径敏感**，并入振幅项后末帧在「近官方格」与「伪吸引点」之间翻转，**任何硬阈值都压不住**。**要真正用上振幅信息，必须换掉搜索形态。**

## 5. 拟替换的搜索形态（三候选）

> 目标的共同特征：**全局、多峰容忍**，把**走时 + 振幅（+ NYAD 负证据 + 可选方位）**放在**同一个似然**里做推断，不再依赖单轨迹爬山的「只朝改善走」。

| 方案 | 形态 | 优点 | 主要风险 | 建议 |
|---|---|---|---|---|
| **A 集成粒子滤波（IPF）** | N 个粒子在 `(lat,lon,depth,origin,M)` 上按**乘积似然**加权 + 重采样 | 即 JMA/IPF 原法；天然多峰、给后验不确定度；一次容纳全部信息通道 | **随机性**——与本项目「逐字节相同」的确定性测试文化冲突；需**固定种子的确定性 RNG** | **终态目标** |
| **B 多起点 / 多峰** | 保留现有 `Scorer`，从 K 个种子（网格 / 各站质心）各跑一次，取 top-K 聚类 | 复用现有打分，改动最小 | 每条轨迹**仍是局部爬山**；K 倍开销；离岸平坦面上仍可能全收敛到同一伪吸引点 | 备选 |
| **C 全局粗网格 + 后验 + 局部精化** | 粗网格（如 0.2°）全扫 `Scorer` 得分 → 取 top 模态 → 局部细化 | **确定性**、可复现、易验证；直接暴露多峰结构 | 网格 + 细化两阶段、开销可控但需调档 | **推荐先做（低风险跳板）** |

**推荐路线**：**先 C 后 A**。
1. 以 **C** 作为**确定性跳板**——不引入随机性，天然满足现有测试契约，可快速验证「全局多峰能否在离岸把末帧拉回官方格」；
2. 若 C 成立，再以 **A（IPF）**为**终态**，用**种子化确定性 RNG** 保持可复现。

**关键设计要点**（三方案通用）：
- **似然 = 走时残差 + 振幅残差（J3 已验证有效）+ NYAD 负证据（J2 方向正确）**，权重按已验证区间（如振幅 `w≈3`）起扫；
- **多峰保留**：不坍缩到单一最优，而是保留 top-K 模态给出**多个候选震源**（这本身也改善离岸「结论不唯一」的表达）；
- **护栏内生于似然**：把 J3 的「站点数下限」从**硬阈值**改为**似然项权重随站数衰减**（稀疏站自动降权），避免「硬护栏把内陆搞崩」。

## 6. 不破坏现有 ABI 的落地方式

**核心原则**：**新增**一条搜索路径，**不动**现有契约与生产默认行为。

1. **新增 ABI 符号**（不修改既有 `rq_hyp_score_search`）：例如
   - `rq_hyp_search_grid_abi_version()` / `rq_hyp_score_search_grid(...)`（方案 C）；
   - 后续 `rq_hyp_search_pf_abi_version()` / `..._pf(...)`（方案 A）。
   现有 `rq_hyp_search_abi_version() == 1`、四段契约、日志格式**全部保持不变**。
2. **Dart 侧默认关闭开关**：扩展现有 `NiedHypStartShadow` 影子机制（已默认 `false`、可无损回退），加 `searchForm`（`greedy`(默认) / `grid` / `pf`）。
3. **回退 = 关开关**：生产默认仍走原生四段贪心；新路径仅在显式开启时启用。

> 与既有七次影子实验一致：**全程 Dart/影子层或新 ABI 符号，不动生产默认路径**。

- **决定性机制**：北海道東方沖的**全局最优模态**在 (39.35,141.00,10km)、s=0.393，**距官方震央 682 km**——比贪心局部解（61.9 km）**更低分且更远**。即**现行纯走时 Scorer 的全局最优本身就是伪盆地**。
- **裁决**：**No-Go（方案 C 作为直接替换形态）**。但§10 末句「应止于 L5」**不成立**——正确读法是**改向**：
  1. 证据 9 证明「全局形态 + 现行似然」必然放大伪盆地；证据 8 证明「新信息 + 贪心形态」必然路径敏感；
  2. 两条**单变量**路线均已实测触顶 ⇒ 下一步是它们的**交汇点**：**联合似然**（走时 + 振幅[J3，几何自适应权重] + 深度弱先验[非 J1 定格] + NYAD 负证据[J2，阻尼]）× **全局多峰形态**（C 已验证可显式枚举伪盆地）；
  3. 多峰后验的**诊断价值**成立（伪盆地变成可枚举的 `grid_modes` 列表）；Dart 全扫开销 20–30×（山梨 >55 min），**Rust 化是任何后续的硬前提**。

**生产影响：零**。生产逐位验证：`off` 模式复跑与 10-14 存档**逐帧完全一致**（73/73 帧估计与诊断键相同，无 `search_grid_shadow` 键）；回归 + 影子单测 **56/56 绿**。
