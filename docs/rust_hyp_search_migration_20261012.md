## 保持的搜索规则

四阶段依次为经纬度 3/1/0.3/0.1 度、深度 100/50/20/10 km。保留经度正向、纬度负向、经度负向、纬度正向、深度负向、深度正向的候选顺序；平分不替换，仅 `candidate.score + 1e-9 < current.score` 时移动；全局最多 1,000 次迭代。保留深度 0–700 km、纬度 -90–90 度、非有限值拒绝的优先级；参考模式的经度保持原来不设边界的行为。

Rust 复用当前、最佳和待评估三个数值结果缓冲，只记录实际移动及每阶段最后一轮候选。最终通过独立拥有的 Float64/Int8 数组导出，Dart 一次恢复全部原诊断 Map；返回对象不引用原生内存。

测距继续使用原 Dart 三角函数和运算顺序。Rust 通过同步、同线程的 `NativeCallable.isolateLocal` 请求距离；调用结束立即关闭回调，Rust 不保存函数指针或借用数据，不跨原生线程调用，也不重入评分会话。回调失败返回明确状态并传播原异常。

一次搜索内，最多缓存 8 组经纬度的原始距离数组；键是两项 Float64 原始位，区分正负零，不量化坐标。淘汰时复用数值缓冲，搜索结束释放。深度变化可复用同一地表距离；没有跨帧缓存或无界增长。原始样本中 1,066 次评分对应 766 次实际测距、300 次精确复用，评分次数不变。
