# 日本周边海域离线地名接入

本页记录最初海域接入。后续已补全日本实际陆地并物理裁剪重叠，当前查询行为见
`east_asia_effective_names_20261020.md`；原海域源文件和本页来源记录保持可追溯。

日期：2026-10-20。

原有日本周边查询仅使用全球FE粗网格，日本陆地遮罩用于防止台湾海域覆盖日本岛屿。
本次新增120个海域及岛屿周边分区，通过现有`getFEName`调用链供坐标转中文使用。
日本陆地、其他国家、台湾陆地/近岸优先级及既有历史名称处理保持原逻辑。

数据由0Quake依据JMA官方区域图整理，为第三方描绘矢量，不能称为官方GeoJSON。
120个分区使用原始几何，未抽稀、重画或加缓冲；原始档案及显示别名分开保存。

- 来源及全部名称清单：`assets/regions/japan_sea_regions.provenance.json`。
- 构建及命名规则：`tool/region_data/README.md`。
- 公共来源：https://github.com/0Quake/JMA_Region/tree/a7ee5949d8df9879dd081eec21142a37622e9f3a 。
- JMA官方参考图：https://www.jma.go.jp/jma/press/0609/20b/20060920bessi3.pdf 。
- 我国钓鱼岛基线声明：https://www.fmprc.gov.cn/web/wjb_673085/zzjg_673183/bjhysws_674671/bhsmgb/201209/t20120910_320427.shtml 。

钓鱼岛、赤尾屿分别使用我国声明所列闭合基线坐标建立名称查询区，显示为台湾省相应岛屿区域。
它们只是基线围合区域，不冒称精确海岸线、全部领海或专属经济区。
与东海重叠的源858、859、860分区统一显示“东海”；千岛及国后、择捉只使用地理名称，
不附加日本归属。中国现有行政区与台湾海域仍优先于新分区。

新增几何查询在Rust完成，只读数据编译进DLL；Dart仅传坐标和解码UTF-8结果。
当前既有FFI宿主是Windows，其余平台继续原有查询。运行时不增加联网或轮询。
本次没有改地图绘制、统一UI布局、事件接纳、原始报文或历史记录。
