# NIED HYP 输入复用验证（2026-10-13）

本轮处理上一轮定位的重复输入解析，SDK 保持 Flutter 3.41.1 / Dart 3.11。NIED 驱动生成的测站快照同时提供原字段 Map 视图和 HYP 类型视图，供已有 Rust 数值内核直接读取。入口不再复制每站 Map、经纬度列表、再创建一份解析结果。固定邻接表在推算 isolate 内按首次访问建立只读 Set，随所属拓扑对象释放；缓存采用静态 Expando，不作为结果对象字段跨 isolate 复制。

这轮是 Dart 数据通路优化，没有迁入新的 Rust 算法。前后使用 SHA-256 相同的上一轮 Rust DLL，隔离重链接造成的变量；新构建的 DLL 另存供核对。原生评分、搜索、事件归属、报数、过滤、语音和 UI 均沿用现有逻辑，测站记录状态本身尚未迁完。
