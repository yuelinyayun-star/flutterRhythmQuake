# NIED 归档会话迁入原生后端（2026-10-16）

## 热点依据

对正在运行的 Debug 进程 18616 采样 30 秒。主 isolate 310 个样本中，项目调用 `_tick` inclusive 33、`NiedReplayLogger._writeSync / _autoSave / logFetchParse` inclusive 24，包元数据写入 inclusive 13；这些调用包含关系不能相加，也不是完整 APP CPU 百分比。NIED 推算 isolate 共 16 个样本，观测适配 inclusive 7；该窗口没有覆盖所有预警/推算活跃场景，因此本次选择当前明确的主线程归档热点，不能称它在所有场景下绝对最重。

原始采样及函数汇总：`build/performance/dart_hotspots_20261016/`。采样前 profiler 已开启，完成后恢复原设置，没有关闭用户窗口。原始样本压缩保存，仅另生成汇总，不改事件报文。

旧归档器在 Dart 长期保存全部记录 Map、GIF 元数据 Map 和去重集合；每满 80 条且间隔 15 秒，将累计记录重新 pretty JSON 编码并同步写桌面日志、包内日志两份，再重新编码包清单。这使记录越多，每次保存的处理和临时缓冲越大。

## 本批实际迁走的职责

`native/station_core/src/replay_log.rs` 提供独立、有序的原生归档会话，负责：

- 持有最近 30 张原始 GIF 缓存、会话与文件名去重状态。
- 记录计数、80 条/15 秒自动保存调度、停止时的尾部保存和写盘失败重试节流。
- 原始记录和 GIF 元数据写入原生长度前缀 journal；正式写盘模式不保留整批记录或元数据对象图。
- 流式、增量发布桌面日志、包内日志和 capture_manifest。两份日志保留相同数据；晚创建 capture package 时从 journal 补齐之前的全部记录。
- 原始 GIF 写入、路径校验、UTF-8 元数据、文件与 journal 的生命周期和关闭。

原生 worker 在后台推进，实时路径不执行整批 JSON 重编码或同步写盘。显式保存/停止保留完成屏障；自动保存只发布小型状态，Dart 不再为保存操作遍历或保留全部记录。原文只有在 `debugRecords` 等显式诊断请求时才读回。

Dart 的 `NiedReplayLogger` 目前是记录接口和显示状态桥：尚未迁走的监测/推算链仍调用它生成新记录，桥将**这一条新记录**编码一次送给原生会话。未宣称所有监测、检出和推算业务已原生化，也未宣称 Dart 已完全只剩 UI；本批迁走的是本次采样命中的完整归档会话处理。

Windows 新 DLL 默认启用此会话。非原生平台/测试及仍加载旧 DLL 的热重启窗口保留参考实现；`archiveBackend` 可明确核验是否为 `rust-replay-archive-v1`。旧 DLL 不能通过热重启替换，完整退出后加载新构建才能生效。WinHTTP 实验仍保持原来的关闭状态，与本批无关。

## 数据与行为

JSON 文件改为紧凑布局、根键顺序可以不同；记录字段、顺序、数值类型、未知值和原始时间不变。原生 journal 保留接收到的记录 JSON 字面值，GIF 字节原样保存。没有删记录、降低测站数、改变震级/震度或修改报文再测试。

修复了原逻辑关闭记录时先设置 `_enabled=false`，导致随后保存立即返回、尾部未保存的问题。原生停止会先完成保存再结束会话；兼容路径也补齐这个行为。写盘失败仍遵守 80 条和 15 秒节流，不会在每条新记录上反复尝试保存。

原生 journal 在临时目录创建唯一文件并由自身会话回收，不删除历史归档或原始 GIF。路径组件检查禁止 GIF 层名/文件名越出捕获目录。正常保存不静默丢弃记录；IO 错误由状态/保存结果明确返回。当前队列统计可观测，不把它说成已经实现全局严格内存上限。

## 性能口径

`tools/benchmark_replay_archive.ps1` 在三个交替顺序的独立 AOT 进程中比较冻结的旧 Dart 存储算法和原生会话。两边逐条读取相同 20,320 条真实记录，包含共同的生产者解码、单条桥接、计数、序列化和 IO，每 80 条强制完成一次保存，最后逐条核验所有记录、计数、两份日志与原 GIF。

只使用上述同一张原 GIF 创建两份日志输出，并未回放原归档中的全部 18,724 张 GIF。该测试加速执行归档压力，不是完整 APP、真实时间调度、全部测站处理链或 GPU 测试。所有性能指标在最终大对象等价性检查**之前**采集，验证读取的整棵树不混入测量。两边加载同一 DLL，编译/功能测试不与计时重叠。
