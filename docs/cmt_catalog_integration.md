# CMT 独立列表项

- FSSN、CENC、USGS、JMA、F-net、Hi-net AQUA CMT 使用各自的列表桶，默认
  进入列表。普通震源目录和 CMT 即使原始 ID 相同也保留独立条目。
- 来源标签明确显示 `USGS-CMT`、`CENC-CMT` 等，列表徽章直接复用统一 UI
  的 `CmtBadge` 和现有机制球渲染。缺失有效机制参数时沿用该组件的缺失状态。
- 同源同 ID 的更新通过原有桶更新流程替换该条目，张量、断层面、矩心深度和
  元数据变化也会刷新列表。目录首次加载仍沿用每源最新候选逻辑。
- 点击 CMT 列表项同步显示原始机制解的统一信息卡、地图机制球和 CMT 详情；
  复用原有自动／正式标签、震级筛选及选中项的“取消显示”覆盖层。
- 历史查看不进入实时通知或语音队列。数据 ID、时刻、震源深度与矩心深度
  各自保留原值，不制造新的实时事件。
