# USGS DYFI 公众体感报告

DYFI 作为关联 USGS 地震下方的独立列表卡显示。缩略图绘制官方原始体感网格及打包的国家轮廓，不叠加震中十字或震级标签。卡片显示最高 CDI 原值、产品报告总数、网格数和实际网格分辨率；地点复用现有中文转换，产品更新时间转换到电脑时区。产品总报告数与可绘制网格内报告数分别读取，不补造缺少坐标的问卷。

点击 DYFI 的地图显示，独立选中该产品并显示统一信息卡；原 USGS 地震行与 DYFI 行拥有各自的选中状态。再次取消只清理手动选择。主地图保留现有震中标记，静态填充原始网格，点击网格查看原始 CDI、报告数和距离。仅在绘制时选择镜头附近的经度世界副本，不修改源坐标。

自动产品卡使用 `usgsDyfi`，与 `usgsEqlist`、`usgsShakeMap` 分别展示和轮播。原始事件 ID、发震时间及产品原文保持不变。产品自动展示两分钟，到期不会清理手动选择或普通 USGS 信息卡。产品更新不重新进入实时地震接纳队列，不触发重复语音或警报。

DYFI 共用设置中的 USGS 来源震级过滤，依据绑定地震的原始震级：0 不过滤，负值不接收，正值为最低震级且包含等于阈值的事件。列表随 USGS 父事件过滤；手动地图、自动地图和统一信息卡也受同一阈值约束。收紧阈值立即移除不符合条件的已展示产品，下载中返回的数据不能重新显示被过滤的事件。侧栏列表自身的震级下拉筛选同样作用于包含 DYFI 的整组 USGS 列表项。

加载沿用官方 USGS 目录的 `detail`、`types` 和 `updated`，没有增加独立轮询。启动已有产品仅建立基线并加载列表网格，不触发历史产品自动展示；新的原始产品身份才自动展示。详情选择 `preferredWeight`、`updateTime` 对应的产品，优先使用实际存在的 10 km GeoJSON，其次使用 1 km GeoJSON。旧产品不能覆盖新缓存；重复产品不延长自动展示时间。失败保留同事件已有的真实网格，之后目录更新或手动点击可重试。

## 验证

### 2026-10-10 空网格修复

实际巴拿马事件 `us6000u1em`（M4.3，2026-10-10 12:34:08 UTC）的官方产品包含 `maxmmi: "0.0"`、`numResp: "1"`，10 km GeoJSON 正常返回空的 `features`。该产品不能因最高值为零而整条解析失败。模型保留 `maxCdi == 0` 和产品原文；展示层将不在 CDI 量表内的零值显示为“未知”，真实报告数仍显示 1。列表不为实际空网格创建缩略地图，显示“暂无可绘制体感网格”；主地图也明确提示空网格。网格内单元 CDI 仍要求 1–12，没有放宽单元值校验。

原始详情及 10 km 网格逐字节保存于 `test/fixtures/usgs_dyfi/us6000u1em.*.original.geojson`。回放覆盖服务加载、手动选择、原文保持不变，以及手机/桌面的正式列表、统一 UI 和地图提示。

使用 `test/fixtures/usgs_dyfi` 和既有 ShakeMap 原始详情捕获进行回放，不改写源时间或震级。`ci41345415` 的 191 份与 210 份报告版本用于验证更新；191 份版本有 15 个网格、187 份可定位报告。另一个实际事件 `us6000u0xi` 用于验证手动选择旧产品时新 USGS 事件继续显示。

11 项 DYFI 检查覆盖原始值、启动基线、更新去重、旧报拦截、下载中震级过滤、已显示产品过滤和阈值边界、手动与自动生命周期、手机和桌面正式列表及统一 UI、无震中标记的缩略图，以及主地图网格点击。另完成 51 项现有 ShakeMap、CENC、历史选择和统一 UI 轮播回归。组件预览输出到 `build/ui-previews/dyfi`。
