## 一句话结论

**「换搜索算法」这条线已证明：无论换成哪种全局形态、叠加哪几种证据通道（振幅 / NYAD / 深度先验），伪盆地的全局分依旧更低。** 问题不在搜索、不在信息，而在**打分函数（似然）的语义结构本身**：

1. **深度 ⇄ 发震时刻简并**（离岸「往海里推 + 变浅/提前发震」代价面不动）；
2. **大事件未触发站证据权重归零**（`inactiveWeight = 0 @ effCount ≥ 50`）；
3. **相位级残差缺乏鲁棒性**（纯加权 RMSE，离群站 / 误检相位不成比例地主导代价）。

本提案把这**三条结构缺陷**作为**唯一改动对象**，逐条设计可被单变量证伪的影子实验；搜索形态（多峰后验）**退居为载体**，不再是主攻方向。

## 1. 问题定义：为什么"根在似然"

### 1.1 前序证据链（全部已实测，无需重做）

| 证据 | 实验 | 结果 | 说明 |
|---|---|---|---|
| 5 | L2/L3 起点 / 路径 | 离岸 28.6 → **69.5 / 63.4** | 改起点只会更差 |
| 6 | J1 深度定格 | 离岸 28.6 → **56.3 / 87.8** | 无可靠深度先验时硬钉更糟 |
| 7 | J2 NYAD 负证据 | 28.6 → **30.7**（±2km 噪声内） | **方向正确**（一致西移）但过冲 |
| 8 | J3 振幅入似然 | 28.6 → **24.8**（w=3，单杠杆最大改善） | 信号真实；但離岸種子島 12614km、内陆熊本 1373km |
| 9 | C 全局粗网格后验 | 离岸 28.6 → **179.6**；北海道 61.9 → **681.7** | **⚠ 2026-10-15 M2-a 复核：681.7 是"检测号重置后远场（东北）簇"的定位结果（簇关联伪影），非全网似然全局最优；全网上的全局最优偏 150–200km**（详见 §6 ⚠ 与证据 12） |
| 10 | M2 联合似然 × 全局多峰 | 北海道最好 **388km**（生产方式 61.9） | 三通道全开，全局形态在含远场站的满网上**仍**劣化（真），但"682km 灾变"是簇伪影 |

### 1.2 决定性机制（证据 9+10，2026-10-15 M2-a 复核后）

- 全局搜索**忠实**地找到了全局最优；但**全网**上的那个全局最优偏 150–200km（真问题）。
- 原引用的「682km 伪盆地」经复核是**检测号重置后远场簇**的定位结果（簇关联伪影）——
  **它是"对错簇的正确解"，不是"对全网解错"**。⇒ 至少**两条**独立瓶颈：① **站集/簇关联**；② **缺支撑数正则**。两者都在似然之外/边缘。
- 加入振幅 / NYAD / 深度先验后，**远场簇的全局分仍然更低** ⇒ 这三条通道确实未触及根因。

### 1.3 三条结构缺陷（本提案的唯一改动对象）

| # | 结构缺陷 | 代码 / 数据依据 | 后果 |
|---|---|---|---|
| **D1** | **深度-发震时刻简并**：origin 与 lat/lon/depth 一起在似然里被联合优化 | `hyp_score.rs` 6 场景按候选 origin 求残差 | 往海里推震央 + 提前发震可维持代价不变 ⇒ 离岸平坦面 |
| **D2** | **未触发站证据权重归零**：`inactiveWeight = 0 @ effCount ≥ 50` | `hyp_score.rs`（`count ≥ 50` 权即归零） | 大事件（离岸典型多站）中「沉默的站也是证据」被整体弃用 |
| **D3** | **相位级残差缺鲁棒性**：目标 = 加权 RMSE | `Scorer` 输出 = 加权 RMSE | 少数误检 / 离群站残差平方主导代价，把解拉向伪盆地 |

> 三者共同解释：**为什么 J3（唯一正向信号）在贪心形态下路径敏感、在全局形态下放大伪盆地**——信号进了似然，但似然的这三处结构把它稀释掉了。

## 2. 现状契约（为什么不能在搜索侧解）

同前序提案 §2，此处仅复述与本提案相关的约束：

- **Rust 定位内核**（`native/station_core/src/hyp_search.rs`）：四段贪心（0.1° / 六邻 / 严格 ties / 1000 迭代），**ABI 契约冻结**（`include/rq_station_core.h:172-174`）。
- **打分器**（`src/hyp_score.rs`）：纯走时加权 RMSE；6 个 P/S 场景；未触发站弱线性罚。
- **Dart 驱动**（`lib/core/source_estimation/source_estimator.dart`）：种子 = 最早触发站质心 + 热启动。
- **数值等价已证**（证据 6）：Dart 参考搜索与原生 Rust **逐字节相同** ⇒ 改似然**必须同时触及两侧**（Dart 影子 + Rust 新符号），否则对拍失败。

> ⚠️ **参考一致性契约必须重新谈判**：似然语义的任何改动都会**改变既有 ABI 的输出契约**（`output[99]` / `waves[2*count]` / 日志格式的**数值**）。本提案的落地方式（§5）是**新增符号**而非修改旧符号；产品化须正式修订 `rq_station_core.h` 的契约声明。

## 3. 三条设计方向（逐条对症 D1/D2/D3）

> 共同原则：**先把似然修对，再谈搜索形态**。多峰后验（`search_grid_shadow.grid_modes`）作为**诊断载体**保留，用于验证伪盆地是否被降级——**不再是主攻**。

### 方向 R1 —— 发震时刻解耦（对 D1）

| 项 | 内容 |
|---|---|
| **JMA 参照** | 理论走时（JMA2001）**预测**到时 → AR-AIC 在 **±3s 窗**精搜变化点（边界则扩 ±10s）；origin 由**最早可靠 P 到时**反推，而非与震央联合优化 |
| **我们现状** | origin 是候选震源的一维，与 (lat,lon,depth) **联合**进入似然 ⇒ 简并 |
| **拟设计** | 把 origin 从搜索维度**边际化**：对每个候选 (lat,lon,depth)，origin 取 **profile 最优**（或对该维做**闭式解**——`argmin_origin Σ w_i·(t_i − origin − tt_i(x))²` 的加权均值 / 加权中位数）后代入残差；等价于把 origin **解析消掉**，只保留 (lat,lon,depth) 的搜索 |
| **预期** | 砍掉简并的一维 ⇒ 离岸向海漂移失去「提前发震」这个免费补偿通道，代价面出现真实梯度 |
| **风险** | 计算成本（每候选一次一维优化，可用闭式解规避）；origin 稳健估计须防离群站污染（与 R3 耦合） |
| **可行性** | ★★★（确定性、单变量、Dart 影子可先做） |

### 方向 R2 —— PLUM 式证据融合 / 站选择解耦（对 D2 + 似然语义）

| 项 | 内容 |
|---|---|
| **JMA 参照** | **远场站不参与定位**：IPFx 估计组 = **首触发站最近 20 + 10 个宽方位站**；远场交由 **PLUM** 用 30km 内邻近站观测震度**直接外推震度**（不估震源）；EEW 综合取 **max(IPF, PLUM)** |
| **我们现状** | 参考打分器把**远场触发站全量**入似然（与 JMA 显式选站不同）；未触发站在 effCount≥50 时**整体弃权** |
| **拟设计**（两条子项，分开单变量） | **R2a 站选择**：定位似然只纳入「最近 N + 宽方位 M」子集（N/M 起扫，如 N∈{20,30}、M∈{10}），远场站从定位项**移出**；<br>**R2b 负证据方差标准化**：把未触发站证据从「计数线性罚」改为**按期望触发概率加权的负对数似然**，权重**不随总站数归零**（用 σ 标准化），保留 J2「方向正确」的信号、用**阻尼**压掉过冲 |
| **预期** | 远场站不再以「距离歧义大」的姿态主导代价；沉默站证据在大事件中不再整体失效 ⇒ 直接对症 D2 |
| **风险** | R2a 可能牺牲多站收敛后的稳健性（需守内陆不劣化）；R2b 过度则重蹈 J2 过冲（须带上界 / 只作 tie-breaker） |
| **⚠️ 2026-10-15 M1c 实测（降级）** | 离线复刻 NYAD（全站网 1618 站，报告 `tmp/capture_survey/lik2/LIK2_M1_STEP3_NYAD.md`）显示：**R2b 在晚帧/大事件上 No-Go**——① 判别力随 elapsed 衰减（北海道 20s 时官方/伪盆地违例率 0.70 vs 0.96，143s 时塌到 0.94 vs 0.99）；② 裸计数版 `(违例站/effCount)×W` 量纲失衡（W=2 已 ≫ rmse），大 W 把 argmin 推去 104–230km；③ 归一律版因梯度平坦而不改变 argmin。⇒ **R2b 须限定为「早期项」（elapsed ≲ 30s），且必须做 σ/对数似然标准化**——即生产现有门控方向正确。**M2-a 首攻改为「先离线复现 682km 伪盆地、再定位其生成器」**（已排除 inactiveWeight / waveMultiplier / ascend 零权门）。 |
| **可行性** | ★★（R2b 属「增强现有」，落地成本低；R2a 需重构站选择，中） |

### 方向 R3 —— 相位级鲁棒似然（对 D3）

| 项 | 内容 |
|---|---|
| **JMA 参照** | 相位**逐站独立**（AR-AIC 直接检 S，或由 P 到时 + 理论 S−P 推算）；拾取精度 0.06–0.31s，优于 STA/LTA |
| **我们现状** | 目标 = **加权 RMSE** ⇒ 残差**平方**，离群 / 误检站以平方权重主导 |
| **拟设计** | 把代价核从 L2 换成**鲁棒损失**（Huber / Cauchy / 截断最小二乘 Tukey），逐站相位残差**独立**纳入；离群站**自动降权**而非被平方放大 |
| **预期** | 少数伪相位不再能把解拖进伪盆地（证据 9：伪盆地靠的正是"某些站残差被平方后看似更优"） |
| **风险** | 鲁棒核参数（δ / c）需标定；核过强会吞掉真实差异（需与 ① 判据联动校验） |
| **可行性** | ★★★（确定性、可单变量、Dart 影子可先做） |

> **三者关系**：R1 砍简并维（几何），R2 修证据权重（站），R3 修代价形态（残差）。**证据 10 的教训是三者必须"同时在同一个似然里"才可能生效**——但实验仍须**先各自单变量**（否则无法归因），再**组合**（M2）。

## 4. 拟替换的似然形态（组合目标）

> 目标形态：**一个对 (lat,lon,depth) 的似然，其中 origin 已边际化（R1）**，代价 = **鲁棒核的相位残差（R3）** + **站选择受限的走时项（R2a）** + **方差标准化的未触发站负证据（R2b）**。

搜索形态（**载体，非主攻**）：

| 方案 | 形态 | 角色 |
|---|---|---|
| **G 全局多峰**（复用方案 C 影子） | 粗网格全扫 → top-K 模态 → 局部精化 | **诊断载体**：暴露伪盆地是否被降级（`grid_modes` 官方格是否入 top-K） |
| **A 粒子滤波（IPF）** | N 粒子按乘积似然加权 + 重采样 | **终态候选**：须**固定种子的确定性 RNG** 以保测试契约 |

**关键设计要点**：
- **伪盆地降级 = 首要验收项**：修好似然后，北海道東方沖的**全局最优必须不再是 682km 伪盆地**（或至少官方格进入 top-K 且分差被压缩）。
- **护栏内生于似然**：把「站点数下限」等硬护栏改为**似然项的连续权重**（避免 J3/J2 的"硬阈值把一个灾变换成另一个灾变"）。
- **多峰保留**不坍缩到单一最优，既改善离岸"结论不唯一"的表达，又是诊断协议。

## 5. 不破坏现有 ABI 的落地方式

**核心原则**：**新增**一条似然/搜索路径，**不动**现有契约与生产默认行为。

1. **新增 ABI 符号**（不修改既有 `rq_hyp_score_search` 与 `Scorer` 语义），例如：
   - `rq_hyp_score_search_lik2_abi_version()` / `rq_hyp_score_search_lik2(...)`；
   - 现有 `rq_hyp_search_abi_version() == 1`、四段契约、日志格式**全部保持不变**。
2. **Dart 侧默认关闭开关**：扩展现有 `NiedHypStartShadow` 影子机制（已默认 `false`、可无损回退），加似然族开关（如 `likelihoodForm` + `originMarginalized` / `robustKernel(delta)` / `stationSelect(n,m)` / `inactiveNegativeEvidence`）。
3. **回退 = 关开关**：生产默认仍走原生四段贪心 + 现行 Scorer；新路径仅在显式开启时启用。
4. **对拍义务**：新符号上线前，Dart 参考实现与 Rust 新符号必须**逐位对拍**（沿用证据 6 的对拍法），否则无法证明"仅似然改变、无实现漂移"。

> 与既有影子实验一致：**全程 Dart/影子层或新 ABI 符号，不动生产默认路径**。

## 8. 风险与工作量评估

| 风险 | 等级 | 缓解 |
|---|---|---|
| 似然语义改动破坏 ABI 参考一致性契约 | **高** | **新增符号** + 正式修订契约声明；Dart↔Rust 逐位对拍 |
| 序列不可分：三缺陷**耦合**，单变量可能都无效 | 高 | 沿用「先单变量归因 → 再组合」；M1 允许部分单变量 No-Go 但保留信号 |
| origin 边际化后仍收敛到伪盆地 | 中 | 若 R1 单独无力，则证明 D1 非唯一根因，依赖 R2/R3 组合 |
| 鲁棒核参数引入新的不确定性 | 中 | δ/c 起扫 + 与 ①③ 判据联动；过强即 No-Go |
| 全局 / 粒子滤波开销上升（Dart 全扫 20–30×，山梨 >55min） | 中 | **Rust 化是任何后续的硬前提**；粗网格 + 早停 + `DistanceCache` |
| 方案 A 随机性破坏"逐字节相同"测试文化 | 中 | 固定种子的确定性 RNG + 固定轨迹回归；或**止步于确定性 G 载体** |
| 离岸本性困难不可根除 | 高（承认） | JMA 亦承认离岸「slightly offshore」（2024 能登，UJNR-14）；目标是**显著改善**、非根除 |

**工作量（粗估，需批准后细化）**：
- 阶段 1（M1 影子验证）：Dart 侧似然三方向单变量 + 组合，复用现有影子框架 —— **中等**；
- 阶段 2（M2 Rust 化 + 对拍）：新似然符号 + 逐位对拍 —— **中等偏高**；
- 阶段 3（M3 产品化）：生产可切换开关（默认关）+ 回归全绿 —— **中等**；
- 阶段 4（M4 方案 A / IPF，可选）：粒子滤波 + 确定性 RNG + 全量重放 —— **高**。
