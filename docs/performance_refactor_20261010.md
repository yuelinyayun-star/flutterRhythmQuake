## 改动

1. **NIED 测站邻接关系**：将检出和震源推算的邻接计算合并，同一坐标距离只算一次。保留原有距离公式、30/40/300 km 范围、方位分区、排序规则和选站数量；仅减少不会进入结果的临时排序对象。以 ID、站码和坐标共同检查缓存失效，取代每帧拼接站码字符串。不可变邻接表供后续帧复用。
2. **观测历史内存**：只在完整质量标记集合相等时复用上一帧的不可变集合；空物理量映射复用常量。标记增加、移除、缺测和乱序时标记仍按原规则更新，无全局驻留缓存。
3. **历史读取**：同一版本的历史只创建一次不可变快照。按时间顺序清理过期前缀，保留原 60 秒窗口边界及全部重复时间观测；旧快照不随新观测或清空而改变。

震源数学算法、原始观测值、原始时间、订阅与 UI 逻辑均未修改。没有为了占用指标降低采样率或丢弃观测。
