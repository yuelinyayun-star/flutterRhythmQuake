# FlutterRhythmQuake 项目介绍

> 最后更新：2026-07-08

---

## 一句话简介

**FlutterRhythmQuake 是一款跨平台的实时地震（及多灾种）监测与预警应用**，能够聚合全球多个官方与公开地震数据源，实时接收地震预警（EEW）、在地图上动态呈现震波传播，并通过语音、弹窗、系统通知等方式及时提醒用户。

---

## 它能做什么

- **实时地震预警**：接收中国地震局（含各省分局）、台湾中央气象署、日本气象厅、韩国气象厅等机构的地震预警速报，区分警报级 / 普通 / 取消报 / 假定震源 / 最终报等完整状态。
- **多灾种监测**：除地震外，已扩展支持火山（日本气象厅）、台风、中国气象预警、强震动（FDSN / Hi-net）以及本地晃动检测。
- **地图可视化**：以地图为底，动态绘制 P 波 / S 波扩散动画、各机构实时震度分布、仪器烈度、行政区划边界，并自动定位震中。
- **语音与桌面提醒**：通过语音合成播报预警信息，桌面端支持系统托盘、窗口置顶、系统通知。
- **历史与列表**：聚合中国、日本、美国、台湾、韩国等机构的地震目录，支持按震级与数据源筛选。
- **实时震源估算**：基于台站观测实时反演震中位置与烈度，并配套回放系统用于算法验证。

| 区域 | 主要数据源 |

| 中国大陆 | 中国地震台网（CENC）、各省分局、FAN Studio |
| 中国台湾 | 中央气象署（CWA） |
| 日本 | 气象厅（JMA）、P2PQuake、NIED 强震监测、S-net 海底观测 |

## 技术亮点

1. **多信源统一管道**：所有数据源经统一抽象层接入，归一为标准事件模型，UI 不再按来源分支。
2. **实时震源 / 烈度估算引擎**：从台站观测实时反演震中，含 JMA2001 走时表、kotoho7 算法桥接、PLUM 证据稳健性校准。
3. **高性能地图渲染**：flutter_map + 自定义图层，P/S 波扩散动画与多机构震度叠加。
4. **事件检测与回放**：稳健的单台触发 + 时空联合事件检测；JMA / K-NET / 合成数据集回放用于验证。
5. **合规地图**：中国区使用天地图 / 高德等合规底图。

---

## 技术栈

- **框架**：Flutter / Dart
- **状态管理**：Provider
- **本地存储**：SQLite（sqflite）
- **地图**：flutter_map（Leaflet 风格瓦片）
- **网络**：HTTP 轮询 + WebSocket
- **语音**：flutter_tts
- **桌面增强**：window_manager / tray_manager / local_notifier
- **时间同步**：NTP，保证预警时间戳准确

## 关于"对标项目"的说明（重要，避免误传）

本项目在设计与交互上**参考了国产开源预警前端「要石 kanameishi」**，但二者均为**中国开发者主导的开源项目**：

- **要石 kanameishi**：作者 `Lipomoea`，GitHub 仓库 `github.com/Lipomoea/kanameishi`，技术栈为 Vite + Vue3 + Leaflet + Tauri，基于 **AGPL-3.0** 开源，定位为永久免费的公益性项目。
- 其项目名"要石"与图标借用了日本动画《铃芽之旅》的元素，**容易让人误以为是日本项目，实为国产**。介绍时请务必准确表述，以免对外造成误解。

FlutterRhythmQuake 与要石 kanameishi 是**并行存在的两个国产开源地震预警项目**，前者以 Flutter 跨平台 + 算法引擎为特色，后者以 Vue/Web + Tauri 桌面端为特色。
