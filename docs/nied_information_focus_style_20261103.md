# EEW 期间 JMA/P2PQ 情报与 NIED 小点联动

> 本文记录最初的 EEW 临时展示联动。其后用户已授权扩展到普通 JMA/P2PQ 情报展示，当前生效范围见 [后续扩展说明](nied_jma_information_display_20261103.md)。

## 授权范围和实现

仅改变 NIED 的站点符号：存在 EEW，且 JMA/P2PQ 普通情报已进入现有 6500ms 临时展示时，数字震度图标改为对应原有震度配色的小点。临时展示结束、被新 EEW 打断或被其他来源情报替换后，恢复原有符号规则。普通 JMA/P2PQ 展示、EEW 单独展示、CENC 情报以及特殊 LPGM/火山产品不启用该开关。

- `lib/widgets/map/quake_map_view.dart`：仅修改 `_buildNiedStationLayer`。监听已有临时情报显示通知，结合 EEW 存在状态和情报来源传递样式开关；复用现有计时，不增加计时器。
- `lib/widgets/map/nied_intensity_layer.dart`：新增默认关闭的 `informationFocusDotsOnly` 参数，并将其纳入符号缓存键。开启期间仅将数字图标改走小点绘制，高震度采用原有图标调色板；低震度、静止和缺测站保留原来的小点颜色和透明度，沿用小点大小及缩放绘制器。关闭时走原有分支。

不修改测站值、震度阈值、检出、推算、网格生成及闪烁、回调、相机规则、6500ms 时长、情报接收和其他网络图层。上轮发现的“无可定位范围不启动临时展示”路径本轮未修改。

## 验证

- 原始 JIAN/JMA 情报：EEW 单独显示时关闭小点模式；情报临时显示期间开启；到期后关闭。原始 CENC 情报临时展示不会启用该模式。
- 原始 P2PQ 无震中 ScalePrompt：6.4 秒仍为情报小点模式，6.6 秒恢复正常；第 3 秒加入另一条原始 EEW 记录会立即退出小点模式。原始报文正文未修改。
- 渲染用等级样例覆盖低震度、数字图标等级及缺测站；两种“显示震度 0”设置均验证开启后无数字图标、关闭后原图标恢复。确认网格边界与闪烁、回调次数、站点值与检出状态不变。
- 使用修改前 NIED 渲染源码作独立对照，两种“显示震度 0”设置的普通状态图像差异均为 0 像素；同一图层开启再关闭后的图像也逐像素一致。
- NIED 渲染文件及两个正式测试文件静态分析无问题。地图大文件分析仅报告 24 项既有的单行 if 风格提示，均在本轮修改区域之外，未顺带调整。

测试及对照证据位于 `tmp/nied_information_focus_style_20261103/`，包括 `verified.log`、`p2p-hold.log`、`p2p-new-eew.log`、`normal-pixel-comparison.json`、`production-change.diff`。
