## 连接结论

CWA Open Data、TECDC Rapid、P-Alert GraphQL 本轮请求均成功。部分精确时刻返回HTTP 200但没有事件级PGAList或waveform，是历史产品覆盖缺项，不是网络断连。未测试APP实时WebSocket，不对实时WS作“永不掉线”的结论。
