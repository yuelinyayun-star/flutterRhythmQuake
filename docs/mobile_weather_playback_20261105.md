# 手机气象地图独立页面与实况动画

## 本轮范围

按用户提供的手机气象地图参考图调整布局，但继续使用 APP 的玻璃卡片、圆角、字体、图标及颜色。仅改变手机气象地图页面及其历史帧显示，不更改桌面、地震页、EEW / 情报 / 检出规则、实时产品解析和原相机算法。

## 支持的历史实况

- 全国雷达：中国天气网原始 `readRadarList` 目录及对应 PNG。
- 全国小时降水：中国天气网原始 `getPreObs1h` 目录及对应 PNG。
- JMA 雷达：原始 `targetTimes_N1.json` 的实况瓦片时次。
- 葵花卫星云图：原始 `targetTimes_fd.json` 的实况瓦片时次。
- NSMC 全球红外云图：原始 24 小时时次目录，复用原图像投影处理，不改 RGBA 或现有投影算法。

其余仅有实时入口的产品继续显示实时信息，不用虚构历史帧、平移图片或重复同一图片冒充动画。播放针对当前主产品；叠加的其他图层继续按其原实时逻辑显示。底图和透明度保留原有配置。

## 原始数据与测试

`test/fixtures/weather_playback_20261105/` 保存本轮从上述五个上游地址原样获取的目录，以及全国雷达目录中对应原始 PNG，未改写报文或图片。

- Rust 两项测试通过：五类原始目录排序 / 上限 / 输入不变 / FFI 分配释放，及 UTC / UTC+8、非法日期、预报过滤。
- Dart 原生 / 便携目录结果一致；使用原始雷达图测试播放、暂停、逐帧、缓存边界、回到实时、退出及迟到图片隔离。
- 手机首页回归新增断言：地图内切换栏消失，返回首页恢复；原实例保留和返回逻辑断言继续保留。
- 最终 41 项 Flutter 相关测试通过。新增断言明确检查未点播放已请求目录和前两张原图，点播放不重复请求第一帧，预载过程不覆盖实时显示；慢请求期间立即暂停，迟到图片不再推进显示。
- 最终 Windows Release 编译成功（131.2 秒），并启动实际构建产物进行手机尺寸验收。进入雷达后未点播放，自动加载出 17:06–19:24 的 24 帧目录；点播放立即显示原始 17:06 帧，后续实际地图推进到 18:42（17/24），雷达回波随帧变化，非仅数字时间变化。顶部三栏目切换已隐藏。
- 实际保存配置仍显示地震页全局雷达、台风为 true；手机配置单独为雷达 true / 台风 false。没有重写原地震页开关。未发现本次运行的 Flutter exception / overflow / Unhandled 日志。
- 实机暂停后点时间轴，地图显示 17:48（8/24）的对应原始雷达回波；返回天气首页恢复顶部切换栏，再次进入独立地图正常。
- 本轮未制作新的安装包、未更新云电脑，尚未在 Android 真机安装。
