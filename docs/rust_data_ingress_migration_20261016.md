# SSE 分块与共用数据入口迁移

## 本轮接入

本轮成批处理九个服务的数据入口：TREM SSE、中国天气本地预警、中国天气预警地图与详情、JMA 火山地图 JSON、后台已接纳事件缓冲、OBS 运行状态恢复、矢量底图、中国断层、通用边界。共用 API JSON 核心继续由 Rust 持有原始解析树，Flutter 保留连接调度、领域模型、事件规则与界面。

1. 新增 ingress ABI 1：原始 UTF-8、按源显式选择的宽容解码、既有 JS 包装选择与 JSON 解析在同一次原生调用中完成。
2. TREM HTTP 块直接进入独立原生分帧 owner，处理跨块 UTF-8、CR、LF、CRLF、首个 BOM 与 EOF。每条 `data:` 行仍独立解析，无效 JSON 行继续跳过，非法 UTF-8 终止当前流。没有改变为 SSE 多行聚合协议。
3. 每个 SSE 订阅在正常结束、错误、取消及重连时释放自己的 owner。输出先复制为独立快照，后续帧与释放操作不会改变已发布原文。
4. 中国天气地图把原始 HTTP 字节送到既有工作 isolate，在 worker 内直接解析；详情保留原来的首次左大括号至最后右大括号规则。本地预警详情保留原来的 `alarminfo` 非贪婪匹配语义，包括旧规则会拒绝的括号边界，未趁迁移改变业务解析。
5. 矢量底图及中国断层使用原始 asset 字节进入工作 isolate，移除整份 String 中转。只读数据消费者直接读取独立原生文档，不为每个坐标数组额外创建可写包装。拓扑展开、孔洞、反向弧段、坐标转换和绘制规则沿用原实现。
6. 后台已接纳事件及 OBS 状态的 JSON 恢复接到同一个核心，继续保留可写容器契约。

已保存涉及的 20 份既有源文件和原始样本哈希基线，既有完整迁移前备份与实验资料保留。未改动原始报文、云端、SDK 或依赖。
