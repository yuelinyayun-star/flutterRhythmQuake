# Windows 预警历史按需加载（2026-10-13）

## 行为与范围

历史列表常驻每报显示快照、原文引用、原始报告时间及测站归档引用。展开详情、导出或开始回放时读取所选原文；收起、关闭历史抽屉、停止回放后释放完整报文。用户导入的外部回放包仍由导入列表持有，不混同本地历史缓存。

本轮接入 Windows 独立历史文件后端。Android 和其他 SharedPreferences 后端仍按原方式恢复原文，尚未完成此项按需加载。Flutter SDK 保持 3.41.1，没有新增 Rust 算法或依赖，没有制作或替换正式安装包。

## 存储与生命周期

- 每个事件文件增加小型快照头，与原完整 `value` 同文件写入、flush 后重命名发布。旧文件首次生成快照；已有当前快照时启动不读完整正文。迁移保持原始 `value` 字符串，旧读取器仍可读取。
- 存储层只合并正在进行的同事件读取，完成后移除 Future，不缓存完整结果。原文由展开详情、导出或回放调用方持有。
- 原文身份检查报告快照字段的 SHA-256，缺失或不符明确报错，不猜测时间、坐标或报号。独立派生的显示字段不参与正文身份；导出、回放先加载原文，不导出缺报文的快照包。
- 新报与历史引用可以共存。保存时加载旧报文合并，仅本次实际保存成功的那个事件对象才能释放原文；旧保存期间到达的新报继续持有正文，等待下一次保存。
- 抽屉关闭清除展开卡片的正文；异步完成检查组件生命周期和加载代次。停止回放清除播放计划与测站快照，并从当前历史列表重新取得快照；新报稍后保存成功时同步刷新闲置的本地选中项。
- 保留原始报告时间以维持回放时间轴。源数据、震级、时间、报数、原文内容和顺序不改写，实时事件仍按完整数据处理。

同期加入的预估烈度显示也已集成核验：卸载正文前单独保存显示值及“已解析”标记，原上报烈度保持原值；加载回原文后导出与回放仍使用原报告。快照增加 `presentationVersion`，对缺少该标记的早期快照从原文一次性重建，之后恢复只读快照。CWA 的原文 PGA 调整与训练抑制状态通过显示快照保留。
