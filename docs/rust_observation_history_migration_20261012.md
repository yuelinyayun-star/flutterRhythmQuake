# NIED 观测窗口与传输迁移（2026-10-12）

保留 Flutter 3.41.1 / Dart 3.11.0。本轮将 Windows NIED 推算工作线程的数值观测窗口接入现有 Rust DLL，并将传给 UI 的观测历史改为独立拥有的无指针紧凑快照。默认 Dart 观测历史和其他平台的处理保留；事件字段、检出规则、震源计算、报数、过滤、语音和 UI 不改变。

## 备份

修改前备份位于 `D:/flutterApp/flutter-observation-history-migration/20261012-194521/before-observation-migration.zip`，共 3,847 个文件、49,469,356 字节，SHA-256 `79b1ebe33fd1377f70633034777580d707f079101bcc1625e982fbc1e6926ae1`。ZIP 每个成员均核对长度和 SHA-256；现有脏工作区未清理。目录同时保存源码清单、原实现及迁移实现的独立验证程序、构建日志、原始输出和测量脚本。本轮未修改 SDK、未制作或安装新安装包。

## 存储和传输

原实现由每站的帧对象列表保存 60 秒窗口，每秒发送事件时，工作线程和 UI 会同时持有完整帧对象图。现将数值窗口的顺序检查、追加、过期和清空交给 Rust；工作线程只保留当前帧及原质量标记和物理观测的元数据引用。元数据仍在 Dart，不能称为全部事件状态已经迁移。

普通行固定 24 字节：Float64 原始位值、精确的观测/接收时间微秒差、元数据 ID、原始等级、检出等级和原有效性/UTC/触发位。时间差或其他整数超出紧凑表示范围时，以宽记录保存原来的七个 64 位字；不截断、不四舍五入、不改时间、不降低采样率。窗口基准平移只做可精确还原的整数运算。

跨 isolate 发送的快照持有自己的字节数组；不传递 FFI 句柄、指针或借用视图。完整历史只有消费者读取时才按原字段还原，`latest` 仍保持原用法；导出快照不在工作线程额外缓存第二份数值窗口。显式读取的旧快照在继续追加、清空或释放后仍可读取，保持不可变列表约定。

`rq_observation_*` 为版本 1 的 C ABI，调用缓冲同步使用，Rust 不保留调用方指针。逐站窗口由显式销毁及 NativeFinalizer 管理；事件归档、重置和工作线程退出时释放原生窗口，已被其他对象保留的记录冻结成无指针快照。原生分配从统一 Rust 分配统计中核算，不能仅凭 Dart 堆下降声称内存改善。

首版原生行和传输行均为 56 字节。固定输入测量发现其原生缓冲抵消大半 Dart 堆收益，因而继续改成 24 字节无损行；保留首版原始记录供追溯，最终数据位于备份目录的 `packed-final`。

## 等价性与边界

性能数据使用未经修改的奈良 51 帧 GIF（20260610180120 至 20260610180210）、每帧 1,634 站，共 83,334 条原始输入，保留原时间、像素和顺序。运行前后检查原文件 SHA-256。迁移前后独立 Windows Profile 进程交替冷启动，内存与完整输出/耗时分别三轮，合计 12 次进程运行。

首轮保存并逐字段核对全部 51 帧的检出、事件、历史、每站观测、震源、质量和诊断输出，40 次推算的业务字段完全一致，差异仅为 `search_elapsed_ms`。前后 HYP 调用均为 1,066 次，本轮不是重复计算 HYP 收益。所有迁移后进程关闭时观测窗口会话数归零。

受控边界测试与真实数据性能验证分开：包含重复/乱序时间、精确过期边界、零/负保留时长、DateTime 溢出时的原先追加后抛错行为、UTC/本地标记、负零/NaN/无限值/小数位值、超范围等级和时间差、宽记录淘汰、超过 35 分钟的基准平移、中文/日文质量标记、物理观测、快照不可变及跨 isolate 传输，以及归档/重置后的释放和旧记录可读性。

## 测量口径

VM 的 `getAllocationProfile` 对同一个 isolate group 报告整组堆。已用 `getVM` 核实主线程与 `nied-source-estimation` 工作线程共享一个组，因此只计一次，禁止将两个 profile 相加。原始证明在备份目录 `vm-isolate-groups.json`，计算脚本为 `compare_packed_profile.py`。

验证程序为复现保留全部 51 帧输入快照；内存场景不展开/序列化完整输出，在保留最后事件和工作线程时主动 GC 后读取共享 Dart 堆，并另列外部内存与全部 Rust 当前分配。RSS 记录为 GC 诊断前的单点，私有提交另保留在 `process-results.json`。这些口径均不是完整 APP Release 的 30 分钟稳态数据，不得替代整机目标验收。

| --- | ---: | ---: |
| 共享 Dart 堆（GC 后） | 103.591 MiB | 95.534 MiB |
| Dart 外部内存 | 0.163 MiB | 0.164 MiB |
