# 测站显示摘要原生会话迁移（2026-10-17）

本轮将 Windows 的侧栏摘要计算迁入 Rust，并按台网增量更新。源连接、保持/过期、检出和推算编排仍有未迁部分，完整链路边界继续遵守 `native_full_pipeline_boundary_20261016.md`。

## 原生与 UI 的职责

- Rust 选择 SeisJS、NIED、TREM、KMA、P-Alert 的最大站及 SeisJS 指定地点站；处理 TREM 警戒值选择和 P-Alert 保持值、采样值、PGA/PGV 阈值优先级。P-Alert 直接复用既有原生阈值函数。
- Rust 选择 S-net 前五站、计算 JMA 等级；保留原有活动/等级过滤、有限值判断、正负零顺序、UTF-16 站名同值排序及震度零时的显示规则。
- Rust 完成 NIED 检出格的区域归属、附近桶搜索、最近站距离和排序；计算顺序沿用旧地图方法。仅无格内站时计算最近距离；未变化的格和等级复用区域结果。
- 原生会话持有静态目录、NIED 坐标与摘要状态。普通 NIED 帧只转交原始等级和活动状态两列整数，原位更新；不会每帧重新分配目录或原生测站数组。
- Dart 投影桥负责 FFI 序列化、静态目录修订识别，以及将原生返回的索引/区域结果绑定到现有 UI 视图。最大值、阈值、排序和空间归属不在 Windows Dart 路径重算。有限索引通过同步借用绑定，避免每次复制整份索引向量；诊断接口仍提供独立快照。
- LPGM 已有摘要直接绑定显示；时间窗口继续使用实时或回放的显示时钟。

任一台网更新只提交该台网；设置变化和实时/回放模式切换完整重建摘要。切换释放旧原生 owner，避免实时和回放状态混合。S-net 图片输入的更新回调补齐摘要发布，避免增量更新后依赖其他台网刷新才能看到新值。

迁移前相关源码已保存到 `tmp/station_summary_before_20261016_234820`，原有完整迁移前备份、实验资料和其他工作区修改保留。原始报文、时间、ID、测站值与云端均未修改。非原生平台保留既有实现，Windows 的正式路径直接使用原生摘要。

## 验证

- Rust 全组 37 项通过；新增模块覆盖增量最大值、清空、同值排序、正负零、UTF-16 与区域规则。
- Flutter 原生组 18 项通过：原始 1560 站 WHEWS 报文、原始 SeisJS 抓包、S-net 选择、NIED 区域/最近站、CWA/P-Alert 优先级、目录同长度修订、空数据、错误调用不替换状态、资源释放，以及现有侧栏字体布局与原始 GIF 快照。
- 新增源文件、投影桥、测试和测量工具静态分析无问题。
- 连续创建/更新/销毁 20 次后，原生摘要会话数及 Rust 当前分配字节回到调用前基线。已返回的独立快照在更新/释放后保持有效。
- Windows 正常 `lib/main.dart` Profile 构建通过；未构建 Android、未制作安装器、未替换用户正在运行的 Debug 进程。使用新 ABI 需要完整构建后重启应用，热重载不能替换已加载 DLL。

## 组件测量与尚未解决的开销

工具 `tools/benchmark_station_summary.dart` 使用原始目录、观测及 SeisJS 抓包，重复输入做吞吐测量。两种模式都预先初始化原生目录，三轮交替独立 AOT 进程，每轮 60000 次；所有结果校验值相同。

| 最大值选择与 FFI 场景 | 原 Dart 中位总耗时 | 原生中位总耗时 | 解释 |
| --- | ---: | ---: | --- |
| SeisJS 更新，NIED 1560 站未变 | 261.24 ms | 118.58 ms | 不再反复扫描 NIED，组件约减少 54.6% |
| 每次都更新 NIED，并处理 SeisJS | 261.85 ms | 631.72 ms | 纯最大值场景仍有约 0.0062 ms/次额外边界开销 |

上述测量只包括最大值选择和对应桥接，没有包含完整侧栏绑定、区域计算、检出/推算、地图绘制或 GPU。独立进程峰值 RSS 约为 Dart 17.0 MiB、原生 23.4–23.9 MiB；这份结果没有证明内存下降，不能用组件时间下降宣称完整 APP 占用下降。

初版逐帧封装五列时，NIED 场景中位约 2730.73 ms/20000 次；该实验结果保留在 `build/performance/station_summary_initial_bridge_20261017.json`。已消除重复目录/坐标传输、逐帧原生数组分配和索引复制，但目前仍需从 Dart 测站视图封装动态列。最终数据在 `build/performance/station_summary_comparison_20261017.json`，包含 DLL 和原始观测 SHA-256。
