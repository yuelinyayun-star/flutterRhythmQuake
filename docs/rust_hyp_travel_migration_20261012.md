# HYP 走时内核与候选距离复用（2026-10-12）

保留 Flutter 3.41.1 / Dart 3.11.0。本次将 Windows HYP referenceBroadFourStage 的批量 JMA2001 走时插值接入现有 Rust DLL；同一候选的参考站和未触发站距离只计算、排序一次，供多个 P/S 方案复用。P/S 推断顺序、浮点累加顺序、候选遍历、事件身份、报数和发布规则不变。其他平台使用原 Dart 走时公式，也复用候选距离。

## 备份与恢复依据

修改前备份 `D:/flutterApp/flutter-rust-hyp-migration/20261012-191417/before-hyp-migration.zip`：3,839 个文件，49,290,573 字节，SHA-256 `1b3c5c6d16d49aa274d65ce77121ab086b85bd47511c3e569915240576fb7f6a`。ZIP 成员逐项检查长度和 SHA-256；当前脏工作区完整保留。该目录含源码清单、冻结的原 source_estimator.dart、编译日志、验证程序及每轮原始输出。

## 数值与生命周期

`tools/generate_rust_hyp_tables.py` 机械复制原 Dart JMA2001 表的 50,374 个 Float64 样本及坐标，逐位核对一致，未拟合或改动原值。查表采用二分边界查找，插值仍保持先深度、后距离的原运算顺序，边界、非有限值、负值钳位和表外外推规则不变。

初次将测距移到 Rust 时，在原测站目录发现一项结果相差 1 ULP，已撤去该测距实现。现保留原 Dart 三角函数、常数和运算顺序，只将走时插值批量送入 Rust。未用放宽容差掩盖差异。

新增 `rq_hyp_geometry` ABI 1：调用方持有原顺序距离和输出 distance/P/S 三元组，Rust 不保留指针，不分配持久状态。每次有序搜索复用 FFI 输入/输出缓冲，所有返回和异常经 finally 释放；返回 Dart 的结果独立拥有数据，不将可复用原生视图交给后续消费者。调用计数只用于内部诊断，与地震报数无关。

## 原始数据与验证

使用未经修改的奈良 51 帧 GIF（20260610180120 至 20260610180210）、每帧 1,634 个测站，共 83,334 条输入；保留原时间、顺序、像素和震度，运行前后检查 SHA-256。三轮交替运行迁移前、迁移后的独立 Windows Profile 进程；原实现从本次备份恢复到专用验证副本编译，不影响用户安装的 APP。

首轮保留全部 51 帧完整输出，逐字段比较检出、事件、历史、每站观测、震源、质量及搜索诊断；共 40 次推算，所有业务字段一致，只有 40 处 `search_elapsed_ms` 计时值不同。后两轮不写完整字段文件，仍保留签名、原文件哈希和计时数据。每次迁移后均调用 Rust 1,066 次，迁移前为 0。

回归：Rust 4 项；Dart 原目录逐位对照、缓冲生命周期、51 帧工作线程回放及 NIED/P-Alert 相关回归合计 32 项通过。修改文件的 Dart 静态分析无问题。
