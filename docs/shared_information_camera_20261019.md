# 同区信息事件共享视野

普通地震情报与 ShakeMap、DYFI 原先经过不同的自动聚焦分支。轮播切换到图层时会重新按图层范围定位，切回普通情报时又按震中定位。手机普通信息还可能按最新事件定位，而卡片按另一轮播项显示；自动图层存在时，卡片没有启用地图索引同步。

## 本次行为

- 沿用现有 2500 km 分区距离。同组各震中之间均不超过该距离，避免通过中间事件把两个超距区域连起来。火山继续使用独立视野。
- 同组普通情报、ShakeMap 等烈度线、DYFI 原始网格和烈度速报测站共用一组范围；组内卡片切换及周期刷新不再重新拟合或移动地图。
- 仅保存地图几何的缓存。报号、震级和时间更新不会独立改变视野；坐标、区域或图层范围变化后更新范围。视窗尺寸改变、主动重新居中、结束手动暂停或切回另一地区时允许重新定位。
- 地图图层仍使用原坐标；DYFI 保留既有网格最小像素和自动缩放限制。优先用同组图层的震中作为固定锚点。
- 手机普通信息按当前统一轮播索引定位，卡片沿用地图提交的当前事件。自动 ShakeMap／DYFI 存在时也启用同一逻辑。
- EEW、推算／检出和手动历史选择仍经过各自已有的优先级；没有合并、删除任何信息源事件，也没有改动订阅与原报文。
- 信息结束时释放几何缓存。

## 验证

- 11 个地图／信息显示测试文件共 76 项通过；另补充手机自动 ShakeMap 卡片同步测试，通过。最终针对共享视野和手机卡片的 15 项测试全部通过，以上共有 77 个不同测试。
- 使用已归档原始 USGS ShakeMap 等烈度线，在桌面 1584×850 和手机 390×844 尺寸测试同组事件连续切换，地图中心与缩放不变，地图移动事件数为 0。
- 核验分区不会超距串联、不同区域仍可切换、其他远处事件更新不改变当前组视野，以及缓存释放和重新跟随。
- 原有 CENC 测站、JMA 震度、火山、EEW 波圈与 DYFI 网格相机测试通过。
- Dart 分析没有错误或警告，地图大文件仍有既有代码风格提示。
- Windows Profile 构建通过（97.3 秒）。没有启动实际 API 连接，也没有编译安卓。

回归与构建日志位于 `tmp/shared_info_camera_20261019/`；修改前相关文件及 SHA-256 清单位于 `before/` 和 `before-manifest.json`。
