# 统一事件链原生迁移（2026-10-19）

本轮迁移 Windows 统一事件接纳与生命周期。默认路径为 Rust 常驻会话和独立工作线程；Dart 保留不可变展示对象、UI 绑定与平台插件调用。没有修改原始报文或扩大 WHEWS 的烈度处理规则。

## 已迁移的状态与运算

| 环节 | 原生负责的内容 |
| --- | --- |
| 接纳 | 来源开关、震级过滤、地点白名单、历史与实时区分、来源时间和到达时间窗口 |
| 身份 | 多 API 的 EEW 身份与别名、回放会话隔离、机构目录身份、CENC 秒／分钟精度、Early-est ID 前缀 |
| 修订 | 旧报拦截、同报正文修订、正式／自动报优先级、正文去重、取消报终态与恢复窗口 |
| 生命周期 | 到期调度、取消报 20 秒展示、待播更新合并、解除展示后的抑制状态 |
| EEW 历史 | 启动恢复合并、报序、取消报排序、分组、按源保留数量、原文释放后的句柄替换 |
| 信息列表 | 单源行匹配、已证明的 ID 别名、旧报保护、裁剪、排序；最终列表的筛选、JMA 去重、排序及变化判断 |
| 持久化索引 | 已见正文／事件、已接纳报号、取消状态的原格式行编码和过期／数量限制 |

实时命令经过 `rq-unified-events` 工作线程，按序返回展示句柄和效果指令。过期和 300 毫秒更新合并由原生截止时间唤醒，没有周期扫描线程。无任务时等待条件变量。

生产模式的列表行合并同样走异步工作线程。Dart 每个列表只串行传递请求、绑定原对象；若等待时上游替换了列表快照，重新提交新快照，避免旧结果覆盖新列表。Early-est 已入站但尚未完成 UI 绑定的历史报也在原生保留比较状态，防止此时接纳较旧的实时报。

## 原始数据和兼容性

- 来源 ID、经纬度、报号、时间、原始正文保持不变；规范化值只作为比较身份和展示派生字段。
- 原始正文仍附在现有只读展示对象或磁盘引用上，不完整复制进原生生命周期状态。非 Jian 来源不会为读取无关状态而解开编码正文。
- 保存历史转成轻量摘要后，原生只替换显示句柄；Dart 释放旧正文对象，原生保留原有身份和报序比较信息。
- 已有偏好键及 `key|timestamp`、`key|report|timestamp` 格式保持兼容。小数比较键按 Dart 的边界舍入方式生成。
- 普通报与同报号取消报可以共同保存在历史中；取消后的迟到普通报不会恢复事件。取消报不会延续普通报的长展示窗口。
- 对外通知、OBS、语音等平台调用仍由主 isolate 执行，接纳／更新／取消／过期和更新合并指令来自原生。
- `nativeUnifiedEvents: false` 为旧实现对照入口；Windows 正常路径不在原生错误时自动切回旧处理。其他平台保留既有实现，本轮没有构建 Android。

## 验证

使用 `RQ_STATION_CORE_LIBRARY` 明确加载本轮 Release DLL，避免单元测试走默认的非原生路径。

- 29 个相关测试文件：274 项通过，1 项因未提供可选本机历史副本而按既有设置跳过。
- 43 份提供的 JMA 原始电文：每报接纳后的活动事件和历史内容与旧实现逐条对照，ZIP 哈希保持不变。
- 44 份捕获的多源原始报文：身份键和列表展示字段与旧实现对照。
- 原始 CENC、Early-est、CMT 历史：正反到达顺序和旧报重放结果与旧行合并规则对照。
- 真实原生线程：启动恢复前等待、取消报 20 秒到期、队列清空、关闭后的会话／线程计数恢复。
- 列表异步绑定：原始报号 6／9 的顺序保护，以及等待期间列表快照被替换的竞态。
- 历史摘要句柄替换后不再保留旧原文对象；只读键查询不会重新常驻原文。
- 舍入边界、历史烈度派生值、Jian CEA 效果、回放、取消报、语音更新、ShakeMap／DYFI 轮播与地图联动回归。

测试修正仅补上 LPGM 测试缺少的 SharedPreferences 模拟，并把既有 Jian 测试中“历史仍需要徽章估算”和“历史不触发实时警报”分开断言；没有更改这两项产品行为。

原始 43 报的单次组件测量：提交耗时 6.333 ms，原生命令处理合计 3.849 ms，最慢一条 0.178 ms；结束后输入与输出队列均为零。此数值来自测试进程，不能当作整机 APP 的 CPU／内存降幅。20 秒取消窗口的真实线程测试也核对了截止时间唤醒次数，避免空闲轮询。

构建、分析、对照日志和组件测量位于 `tmp/unified_event_owner_20261019/`。迁移前 12 个相关文件及 SHA-256 清单位于其 `before/` 和 `before-manifest.json`；未清理已有备份或其他工作区修改。

Windows Profile 构建通过；依赖锁文件后续更新后，按当前依赖重新验证 274 项通过、1 项跳过，并再次构建成功（139.1 秒）。安装目录中的原生 DLL 与回归测试 DLL 的 SHA-256 相同：`914bb88087ffb50aadcab989ad5e69df81eff717786648094a009ecfbccba289`。本轮没有运行连接实际 API 的 APP，也没有得到整机 CPU／内存的新对照数据。

## 实现入口

- `lib/providers/quake_provider_native_events.dart`：UI、存储与平台效果指令绑定。
- `lib/services/native_unified_event_owner_io.dart`：不可变对象句柄、紧凑字段编解码和原生消息端口。
- `native/station_core/src/unified_event_runtime.rs`：线程、输入输出队列、截止时间等待与关闭。
- `native/station_core/src/unified_event_state.rs`：事件、历史、取消和去重状态。
- `native/station_core/src/unified_event_policy.rs`：身份、修订、时间窗口和兼容比较规则。
- `native/station_core/src/unified_catalog_bucket.rs`、`unified_catalog_history.rs`：列表行合并和最终历史投影。
- `test/native_unified_event_owner_test.dart`：原始电文对照、真实线程和对象释放验证。

其他来源适配器、语音文本生成、地图渲染、测站与推算链不属于本轮“统一事件接纳与生命周期”的迁移范围，不能据此认定全部后端已经迁完。
