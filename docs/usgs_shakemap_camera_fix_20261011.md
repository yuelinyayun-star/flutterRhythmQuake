# ShakeMap 震中视角修复（2026-10-11）

截图中的视角偏移来自产品聚焦方式：原先使用整张产品栅格的地理外框拟合，没有指定震中锚点。外框包含没有等烈度线的空白区域，其中心不必与震中一致。

现已由自动显示和列表显示共用 `focusUsgsShakeMap`：以事件原始经纬度为锚点，拟合实际绘制的等烈度线。没有等烈度线时才使用原始栅格边界。可视范围扣除桌面左侧信息列表、右侧面板、顶部与底部图例；震中位于这块可视地图的中心。沿用现有地图控制器、缩放上下限和手动操作暂停规则。

同时修复历史震中绘制器的重绘判断：相机中心、缩放、旋转、窗口尺寸改变时重新绘制，避免旧像素位置残留。震中样式和原始坐标保持原规则。

验证使用原始 USGS 产品 `ci41345415`、`us6000u0xi`、`aka2026tvzrwv`，分别覆盖 1584×850、1200×800、430×900。9 项测试全部通过：震中与可视中心误差小于 1 像素，所有实际等烈度线顶点位于可视范围，手动暂停后保持原视角，原始详情与等烈度线文件 SHA-256 不变。其中无等烈度线的产品也验证了边界处理。

测试：`test/usgs_shakemap_camera_fit_test.dart`。日志：`build/performance/shakemap-camera-final.log`。几何渲染截图：`tmp/usgs_camera/*_centered.png`（Flutter 测试字体，仅作几何核验）。相关 CENC 相机与 ShakeMap 图层 14 项既有测试通过。
