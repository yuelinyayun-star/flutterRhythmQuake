# 本项目字段获取与注册映射（Wolfx / FAN）

## 1. 目标与原则
- 目标：将 Wolfx、FAN 原始字段解析后，统一注册到项目事件模型 `QuakeMessage`。
- 原则：保留原始数据语义，不改写上游时间字符串本意；展示和计算阶段再按信源时区处理。
- 时区策略：JP 信源按 `UTC+9`，其他默认按 `UTC+8`。

## 2. 统一模型字段（QuakeMessage）
- 基础字段：`source`、`eventId`、`location`、`magnitude`、`latitude`、`longitude`、`depth`、`originTime`、`maxIntensity`
- 扩展字段：`jmaShindo`、`reviewType`、`infoTypeName`、`verify`
- 新增字段：`reportNumber`（第几报）、`reportTime`（发报时间）、`province`（省级分中心所在省份）
- 状态字段：`isTest`、`isHistory`、`isInfoEvent`、`isTsunamiWarning`、`tsunamiWarning`

## 4. FAN 字段注册映射

### 4.1 `/jma`、`/cea`、`/cea-pr`、`/cwa-eew`、`/kma-eew` 等更新流
- 来源文件：[fan_service.dart](file:///d:/flutterApp/flutterrhythmquake/lib/services/sources/fan_service.dart)
- 关键映射：
- `shockTime -> originTime`
- `updates -> reportNumber`
- `createTime -> reportTime`
- `province -> province`（`/cea-pr`）
- `placeName/locationDesc/title -> location`
- `epiIntensity/maxIntensity -> maxIntensity`

### 4.1.1 `/cea` 专项（中国地震预警网地震预警）
- 典型报文：`{"Data":{...}, "md5":"..."}`（允许无 `type` 直接推送）
- 字段映射：
- `Data.id/eventId -> eventId`（优先 `eventId`）
- `Data.shockTime(UTC+8) -> originTime`
- `Data.placeName -> location`
- `Data.longitude/latitude/depth/magnitude -> 基础震源参数`
- `Data.epiIntensity -> maxIntensity`（有原始值优先使用）
- `Data.updates -> reportNumber`

### 4.3 `/cea-pr` 专项显示
- 显示名称：`中国地震预警网省级网地震预警`
- 来源标签：`省级网/<province>`
- 地名展示：优先显示 `<province> + placeName/locationDesc`

### 4.2 其他信息流（`/usgs`、`/hko`、`/fssn` 等）
- 统一走 `_parseFanEvent` 注册基础字段。
- 若无 `updates`，`reportNumber` 保持空值（UI 显示 `第?报`）。

## 5. 时区显示与计算映射
- 工具文件：[quake_time.dart](file:///d:/flutterApp/flutterrhythmquake/lib/core/utils/quake_time.dart)
- 规则：
- JP 信源（`wolfx`、`nied`、`p2p`、`jma_fan`）按 `UTC+9`
- 其他信源按 `UTC+8`
- 展示：地震列表、预警卡片均通过 `QuakeTime.displayClock()` + `QuakeTime.zoneLabel()`
- 计算：倒计时/P-S 波半径使用 `QuakeTime.normalizedOriginLocal()`，避免时区错算。

## 6. 第几报显示规则
- UI 文件：[alert_module.dart](file:///d:/flutterApp/flutterrhythmquake/lib/widgets/ui/alert_module.dart)
- 规则：
- `reportNumber > 0` 显示 `第N报`
- 空值显示 `第?报`

## 6.1 无原始烈度自动转换规则
- 规则：除 JP 的 JMA 与台湾 CWA 外，若上游未提供原始震度/烈度，则自动进行烈度转换。
- 当前实现：
- `FAN`：`jma_fan`、`cwa`、`cwa_eew` 不转换，其他源缺失时使用 `IntensityCalculator.calcCsisLevel(...)`
- `Wolfx`：`wolfx(jma_eew)`、`cwa_eew` 不转换，其他源缺失时使用 `IntensityCalculator.calcCsisLevel(...)`

## 9. CENC CMT 字段映射

### 9.1 数据来源
- 页面：`https://data.earthquake.cn/datashare/report.shtml?PAGEID=earthquake_dzzyjz`
- 来源文件：[cenc_cmt_service.dart](file:///d:/flutterApp/flutterrhythmquake/lib/services/sources/cenc_cmt_service.dart)
- 适配器：[quake_event_adapter.dart](file:///d:/flutterApp/flutterrhythmquake/lib/services/quake_event_adapter.dart) `_cencCmt` 方法
- 获取方式：HTTP 轮询（5 分钟）+ 正则解析 HTML 表格
- 两套目录：自动产出（`cmtype=auto`）与人工复核（`cmtype=review`），人工复核优先

### 9.2 字段映射
| HTML 表格列 | 模型字段 | 说明 |
|---|---|---|
| 发震时刻(北京时间) | `originTime` | Service 转 UTC ISO8601（带 Z） |
| 震中纬度 | `latitude` | |
| 震中经度 | `longitude` | |
| 震源深度 | `depth` | km，UI 显示用 |
| 速报震级 | `magnitude`（fallback） | Mw 缺失时用 |
| Mw 震级 | `magnitude`（优先） | |
| 矩心深度 | `centroidDepth` | km，beachball 下方标注 |
| 断层面1 走向/倾角/滑动角 | `nodalPlane1` = `"strike/dip/rake"` | |
| 断层面2 走向/倾角/滑动角 | `nodalPlane2` = `"strike/dip/rake"` | |
| 自动产出/人工复核 | `reviewType` + `reportNumText` | UI 显示"自动测定"/"正式测定" |
| （构造） | `eventId` = `cenc_cmt_<time>_<lat>_<lng>` | 复用 `_cencInfoEventId` 思路 |

### 9.3 深度字段说明
- `depth`：震源深度（速报值），用于 UI 显示与烈度估算
- `centroidDepth`：矩心深度（CMT 反演值），用于 beachball 下方标注
- 两者物理含义不同，大地震差异可达 10~30km

### 9.4 调用链路
`CencCmtService.fetch -> onListUpdated -> QuakeProvider._handleCencCmtList -> QuakeEventAdapter.convert('cencCmt') -> _handleUnifiedEvent -> 统一UI + eqlist桶 + 地图beachball`

## 10. USGS CMT 字段映射

### 10.1 数据来源
- API：`https://earthquake.usgs.gov/fdsnws/event/1/query`
- 来源文件：[usgs_cmt_service.dart](file:///d:/flutterApp/flutterrhythmquake/lib/services/sources/usgs_cmt_service.dart)
- 适配器：[quake_event_adapter.dart](file:///d:/flutterApp/flutterrhythmquake/lib/services/quake_event_adapter.dart) `_usgsCmt` 方法
- 获取方式：两步 HTTP 轮询（5 分钟）
  1. FDSN query + `producttype=moment-tensor` 获取含 CMT 的事件列表
  2. 对每个事件用 `eventid=xxx` 获取详情，提取 `products.moment-tensor[0]`（按 preferredWeight 排序）
- FDSN query 返回的 GeoJSON 不含 products 对象，必须逐事件获取详情

### 10.2 字段映射
| moment-tensor 产品属性 | 模型字段 | 说明 |
|---|---|---|
| `eventtime` | `originTime` | UTC ISO，Service 转 UTC+8 字符串 |
| `latitude`（feature.geometry） | `latitude` | 震中纬度 |
| `longitude`（feature.geometry） | `longitude` | 震中经度 |
| `coordinates[2]`（feature.geometry） | `depth` | 震源深度 km，UI 显示用 |
| `derived-magnitude` | `magnitude`（优先） | 矩震级 Mw |
| `mag`（feature.properties） | `magnitude`（fallback） | Mw 缺失时用速报震级 |
| `derived-depth` | `centroidDepth` | 矩心深度 km，beachball 下方标注 |
| `nodal-plane-1-strike/dip/rake` | `nodalPlane1` = `"strike/dip/rake"` | |
| `nodal-plane-2-strike/dip/rake` | `nodalPlane2` = `"strike/dip/rake"` | |
| `review-status` / `evaluation-status` | `reviewType` + `reportNumText` | reviewed/confirmed → "正式测定"，否则"自动测定" |
| `feature.id` | `eventId` | 如 `us7000t37a` |

### 10.3 深度字段说明
- `depth`：震源深度（feature.geometry.coordinates[2]），用于 UI 显示与烈度估算
- `centroidDepth`：矩心深度（`derived-depth`），用于 beachball 下方标注
- 两者物理含义不同，大地震差异可达 10~30km

### 10.4 调用链路
`UsgsCmtService.fetch -> onListUpdated -> QuakeProvider._handleUsgsCmtList -> QuakeEventAdapter.convert('usgsCmt') -> _handleUnifiedEvent -> 统一UI + eqlist桶 + 地图beachball`
