# 测站 JSON 与数值处理迁移（2026-10-15）

Windows WHEWS/Jian 的高频测站观测已接入 Rust JSON 解析、原始数值的 Float64 展示转换、有限性与最小/最大值归集，并使用独立拥有的紧凑只读快照。TCP/WS、认证、心跳、时间解析、过期/重复拦截、目录与坐标、机构归属和发布规则仍由原 Dart 路径处理。没有改 SDK、云端、原始时间或观测值。

这是测站输入链的迁移。WHEWS `/ws/all`、Jian `/all` 的地震与海啸事件分发仍沿用原路径；Android/Web 继续使用 Dart，没有把整个数据层宣称为已迁移。

## 备份与数据边界

改动前文件和输入哈希保存在 `build/performance/backups/station-json-20261015-090719`。旧原文快照和 WHEWS 数值循环冻结于：

- `test/support/source_payload_before_station_json_20261015.dart`
- `test/support/station_json_values_before_20261015.dart`

Rust 接收原始 String 的 UTF-16 单元，避免把未配对代理项替换后再处理。JSON 原始整数、浮点位、字符串、字段顺序、未知字段及嵌套结构都保留；重复对象键沿用 Dart 的末值覆盖、首次位置规则。派生 Float64 数组与原始叶节点分别保存，派生值等同原 `num.toDouble()`；不先修改、裁剪或四舍五入原数据。

纯数值数组在 Rust 中一次计算转换值、有限性、最小值和最大值。Dart 按原机构阈值作常数时间判断，直接取得只读 Float64 视图。WHEWS 的数字字符串仍按原 `double.tryParse` 规则处理；Jian 仍拒绝字符串数值。无效 PGA/PGV 仍不阻断有效主观测。原始 JSON 的数组读取保持原 int/double 类型，不用展示数组覆盖原文。

每连接一个原生 owner，重用解析与 FFI 缓冲。返回借用块在同步调用内复制到独立 Dart 存储，历史、回放和 UI 都不持有原生指针。停止、连接错误和重连会销毁 owner；已发布快照与数值视图在销毁后仍可读取。所有快照及数值视图禁止外部修改。

首次目录报文保持 Dart 路径，收到有效目录后才启动高频观测解析。已建目录后的更新报文也能完整解码，但本轮没有宣称目录解析本身更快。解析错误沿用各接收器原规则，不会通过修改数据或改用另一套数值规则重试。

ABI 1 的输入/输出上限为 64 MiB，节点上限 200 万，嵌套深度上限 512。输出为节点、子项索引、UTF-16 字符池与派生数值池，定义在 `native/station_core/include/rq_station_core.h`。未增加 Rust 第三方依赖。

## 原始输入与行为核验

真实 WHEWS NIED 原始抓包包含 1560 个目录站及各 1560 个 shindo/PGA/PGV 值：

- `test/fixtures/whews_nied/observations.json`：`ae900469e29ea06beb9dd97c2123cc3abb2cecce0d0f92f2c790303a64a1de67`
- 目录与 Jian 已存快照的哈希记录在备份清单，工作结束再次核验全部未改变。

六份已有 WHEWS/Jian 原始 JSON 逐字段、顺序、int/double 类型与 Float64 位对照原 Dart，JSON 导出一致；真实 NIED 原文通过本地 WS 进入生产服务，再经历史归档编码/还原，字段和值保持一致。原始文件的时间没有为测试改写，WHEWS 仍使用既有 UTC+8 约定。

额外受控协议测试覆盖 Int64 边界、溢出整数转浮点、负零、非有限数、极小/极大浮点、未配对代理项、日文/中文/emoji、重复键、非法语法和 5000 个确定种子的数值字面量。它们是编码/生命周期测试，不是地震或测站实况。Jian 测站的时效/重复/停止测试使用明确标注的受控协议输入；没有用历史 `/all` 快照冒充当前 Jian 测站观测。

原始 1560 站的转换值逐位相同。重复原始观测不重复发布，远端断开后 native 会话归零，旧快照与历史原文仍可读；连续 100 次创建、解析、销毁后 Rust 当前分配回到预热基线。

## 性能与实际限制

单独迁移 JSON 的首版测试曾出现观测与目录退步，未把该路径接入生产。最终实现合并数值转换与校验，避免逐元素临时 ASCII 分配、重复深拷贝以及 Dart 数值列表重建；首次目录仍保留 Dart。

最终基准使用冻结的旧快照和旧数值循环，而非改造后的 Dart 分支。同一 Dart 3.11.0 AOT，三轮交替顺序、独立进程；每轮 3000 次重放同一份未修改观测，共处理 14,040,000 个原始数值。计时包含解析、快照、三个数组的转换/校验、FFI、输出复制及逐项消费，不包含网络、UI、语音或磁盘读取。

| 范围 | 原 Dart 中位数 | Rust 路径中位数 | 结果 |
| --- | ---: | ---: | --- |
| 3000 份原始 1560 站观测处理 | 1855.217 ms | 1395.500 ms | 耗时下降 24.78% |
| 同一组件 RSS | 16.441 MiB | 17.367 MiB | 增加约 0.926 MiB |

校验和各轮相同。此前约 31% 的初测没有冻结旧快照循环；以上最终对照取代该数字。RSS 仍包含原生缓冲，不能只报告 Dart 堆变化。不能把组件耗时下降当作 APP 总 CPU/GPU 降幅或主界面帧率结论。

可复现入口：`tools/benchmark_station_json.ps1`。原始三轮、SDK、DLL 与抓包哈希：`build/performance/station_json_observations_20261015.json`。

本轮尚未达到迁移计划中提议的 30% 组件 CPU 或 20% 内存门槛，整机固定输入长时验收也未完成。当前属于开发验证接入，没有制作正式安装包或发布版本。
