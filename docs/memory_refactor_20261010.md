## 同一份原始数据的测量

对备份中 **163 份 GlobalQuake 报文**，使用同一个 Dart SDK 预热并分别执行 GC，比较仅由这些原文带来的堆增量：

| 表示方式 | GC 后堆增量 |
| --- | ---: |
| 原不可变嵌套 Map/List | 34,520,368 字节，32.92 MiB |
| 完整 UTF-8 按需展开 | 3,759,040 字节，3.58 MiB |
| 差值 | 29.34 MiB，减少 89.11% |

这是单独原文对象实验，**不是 APP 总 RSS 的降幅**。结果保存在诊断目录的 `payload-before.json` / `payload-after.json`。

实际 Windows Profile 运行中，两次缓存采样跨过一次服务轮询周期，图片缓存均只有一张 `RadarFrameImage`，解码缓存大小 24,912,008 字节（23.76 MiB）。旧诊断中的两张雷达缓存共 47.52 MiB；不同图片缓存身份的替换和退出清理另有真实 PNG 渲染测试验证。

运行检查还确认：未启用背景的 `_customBytes == null`；AssetBundle 不再缓存上述四份地图原始文本。当前 AssetBundle 仍有按原逻辑加载的走时表文本，本次没有改动它。
