# 韩国地名及中日韩分区对照

本页记录最初韩国陆地接入。当前实际查询已使用物理裁剪后的派生索引，基础FE粗区
不再显示“韩国附近”，详见`east_asia_effective_names_20261020.md`。

采用韩国官方SGIS网站2025年17个市道多边形，替代陆地查询原先只有“韩国”的FE粗分区。
原始文件URL：https://sgis.mods.go.kr/js/data/geo_sido_2025.js 。
数据口径与构建步骤、原文件哈希见 `tool/region_data/README.md`。

只读几何编译进Rust模块，查询复用本项目CWR1多边形引擎，Dart只传坐标并读取地名。
中国现有行政区、台湾陆地和海域优先级保留；日本海域接入不受影响。
当前既有FFI宿主为Windows，其他平台继续原有查询。

韩国陆地名称为：首尔特别市、釜山广域市、大邱广域市、仁川广域市、光州广域市、
大田广域市、蔚山广域市、世宗特别自治市、京畿道、江原特别自治道、忠清北道、
忠清南道、全北特别自治道、全罗南道、庆尚北道、庆尚南道、济州特别自治道。
上述名称加“韩国”前缀；与原始韩文属性分开保存。

源庆尚北道中两个独岛（竹岛）多边形保留全部原几何，单独使用中性地理名称，
不附加日韩归属。苏岩礁不作为韩国陆地处理，也不由陆地多边形推导海洋管辖范围。
海域继续既有FE地理海区；KMA官方的“地点＋方向＋距离”解释不等于固定海域分区：
https://www.weather.go.kr/w/XML/INTENSITY/report_20211214171914.pdf 。

验证：3项新增Rust测试通过；30项Flutter测试通过（含3项新增韩国测试、既有中日台地名、
KMA来源一致性、原报文未变、加载时序）；相关Dart静态分析无问题。
隔离目录全量重建的所有二进制逐字节一致，原始SGIS文件哈希未变。
这轮没有重新打包或启动完整APP。

另行绘制的中日韩地名对照图仅用于查看，预览显示精度简化不回写运行时查询资产；
既有FE粗分区使用虚线，与真实多边形区分。
