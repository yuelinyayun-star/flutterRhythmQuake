# 台湾震中地名映射核验

## 结论

已确认原始数据的离岛陆地覆盖缺失，以及异步加载时旧的粗略名称可能被保留。
本次仅核验，没有改动生产代码、运行时映射文件、上游报文或原始 GeoJSON。

- 输入：用户提供的 `cwa_epicenter_regions.geojson`，935,003 字节。
- 输入 SHA256：`1544404e4b3f2ff576960c1d246e2f35714eb4321785daacd778b671f684bacd`。
- 按现有 `tool/region_data/build_region_assets.py` 的 `build_cwa` 单独转换后，
  与现有 `assets/regions/cwa_epicenter_regions.bin` 逐字节一致。

  `8f4c619a7e42f200b7313dc095a3906458707bfbd78f3c039bc624e016cec475`。
- 原文件371个要素：陆地348、近岸海域15、海域8；所有坐标有限且在合法范围，环闭合。
- 在经度118–124、纬度20–27、间隔0.02度的105,651个网格点核验中，
  未发现陆地与海域类别重叠导致“小包围框优先”选错类别的情况。

## 缺少20个离岛乡镇的陆地要素

与项目 `lib/core/cwa_prediction_towns.dart` 已收录的368个乡镇名称对照，
原始文件完全没有以下20个陆地要素：

- 高雄市旗津區、屏東縣琉球鄉、臺東縣綠島鄉、臺東縣蘭嶼鄉。
- 澎湖縣：馬公市、湖西鄉、白沙鄉、西嶼鄉、望安鄉、七美鄉。
- 金門縣：金城鎮、金沙鎮、金湖鎮、金寧鄉、烈嶼鄉、烏坵鄉。
- 連江縣：南竿鄉、北竿鄉、莒光鄉、東引鄉。

以下查询直接调用当前 Dart 解析器。坐标取自项目原有乡镇参考数据，
没有移动或改写坐标；这些是地理核验点，不是测试地震报文。

因果链：原始文件没有这些乡镇的陆地边界；现有查询先匹配中国行政区多边形，
再查询网格、日本陆地遮罩和CWA分区。缺失陆地不会阻止其位置命中海域，
部分离岛还会先匹配到较粗的行政区名称。

另外有3个已收录陆地乡镇的参考点查询到相邻乡镇。乡镇参考点未必位于对应
行政边界内部，因此不能仅凭参考名称把这3例定为边界错误；本结论不把它们
计入已确认缺失项。

## 首批粗略地名可能被保留

调用链：

1. `getFEName` 在地名库未加载时调用 `unawaited(load())`。
2. 原始资源尚未返回时，当前查询使用1度FE网格名称。
3. 例如USGS标准化会把该名称写入事件的 `location`。
4. `catalogDisplayLocation` 对已有中文直接保留，不会重新按坐标查询。
5. 统一事件也保存字符串，地名资源加载本身不触发这些事件重命名。

受控延迟原始资源返回的测试复现结果，核验坐标为
`23.1101922, 121.3562179`：

| 阶段 | 结果 |
|---|---|
| 资源未加载时首次查询 | 中国台湾附近 |
| 加载完成后重新按坐标查询 | 臺東縣成功鎮附近 |
| 把首次生成的中文交回现有显示转换 | 中国台湾附近 |

延迟测试只控制读取时机，所有资源字节、坐标保持不变。
它证明存在时序缺陷，不声称已观察到用户当前进程必然发生这个时序。
上游本来提供的中文地名也走保留分支，应与本机临时生成的粗略名称区分，
不能为修复此问题而一律覆盖上游中文。

## 修复边界

- 更换为包含上述离岛陆地边界的原始分区数据；仅改文件名或重新生成当前
  二进制不会改变查询结果。
- 精确陆地区域与近岸、海域应分层匹配；避免粗行政区先遮住精确陆地名称。
- 对本机异步加载前生成的地名处理加载完成后的刷新或保证进入标准化前
  资源就绪，同时保留上游原始中文名称。
- 不用乡镇中心点的圆形范围、矩形或最近中心距离替代真实边界。
