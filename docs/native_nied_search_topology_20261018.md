# NIED 原生计算迁移：搜索与拓扑（2026-10-18）

## 当前完成范围

Windows 原生主路径已移除 HYP 搜索内部的 Dart 距离回调。坐标原值在评分会话创建时上传一次，由 Rust 持有坐标及预计算余弦；候选点的距离、P/S 评分和四阶段搜索在同一原生调用中完成，返回原有数值、相位与搜索日志。单点评分同样直接进入原生几何。

NIED 推算拓扑由原生完成全站距离、距离/ID 排序、30 km 密集邻接、40 km 稀疏补站及 300 km 内四方向覆盖，再输出已有邻接字段。Dart 绑定准备好的邻接结果，不再逐站计算全网距离后调用排序内核。

实时检出会话也改为从原始坐标直接创建原生几何和邻接。检出原有的距离排序、相等距离顺序、稀疏候选取舍及配对距离由 Rust 持有。它与推算拓扑使用的排序和距离规则不同，本轮分别保留，没有混用。

## 数值与行为验证

初始按位对照发现 libm 实现与此 Windows Dart 运行时在部分结果末位不同。已采用与当前 Windows 运行时相符的原生数学操作和原运算顺序。冻结评分与搜索测试逐位比较候选移动、终止状态、分数和 P/S 相位，不放宽原断言。

真实 Nara 原始 GIF 测试包含 51 帧、1634 站，产生 40 个有推算结果的帧。完整邻接表、反向站序、实时入口到检出/归档/展示投影、原始保存历史及 EEW 同场景回放通过。本轮相关回归 20 项通过；评分、搜索与 P-A 实时/归档回归另外 4 项通过。

原生单元测试 52 项通过，包括新几何入口的无效初始化/复用和拓扑结果的原始顺序、相同坐标、Unicode、空字符与所有权释放。主震源估计算法文件与迁移前备份 SHA-256 相同；没有合入其他会话中仍在研究的搜索修正算法。

## 仍需迁移的常驻处理

NIED 全链尚未迁移完成。数据 owner 和推算 owner 仍是 Dart isolate；逐站观测样本构造、事件记录生命周期、质量标志/观测元数据管理、分簇与输出会话编排仍有 Dart 处理。真实回放 CPU 采样中，`_dartHypocenterInput`、`ingestFrame`、`_appendObservation` 和拓扑初始化可见；搜索段迁移单独测量仅有小幅收益，因此后续应优先迁移观测及事件记录 owner，而不是重复微调已经原生化的搜索内核。

本轮备份、冻结参考、原始日志、CPU 样本与测量结果位于 `tmp/nied_complete_native_20261018/`。原始采集目录未修改，原始报文和图像没有替换为合成输入。新 API 需要与本轮原生 DLL 配套，必须完全退出旧进程后启动新构建，热重载不能替换已载入 DLL。没有构建 Android、修改云端、提交或推送。
