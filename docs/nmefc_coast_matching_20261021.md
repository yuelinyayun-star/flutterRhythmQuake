# NMEFC 报文格式与具名岸线匹配

大陆沿海已扩展为11个沿海省区市的62个行政单元，另含港澳。此前17个台湾省岸线保留。
当前覆盖、源数据及独立验证见 `nmefc_mainland_coasts_20261021.md`；下文乡镇资料描述
仅适用于台湾省部分，不再表示整个匹配器仅支持台湾省。

地区来自`forecasts[].forecastArea`，省份和等级分别来自`province`、`warningLevel`。
不使用forecastPoint、验潮站名、震源名或图片URL代替预报区。
此前具名岸线服务仅允许CWA，其六区名称不能直接套用NMEFC地区名称。

## 接入范围

- 新增NMEFC具名岸线入口，Rust负责省份、名称、唯一性、颜色及重复区域合并。
  Dart仅加载资源、传递原文。显式几何仍优先。
- 复用固定哈希的官方1120317乡镇界，离线合并县市，取联合陆地外环与各县市的交集。
  不画县界、乡镇界和内陆孔洞。这一部分覆盖台湾省17个有海岸的县市。
- 这是具名行政岸线底图，不是机构警戒边界或淹没范围。原始ZIP、报文和底图不回写。
  派生叠加使用1e-9度精度网格；仅合并相接线段，不抽稀、缓冲或连测站点。
  构建检查所有输出均位于联合陆地外岸线上。
- 用户已选择按县市一级显示岸线。完整行政名及该级别唯一的简称均匹配：
  “花莲”“花蓮”对应花莲县，“宜兰”“宜蘭”对应宜兰县，而非同名乡镇级市。
  保留县市全名和省份前缀。新竹县、新竹市都有岸线，“新竹”仍判为歧义；
  “台东北”等方位分区不删除方位后扩大成整个县。
- 冲突省份不匹配，名称有歧义不取第一项，解除/未知等级不继承全局颜色。重复地区
  只绘一次，取原报文明确发布的最高地区等级。未匹配项保留名称、省份、等级与原因。
- 这属于用户选定的行政岸线展示约定，不表示已取得NMEFC官方预报岸段边界。
