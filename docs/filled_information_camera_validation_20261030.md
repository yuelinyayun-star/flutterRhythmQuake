## 跨日期变更线失败的边界与归因

原始 Alaska 产品震中经度 `178.854°`，网格经度范围 `176.083°～181.883°`；`181.883°` 是跨日期变更线的连续表示，不是可以直接删除的原始错误数据。当前 `MapStateProvider._fitPointsAroundAnchor` 先调用 `QuakeCalculator.isUsableMapCoordinate`，后调用 `WorldWrap.longitudeClosestTo`；前者要求经度绝对值不超过180，因此该范围点在传入 Rust 的 offsets 之前已经被排除。原始文件未修改。

已核对 Git HEAD `ac247d859919d182056bb01a51fcc9d1a7bc1e78` 中迁移前的同一函数，过滤与换算顺序相同：旧 Dart 计算也会删除此点。原版本源码保存为 `tmp/jma_info_center_20261030/pre-rust-map-state-baseline.dart`。这是现有路径上的问题，不能将其错误归因于本轮 Rust 计算或震中约束修复；当前失败也不能以迁移前存在为理由写成通过。已确认影响的是该跨线原始网格的范围拟合；同一适配入口收到其他越过±180的连续范围点也有同样风险，不据此声称所有 USGS、CENC 或 JMA 均失败。

本轮用户要求补测，且此前指定只恢复删除的中心约束，因此保留失败用例与证据，未扩大范围修改生产经度规则。
