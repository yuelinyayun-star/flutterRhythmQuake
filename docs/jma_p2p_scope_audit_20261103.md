# JMA / P2P 情报区域数值改动范围审查

本轮审查的是整次四类普通 JMA/P2P 情报的区域数值功能，包括样式、区域位置和缩放；不是只检查最后的数字 1。本轮没有修改生产代码、重新部署或向云电脑注入报文。

## 结论

没有发现新方格、区域数字、配色或相机规则被开启到 CENC/CWA/KMA 等其他类型。确认了一处不应扩散的附加计算：共用 `IntensityFillLayer` 为没有标签的其他类型多边形也构造了新标签样式。

## 确认的问题：未启用标签仍计算标签样式

位置：`lib/widgets/map/intensity_fill_layer.dart:550`。

`labelPlacement` 和 `label` 已受 `showRegionValues && source == 'jp' && mode == jma` 限制，但是 `labelStyle: jmaRegionValueTextStyle.copyWith(color: jmaRegionValueBadgeForeground(color))` 在这个条件之外，对每个被填色的多边形都执行。

因此 CENC、CWA、KMA、日本 EEW，以及调用 `IntensityFillLayer.cencObserved` 的仪器烈度速报，也会生成不用的字体/颜色样式。没有画出标签，没有改原填色颜色、透明度、震度阈值或区域几何。额外计算发生在生成/重建多边形时，平移、缩放仍复用已有多边形缓存；本次没有把它夸大成内存泄漏或已测得的 CPU 占用增幅。

这处应收窄到真正生成标签的主轮廓；没有标签的多边形应保留原来的默认样式。本轮只记录，尚未修复。

后续状态：用户随后授权修复，源码及 14 组绘制检查、26 项相关回归均已完成，见 [修复记录](jma_label_scope_fix_20261103.md)。以上保留审查当时的发现和证据。

## 其他入口和规则

- 新标签开关的唯一生产赋值在 `quake_map_view.dart:3216` 的日本合并填色层；普通其他国家填色入口未传入该开关，默认 false。
- EEW 与情报的合并输入先经 `_shouldDrawIntensityForEvent`：有 EEW 时，正常状态只取 EEW；临时情报聚焦时只取对应普通情报。这两组不会因新增标签被一起混画。
- 日本合并层是图层级开关（任一目标信息启用），不是新增逐条合并规则。非目标标题本身不启用标签；本次没有借审查改动原有合并逻辑。没有把“单独类型未启用”的测试冒充穷尽所有可能的混合报文组合。
- LPGM 走 `JmaLpgmRegionFillLayer`，活动 LPGM 存在时不建立这个日本普通填色层；新标签函数也显式排除 `isJmaLpgm`。
- USGS ShakeMap、DYFI、海啸、火山和 CMT 没有调用新的标签层。它们各自的显示和视角规则没有在此次功能中改写。
- 没有修改测站层、底图、原区域填色计算、原透明度或原始数据；数值位置缓存独立保存，不写入 `TopoJsonRegion.center` 或源多边形。

另外重新运行了 26 项相关回归，全部通过，覆盖填色几何、相机共享视野保持、JMA 震中居中、EEW 情报切换、CENC 共享视角及 USGS 产品回归。本次检查不是安装包全功能验收，也没有更改已运行的云电脑。
