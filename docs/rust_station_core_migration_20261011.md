## 实现与生命周期

Rust crate：`native/station_core`，依赖由 `Cargo.lock` 固定（21 个依赖，image 0.25.10，仅 GIF/PNG/BMP）。Windows CMake 自动编译 release DLL，安装到 EXE 同目录，并携带依赖许可。FFI 调用仍在后台 isolate，不在 UI isolate 执行。

`include/rq_station_core.h` 定义实际 ABI。输入坐标为 Int64，输出含有效位和原始未预乘 `0xAARRGGBB` 通道；越界坐标输出无效。输入字节、坐标、结果均由调用者持有，Rust 不保留指针。Rust 解码图像在返回前释放；Dart 输入缓冲按最大原帧复用，站点配置变化时替换，结果复制为独立 TypedData 后才允许复用原生缓冲。

后台停止采用关闭消息，当前同步计算结束后显式释放缓冲再退出 isolate。手动释放幂等，NativeFinalizer 作为额外生命周期保障。格式/限额错误有明确状态，panic 在 ABI 内转为错误。Windows DLL 缺失或 ABI 不匹配记录错误，沿用既有监测调用者的错误处理；不会以可用性探测掩盖 DLL 未打包。

安全边界：单帧输入最多 8 MiB，图像最多 1,048,576 像素，站点最多 1,048,576，解码器分配限制 16 MiB。当前只接受八位灰度/灰度 alpha/RGB/RGBA；不宣称所有图像格式和位深均兼容。现有上游原始样本全部通过。

## 性能与内存

使用同一冻结 Profile 程序，通过模式选择分别启动迁移前、迁移后实现；每套各 3 个独立进程，交替顺序运行。每批为 51 原帧重复 5 次，即 255 帧，每进程测 5 批，共各 15 批。期间没有同时运行编译或另一套计算。耗时包含 isolate 通信、解码、采样、原震度换算和返回结果，属于模块端到端墙钟耗时，不是整机 CPU 百分比。
