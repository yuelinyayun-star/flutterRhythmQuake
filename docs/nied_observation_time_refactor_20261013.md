# NIED 观测时间数值通路（2026-10-13）

本轮先对原始回放采样，再处理测站记录入口中只需要 epoch 数值或存在性的时间操作。SDK 保持 Flutter 3.41.1 / Dart 3.11；Rust 内核、ABI、依赖和 UI 均未修改，前后使用 SHA-256 相同的上一轮 DLL。这是已有原生内核前的数据通路优化，不能称为完整测站记录状态迁移完成。

## 改动与保持的语义

原生窗口 cutoff 在正常 DateTime 范围内直接使用原始微秒 epoch 减原 retention 微秒值，沿用 VM 的相同 64 位运算，不创建临时本地 DateTime。接近或超出范围时调用原 SDK subtract，让原异常类型、异常文字、负向边界行为及先追加再抛错的顺序继续保持。Dart 列表窗口的实现没有替换。

类型快照增加 hasUpdateTime 存在性视图。普通 HYP 值对象仍判断原 updateAt 是否为空；驱动持有的快照只在时间戳有效且为正时直接判定存在，越界值仍交给原构造器抛出原错误。只替换原生 HYP 入口和 Dart 参考评分中的存在性筛选。实际需要 updateAt 的排序、合并、诊断与显示仍取得原本的本地 DateTime。

没有更改、量化或提前舍入任何原始时间戳、输入像素、观测数值、质量标记、坐标或字段。电脑当地时区与 UTC 标志保留；未切换对外时间为 UTC，也没有修改系统时区或增加全局时区缓存。
