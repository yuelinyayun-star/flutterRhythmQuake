# 情报按实际填色范围缩放（2026-10-31）

本轮授权：地图上有填色的**情报**按实际填色范围计算缩放，保持原有震中定位和各类特殊规则；多条情报在同一视野内切换不移动、不重新缩放。没有扩展到 EEW 的视角规则，也没有修改原始报文、地名、填色算法、阈值、配色、透明度、轮播时长、历史/回放规则或云电脑。

## 实现范围

- `IntensityFillLayer` 只在已绘制区域的集合/绑定变化时发布几何，不重新推算一份与地图可能不一致的填色。涵盖普通 CENC 情报、CWA 观测及预测填色、JMA/KMA 情报。CENC 仪器烈度速报继续保留测站及完整填色边界的独立路径。
- JMA 合并绘制层保持原有合并逻辑；Rust 按每份原始 `warnArea` 的区域名选择边界。没有观测区域时，模型填色只归属原来选中的代表情报，不将另一份情报的区域或 EEW 填色当作自己的范围。
- JMA 长周期观测区域的绘制层接入同一几何接口，保留原有区域代码匹配及颜色。其回调/绘制一致性由渲染契约检查覆盖，未声称注入过一份当前生效的真实长周期报文。
- 地图投影、绘制和动画仍在 Flutter。新边界归并、情报/EEW 选择约束及共享视角保留策略在 Rust；Windows 实际调用新 DLL，没有静默退回 Dart。非支持平台仍有明确兼容实现。
- 缓存以不可变的实际地理对象为键，按最多50000个点分批传输。情报退出后清理其视角缓存，没有增加采样定时器；填色就绪后主动请求下一帧，避免等待时钟刷新。

## 共享视角约束

保留原来的距离分组、所有者选择、源/产品分类、缩放上下限和组几何缓存。没有将相机拟合绑到轮播索引。新成员/更新几何如果仍处于当前可用视口，且与已显示组有共同成员，保留当前中心和缩放；视口大小/旋转改变、独立远处组或范围确实超出时，仍可重新拟合。

边界可见性允许1px的投影舍入差，避免已拟合在面板边缘的角点因浮点误差被判为不在视野。没有放宽实际填色顶点可见性测试：依旧逐顶点检查可用视口（1px数值容差），震中定位误差要求小于1px。

- 相关回归58项通过：CENC 仪器速报入口/共享视角/填色、EEW 临时情报聚焦及返回、CWA 原始观测配色、JMA 长周期解析及渲染契约、USGS ShakeMap/DYFI 视角与手动缩放、火山独立视角、Rust 实际 FFI 及释放。
