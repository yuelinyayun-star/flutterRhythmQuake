# 中国乡镇级气象站数据源调研

更新日期：2026-09-22

## 结论

当前应用的中国气象站图层不是全国区域自动气象站全量数据。

- 已接入的 `weather.cma.cn/api/map/weather/1` 当前返回约 2440 个站点，定位和展示以县、区附近站点为主。
- 中国气象局业务体系确实存在覆盖乡镇附近的区域自动气象站网络，但公开可直接调用的现有接口并未提供其全国原始站表和实时观测全量数据。
- 若要把应用升级为真实乡镇级测站图层，应取得有明确授权的区域自动站站表和实时观测接口；不能用融合网格产品代替测站并标注为“气象站实况”。

## 当前应用接入

### CMA 全国天气展示接口

| 项目 | 内容 |
| --- | --- |
| 全国站点摘要 | `https://weather.cma.cn/api/map/weather/1` |
| 单站实况 | `https://weather.cma.cn/api/now/{stationId}` |
| 当前原始目录规模 | 2440 条站点记录（2026-09-22 实测） |
| 行政字段 | 站点摘要携带 6 位行政区划码；这一级通常对应区、县、县级市、旗等县级区划 |
| 当前目录去重后行政区划码 | 2138 个（2026-09-22 实测） |
| 应用轮询策略 | 全国摘要缓存 10 分钟；本地选定站和地图按需详情缓存 5 分钟 |

该接口的站点摘要包含站名、经纬度、气温、天气现象、风向、风力等。单站详情补充实测降水、气压、湿度、风速、体感温度和更新时间。

它适合：

- 作为无需鉴权的基础全国天气站图层；
- 按用户定位选择最近站点的本地实况卡片；
- 在详细观测数据尚未加载时提供站点名称、天气现象和基础气温。

它不适合：

- 宣称全国每个乡镇均有对应实测站；
- 作为全国区域自动气象站的完整目录；
- 从站名中的“镇”“乡”“街道”推断行政覆盖。

应用代码位置：

- `lib/services/sources/cma_local_weather_service.dart`
- `lib/widgets/map/weather_station_map_layer.dart`

### 本地站点选择的空间含义

应用以用户定位为基准，使用直线距离选择现有目录中最近的站点，不做空间插值。

- 中国区域：定位移动不超过 5 km 时复用已选站；
- 日本区域：定位移动不超过 8 km 时复用已选站；
- 因此卡片含义是“附近测站实况”，不是用户所在位置的插值实况。

经纬度的小数位只能表示接口中站点位置的表达分辨率，不等于台站现场坐标测量精度。

## 乡镇级站网的事实

中国气象局公开材料说明，截至该材料发布时，全国已建设 68762 个自动气象站，覆盖约 4 万个乡镇。这个数字说明乡镇附近的自动观测网络客观存在，但不代表这批站的原始实时流可匿名、无条件地从互联网接口获得。

来源：<https://www.cma.gov.cn/zfxxgk/gknr/jgyzn/bmgk/202209/W020220905533170723301.pdf>

区域自动气象站的业务资料会经过上传和质量控制。接入时应保留站点 ID、观测时间、质量标识和缺测状态，不能只保存最终数值。

## 可选数据路径

### 路径 A：取得 CMA 区域自动站原始实时资料

这是实现真实乡镇级测站显示的首选。

需要向中国气象数据网或中国天气网的官方服务申请并明确确认下列事项：

1. 是否提供全国区域自动站的站点目录，包括站号、名称、经纬度、所属行政区和站类；
2. 是否提供实时或准实时观测，包括温度、湿度、气压、风、降水和观测时间；
3. 更新频率、延迟、并发限制、历史回补和质量控制字段；
4. 使用范围、再分发限制和移动端展示授权；
5. 数据缺测、撤站和站点迁移的元数据更新机制。

中国天气网 SmartWeatherAPI 是官方申请入口之一，但公开页面没有承诺匿名提供近四万区域自动站的原始观测流；申请时应直接指明“区域自动站实时观测和站点目录”需求。

官方入口：<https://www.weather.com.cn/wzfw/smart/weatherapi.shtml>

### 路径 B：CLDAS-V2.0 融合网格产品

CLDAS 使用质量控制后的约 2400 个国家级自动站和近 4 万区域自动站观测，并融合 ECMWF、GFS、卫星及其他资料形成分析产品。

| 项目 | 内容 |
| --- | --- |
| 空间分辨率 | `0.0625° x 0.0625°`，约 6 km 量级 |
| 时间分辨率 | 1 小时 |
| 实时产品延迟 | 官方说明为约 1 小时 |
| 数据性质 | 融合分析网格，不是单站原始观测 |
| 可用性 | 官方页面标示为普通注册用户访问，仍应在接入前核验当前权限和服务条款 |

适合：全国连续温度、湿度、风、降水背景层，或无邻近站时的独立“格点分析”降级显示。

不适合：在地图上画成站点、使用站点图标、称为“乡镇气象站”或混入站点检出逻辑。

来源：<https://k.data.cma.cn/mekb/?dataCode=NAFP_CLDAS2.0_RT&r=data/detail>

### 路径 C：省、市级气象开放数据

部分地方政府或气象部门会开放本行政区的区域自动站数据。这类数据在当地可能比全国目录更密，甚至能覆盖乡镇，但存在以下边界：

- 每个省、市的接口、字段、鉴权、更新节奏和许可不同；
- 没有证据表明可用单一公共接口覆盖全国；
- 接入前要逐个确认来源、站点归属、质量控制和再分发条款。

这一路径适合作为指定省市的补充源，不应先假设可以拼成稳定的全国主数据源。

### 路径 D：第三方地面观测服务

第三方服务可以作为备选或原型验证，但接入前必须下载并审计其站点目录，确认总站数、空间分布、观测来源、发布时间、许可和计费方式。

例如观天者数据站提供按经纬度和按站号查询地面观测的接口，并声明可下载站点表；其文档要求 API Key 和资源点，且公开资料未证明它等同于全国区域自动站全量网络。因此不能将其宣传为已确认的乡镇级全国站网。

文档：<https://docs.datastation.skyviewor.com/developer/api-reference/weather-observation/>

## 推荐接入结构

```text
区域自动站正式授权接口
  -> 原始站点目录和原始观测
  -> 质量标记、观测时间、缺测状态原样保留
  -> 全国真实测站图层

现有 weather.cma.cn 目录
  -> 无鉴权基础回退层
  -> 明确标识为 CMA 天气展示站点

CLDAS 融合网格
  -> 可选连续背景层
  -> 明确标识为格点分析，不进入测站图层
```

推荐优先级：先申请并验证路径 A；在获得稳定的正式数据合同和接口说明前，不把路径 B 或 D 冒充为乡镇真实测站。

## 接入验收清单

在实现任何新增数据源前，至少完成：

1. 抓取并保存一次原始站点目录样本，统计总站数、站类和县级区划覆盖；
2. 对用户常用的城市、山区和边远地区分别计算最近站距离；
3. 保留原始观测时间和质量标志，检查延迟、缺测和补报；
4. 验证温度、湿度、风、降水的原始单位和精度，不以 UI 的小数位替代源数据精度；
5. 将真实站点、融合网格、预报产品在模型和 UI 中分开命名、分开图例；
6. 在后台保活、前台地图和移动端卡片同时验证并发、缓存、限流和断线恢复行为；
7. 确认移动端展示、缓存和再分发符合数据授权条款。
