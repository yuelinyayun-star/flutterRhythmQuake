# 2026-10-11 测站触发检测历史重构

保留 Flutter 3.41.1 / Dart 3.11.0。此次修改仅涉及触发检测历史的存储和清理，以及对应回归测试。原始观测、检测阈值、历史窗口、状态机和对外结果均保留。

备份与完整证据：`D:/flutterApp/flutter-trigger-refactor/20261011-145506`。

## 修改

`lib/core/event_detection/robust_station_trigger_detector.dart` 原来为每条历史创建 `_TimedSignal`，并在每次追加后遍历和搬移整个历史。现改为按需增长的环形缓冲区：

- `Int64List` 保存原始微秒时间戳，`Float64List` 保存原 double 精度信号；不量化、不改观测值。
- 正常时间顺序只清理已过期的头部；同一时刻和恰好落在截止时刻的记录照常保留。
- 收到乱序时，按原算法稳定过滤全部记录，保留顺序；保留窗口恢复有序后继续使用头部清理。
- 整数直方图中位数、非整数排序中位数、缺测处理、预热、升降状态及事件起止时间区间均沿用原规则。
- 重置测站和全局重置仍释放对应历史。

调用链为 NIED source worker → NiedSourceEstimationDriver → RobustStationTriggerDetector。没有更改进入震源估算的门槛或上游解析。

## 常驻历史内存对照

使用上述同一二进制，以 before → after → after → before 顺序独立运行。各进程处理同一份完整原始回放后，释放回放输入并保留检测器；通过活动计时器读取检测器身份，确认其在 AOT 中仍可达，再请求 VM GC。每组两次结果相同：

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| GC 后总 Dart 堆 | 11.131073 MiB | 9.531326 MiB |
| `_TimedSignal` 数量 | 80,323 | 0 |
| 外部内存 | 512 B | 512 B |
| GC 后单点 RSS，两个进程均值 | 213.359375 MiB | 206.271484 MiB |

GC 后堆减少 **1.599747 MiB**。这里堆数字包含诊断程序的共同框架开销；差值来自同场景检测器对照。RSS 只是每个进程 GC 后一次采样的均值，受分配器影响，不能写成整 APP 稳定节省 7.09 MiB，也不能与堆差相加。

第一版诊断程序只写入全局保留变量，AOT 消除了未读取的引用，导致两边历史都被回收。该版内存结果已判无效并保留原记录；正式结果全部位于 `phase2`，分配统计确认两边各有 1,634 个历史实例。修改前的 AOT 已将信号字段直接存于记录对象，未发现每条记录额外保留一个 boxed double，因此不把减少 double 对象列为收益。
