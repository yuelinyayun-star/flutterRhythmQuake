## 数值和内存边界

每次有序搜索建立一个原生会话，按原站点顺序加载邻站数、ascend、原等级、P-Alert 原峰值等级、前一轮 P/S 选择及原毫秒差除以 1000 的观测秒数。会话复用权重、起时、判相、起时插入顺序、排序及场景工作向量；不再为每个候选在 Dart 重建这些列表和闭包。每次返回固定数值结果和两组独立拥有的判相字节，Dart 按原字段构造选中结果和场景诊断。

保持两端锚点先插入、再从中间向外推断的累加顺序；继承场景的初始中心仍按站序计算，过滤和最终评分仍按原中间向外的插入顺序计算。保留零权重 L 站对 rank 的影响、P/S 倾向、30 站阈值和三级继承过滤，以及严格小于时才替换最优候选的规则。没有拟合、舍入原表或放宽浮点容差。

沿用原 JMA2001 表和插值；测距保持原 Dart 三角函数及运算顺序，避免此前已观察到的跨数学库 1 ULP 差异。相同候选的未触发站距离只排序一次供场景复用，原窗口和采样率不变。

`rq_hyp_score_*` 为 C ABI 1。创建时复制输入，求值不保留调用方指针；输出在 Dart 独立复制后才交给消费者。句柄仅留在计算所有者，搜索所有返回/异常路径通过 finally 释放，并有 NativeFinalizer。分配失败和 ABI 错误明确抛错，不隐式重算或改变候选。原生请求字节纳入统一 Rust 统计；其他平台保留原 Dart 评分。
