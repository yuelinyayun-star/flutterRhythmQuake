# 全链路原生后端与 Flutter UI 边界（2026-10-16 修订）

本修订落实用户要求：Dart 最终只负责 UI，连接与数据业务的全部链路迁至高效率、低占用的原生后端。该范围覆盖全部现有数据源、API、实时与回放链，不限于已识别的几个数值内核。此处是迁移边界及验收契约，**不是已经完成实现的声明**。

## 运行链路

原始网络字节 / 原始归档 → 原生连接与协议 → 原生解码、字段适配 → 原生业务状态与计算 → 原生显示投影 → 批量显示快照 / UI 指令 → Flutter 渲染。

原始报文不先交 Dart 再由 Dart 调用原生解析器。原生 HTTP 响应头、完整 JSON 树、完整测站对象图及内部事件历史不返回 Dart 继续处理。Dart 不再生成业务请求、维护连接代次、处理业务重试、源级排序去重、选择最新报或推进推算状态。

所有底层资源和领域状态由原生后端拥有：连接、身份认证、心跳、订阅、重连、HTTP 轮询/超时/取消、协议分帧、解压、JSON/XML/HTML/二进制解析、目录索引、适配、过滤、多源身份合并、修订与取消、事件有效期、观测历史、联合检出、震源/震级/烈度/走时、产品绑定、持久化、归档读取、回放时钟及资源回收。

语音的触发、去重、优先级、播报文本与队列状态由后端决定；界面/平台桥只执行后端给出的播放或停止指令并回传播放状态。地图的数据选择、自动聚焦决策、波圈/烈度/格网数值与批量几何准备由后端决定；Flutter 执行布局、绘制及用户操作。

## Dart 保留的职责

- Widget、布局、主题、字体、屏幕尺寸和 UI 动画。
- 读取后端提供的有限显示快照，更新界面，不复制全量原始数据或重建内部业务状态。
- 将设置修改、源启停、列表选择、显示/关闭图层、回放控制等用户操作作为命令送给后端。
- 薄的 FFI/平台能力调用与回执。桥接层不承担业务计算、事件排序或播报决定。

数据时间和业务期限在后端处理；界面的本机时区与文字格式属于显示投影。原始时间、ID、报数与坐标不因显示或回放而改写。原始载荷由后端归档，用户展开原文时才按需请求只读内容。

## 原生引擎接口与所有权

后端对 UI 暴露引擎会话、命令、更新批次和诊断四类接口。引擎拥有全部源会话与线程/任务调度；UI 不通过逐源原始响应回调控制后端流程。

- 命令包含操作类型、源或事件身份、设置版本和回放会话，不靠传整张 Dart Map 重建后端状态。
- 更新包含版本、显示项增删改、连接状态、地图显示数据和平台操作指令；不要定期回传所有原文/所有历史来刷新一个数字。
- 结果所有权显式 acquire/release，允许持有的只读显示缓冲在后端继续收帧时保持有效；无需的数据不进入 Dart 堆。
- 原生直接连接已迁数值/JSON/波形/图像内核。不能在两个原生模块之间绕回 Dart 再重新编码或调度。
- 原生队列保证领域输入顺序、有限容量及可观察的背压。可以合并显示刷新，不能丢检出输入来换吞吐。
- 实时、回放及不同连接代次的状态隔离。回放使用独立虚拟时钟，保留原报文 ID/时间/报数，不能窜入实时队列。

## 迁移及验收方式

按完整链路交付，最终覆盖所有来源。每一批必须同时移走对应源的连接管理、解析、状态与上层处理，再用原始归档对比最终显示/播报/地图指令。源码中出现 FFI 调用、创建 native client 或去掉一个 jsonDecode 都不单独算一条链完成。

已有 Dart 实现作为冻结的等价性参考，验证时分别运行；完成迁移的正式运行链不再长期维护两套业务状态。尚未完成的链如仍在原路径，必须明确标为未迁完，不能因此缩小最终范围。

完整链性能测量包括源进入至 UI 显示快照生成的全过程：CPU 总时间、UI 帧耗时、进程 RSS/私有提交、原生已分配与保留字节、显示快照占用、积压与延迟、停止/重连/回放结束后的释放。使用相同设置及未经修改的原始输入。HTTP/TCP 或某个计算内核的组件比例只能用于诊断，不能代替这条验收。

前一批 WinHTTP 独立组件占用回退的报告继续保留，实验开关暂时关闭；它说明当前局部替换不达标，不能作为保留 Dart 业务处理的最终架构依据。后续须消除原始数据回 Dart 的边界并测量完整链，仍高的原生环节继续优化或更换实现。

用户已要求停止 Android 构建：当前验证只做 Windows，不因全链路范围变更擅自恢复 Android 编译，不修改云端。没有宣称此次边界修订已完成上述业务迁移。
