# DYFI 信息轮播与地图聚焦修复

## 原因

- DYFI 和 ShakeMap 自动卡片只追加到 `unifiedDisplayEvents`，未进入
  `unifiedEvents`；地图候选、当前事件索引和五秒轮播没有它们。
- 相机策略在普通信息策略之前，只要发现产品图层便调用
  `_focusHistoryProduct` 并返回，因此其他信息即使收到、卡片即使存在，也拿不到视野。
- 列表手动选择的 USGS 产品长期拥有相机。新信息到来后，旧选择仍会重新聚焦。
- 同一位置从普通 USGS 事件切换到 DYFI 时，震中标记的 Selector 只比较事件对象，
  未比较产品类别；自动 DYFI 也被当作普通历史事件另画了震中。

## 修改

自动 DYFI、ShakeMap 以各自的来源标识加入统一信息轮播，和普通 USGS 地震情报分开。
产品服务继续管理缓存、原来的两分钟自动显示期和 USGS 震级过滤，产品不新增地震语音或通知。
同一产品事件的版本更新保留原来的到达顺序、当前轮播目标和五秒计时，避免频繁更新拖住轮播。

移除“只要有产品图层就先聚焦”的分支。自动产品只在被信息轮播选中，或被既有 EEW 临时信息聚焦选中时，
按产品范围调整相机。桌面可见区域的原相机保持规则不会把镜头留在上一张产品上。

手动选择仍保留图层与列表关闭状态；信息目标切换后释放该选择的相机。
之后轮播回到旧事件也不会重新锁住，只有再次手动选择才重新授予相机。
自动产品和手动选择对应不同事件时，当前自动产品使用自己的原始网格。

DYFI 自身不再添加震中标记；普通地震信息自己的标记不受影响。
保留已有 CDI 格子样式、以震中居中计算范围、格子最小像素对应的视野上限。

## 验证

- 产品加载、原始字段保留、过滤、列表与统一 UI、桌面聚焦、DYFI 与 ShakeMap 相机范围、
  手机与 EEW 轮播合计 71 项测试通过。
- 另补充一项原始 DYFI 191→210→223 份报告的版本时序测试，与其余 4 项新增状态测试一起通过。
  该测试使用归档产品的原始元数据，不作为真实地震回放或性能数据；其他信息身份为显式的受控 UI 状态。
- 初次扩展手机回归因测试构造器启动真实 EMSC 连接，留下重连定时器而失败。
  测试改用已有 `startCatalogServices: false` 隔离网络后通过，没有修改生产 EMSC 代码或放宽断言。
- 原始 JSON、GeoJSON 和产品版本文件没有修改。
- Windows 个人版安装包重新构建；尚未在用户正在运行的已安装进程中验证这次修复。
