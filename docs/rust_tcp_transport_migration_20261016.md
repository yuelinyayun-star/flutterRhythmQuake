# GQ 与 SeedLink 明文 TCP 传输迁移

## 接入范围

Windows 的 GlobalQuake TCP、SeedLink/FDSN 明文直连及 HTTP CONNECT 隧道接入共享 Rust/Mio 事件循环。多个连接共用一个 IOCP reactor，不为每条连接启动线程或周期轮询。新增 Mio 1.2.4，使用本地缓存离线构建；已有锁定依赖版本保持不变，Windows 依赖许可证已加入随包 notices。

DNS、代理/PAC 路由、订阅、心跳、重连、序号、测站有效期和领域模型仍在既有 Dart 服务。TLS、HTTP 元数据请求及 XML 解析没有迁移，也没有更换 SDK、修改云端或构建 Android。

`SourceTcpSocket` 仅定义消费者实际使用的原始字节流、add、flush、destroy 和 done 契约，不伪装成一个缺少方法的 Socket。非 Windows 和带作用域的 IPv6 地址保留现有 Dart 路径。TLS 分支仍使用原来的 SecureSocket 和证书策略。

## 原始字节与所有权

- TCP 不包含业务帧边界。相邻接收字节允许合并，顺序及内容完全保留，既有 Java/MiniSEED 分帧器继续处理任意分片。
- 单连接原生接收队列高水位 64 KiB、低水位 32 KiB；达到上限暂停读取，消费下降后通过原生唤醒恢复。没有为了降低占用而丢弃测站包。
- 接收帧移交独立原生分配，通过 Dart external Uint8List 和原生 finalizer 持有，不再复制整块到 Dart 堆。关闭连接或下一次读取不会改变已经发布的缓冲；原列表或其子视图存活期间，字节分配仍有效，最后由 GC 释放。
- 普通 add 不产生没有消费者的写回执。flush 使用有序空屏障，等待此前字节提交；连接关闭时明确拒绝尚未完成的 flush。
- CONNECT 按原路由连接代理，不在代理拒绝时绕回直连。代理头与紧跟的第一段原始数据分别处理，支持分片及 IPv6 authority；拒绝、坏头、超时、取消均关闭连接。
- 连接 ID 单调递增，迟到的事件不能进入替换连接。连接 owner、socket 及未交付队列显式释放；共享 reactor 保留一个空闲等待线程，不声称线程数归零。消费者保留的独立字节块随消费者生命周期释放。

## 连接上层修正

SeedLink 批量订阅保留 STATION/SELECT/DATA/END 的原始顺序，构造一次连续命令缓冲，避免一次大订阅产生数百次独立 FFI/OS 写入。串行协商仍逐次等待应答，DATA 续传与回到实时边沿的规则未变。

TCP EOF 到达时，如果完整测站包还在既有分批解码队列中，先按原来的 128 包/4 ms 预算处理，之后再清理连接。此前直接清空可能使完整包和续传序号丢失。主动停用仍立即取消，旧代次不能继续发布。额外诊断字段展示包缓冲、排空任务和已处理订阅应答，不进入统一 UI 或事件原文。

目录等待测试原来固定睡眠 200 ms，在旧 Dart 传输对照中也会失败。现在在元数据门闩保持关闭时，按条件等待全部 220 站、设两秒上限，并继续断言没有已校准测量。它仍能拦截“元数据阻塞实时接收”，没有改动原始记录、站数或续传期望。
